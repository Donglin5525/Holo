# v9：五模块首页开场与双 HoloAI 重点图

用途：为 1.1.1 简体中文 App Store 页面准备 8 张 iPhone 中等显示屏截图。

## 顺序与产品理由

1. 首页总览，首屏同时看见记账、任务、习惯、想法和健康五个模块，先说明 Holo 是什么。
2. HoloAI 一句话整理一笔支出和两项待办，紧接着展示产品的跨模块能力。
3. 任务热力图与完成时段分布，直接对应 1.1.1 的任务统计升级。
4. 习惯打卡。
5. 想法记录。
6. 健康状态。
7. HoloAI 报告页，展示深度分析如何把财务、习惯、任务和想法放在一起看，并给出跨域规律示例。
8. 记忆长廊，呈现回看日常记录的方式。

头图使用首页总览而不是单一记账或 AI 聊天页，用户先看到五个模块与产品整体定位；第二张再用真实的 AI 混合操作解释 HoloAI 如何把消费和待办一起整理。深度分析留在五模块说明之后，避免一开场把 Holo 误解成记账工具或单一 AI 聊天应用。

## 素材真实性与版式

- 手机内画面均来自 Holo 模拟器实际界面和虚构演示数据；没有用生成模型伪造 App 内字段。
- 首页、习惯、想法、健康、任务热力图、AI 混合操作和 AI 报告页均使用 1.1.1 当前界面或此前核验过的演示素材。
- 第 7 张使用实际的 HoloAI 报告目录页，避免半屏报告弹层带来的暗背景和内容裁切；屏内的跨模块示例明确标注为示例。
- 所有卡片统一使用 Holo 暖色底、手机边框、标题、副标题与顺序编号；编号与上传顺序一致。
- 全部输出为 1206 × 2622 PNG，对应 Connect 当前选中的 iPhone 中等显示屏。
- 可通过 `swift -module-cache-path /private/tmp/holo-swift-cache scripts/render_app_store_holoai_screenshots.swift "$PWD"` 从 `raw/iphone-medium/` 重新生成商店排版图。

## 本地化

当前这 8 张是简体中文 UI。不要将它们分配给繁体中文或英文商店页面；那两种语言应使用对应本地化界面素材。
