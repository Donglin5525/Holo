## 东林真机验收修复轮（2026-10-06 晚）

1. **打开黑屏**（真机复现、模拟器未见）：根因 = 新模块 ViewModel 初始化在主线程同步 `repository.setup()`，真机冷启动数据库未就绪时阻塞主线程整个页面卡黑。修复 = 沿用旧 HabitListView 的首启模式：`warmUp()` 后台等 persistentContainer 就绪后回主线程 setup+refresh；`refresh()` 对未就绪状态静默返回，绝不在主线程等库。

4. **信息密度低**：按东林意见压缩——头部日期与已记录数合并一行、标题 28→24；日期胶囊 46×52→34×38（今天显示"今"），默认滚动到今天完整可见；筛选与"补签/暂停"合并为一行；行高 88→72、图标 40→34、痕迹区收紧。效果：390pt 首屏从 3 行 → **5 行习惯完整可见**（截图 /tmp/holo-habits-final.png）。顺手修复：无记录的计数行不再渲染"− - +"三横线并排（只显示 ＋，有记录后出现 − 和数值）。

## 2026-10-07 黑屏根治轮（真机二次反馈 + 想法模块同症）

**东林反馈**：习惯模块黑屏仍未修复（23:05 截图：内容区纯黑、只有底部今天/回顾/管理标签栏正常）；补充想法模块同样黑屏，怀疑全局问题。

**根因（帧数据实锤，与前两轮的「数据库就绪」诊断无关）**：常驻栈重构（隐藏不销毁）后，模块视图与 `SwipeBackModifier` 的 `@State offset` 跨关闭存活。右滑关闭走 `dismissWithVelocity` 把内容推到整屏宽后**没有任何复位路径**（旧实现靠「关闭=卸载」自然丢弃状态）→ 模块重开时内容整层停在屏外 = 黑屏只剩标签栏。首页此时 opacity 0，模块内容区透明，透出窗口黑底。受影响面 = 全部 8 处 `isResidentScreenRoot: true` 挂载（习惯 V1 容器/旧 HabitsView/想法/财务/任务/AI/健康/记忆长廊）——「全局问题」成立，单点修共享组件全量治愈。

**为何前两轮没修好**：第一轮把「真机黑屏」误诊为「主线程同步 setup() 等库」，warmUp 修复方向错误且本身是假等待（`_ = persistentContainer` 拿到容器对象即返回，不等 store 加载完成）；模拟器走查全用返回按钮关闭、从不用边缘右滑，故从未复现。

**修复**：①`SwipeBackModifier.dismissWithVelocity` 关闭回调后延迟 0.35s（> 0.28s 转场）在隐藏态静默复位 offset=0；②`HabitModuleViewModel.warmUp` 改 `await CoreDataStack.shared.waitUntilReady()`（规范 §10 正确姿势，消灭冷启动快速进模块的主线程阻塞残留风险）；③`HabitModuleContainer` 页头加 `habit.title` identifier（测试锚点）。

**验证（红绿闭环）**：新回归锁 `SwipeCloseResidentBlackScreenUITests`（HoloUITests，已挂 pbxproj）——修复前：关闭后(隐藏态)页头 frame x=16→406（=16+390 offset 残留），重开仍 406（黑屏）；修复后：关闭后即复位 16，重开 16 正常。三步截图判读（/tmp/holo_swipe_close_black_GREEN 同目录结构）确认重开渲染完整。习惯十套件 108 测试全绿。仪器坑归档：automation 树不理会 accessibilityHidden（幽灵元素骗过「回首页」断言）、isHittable 被手势覆盖层误报（速查表在案）、合成边缘手势起点 dy=0.5 会误触打卡行且可能不触发关闭（dy=0.16+长按 0.1s 可靠）。
