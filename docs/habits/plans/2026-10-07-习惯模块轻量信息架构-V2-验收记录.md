## 关键发现与决策记录

1. **HEAD 缺 Tool 系色集资源（V1 入库欠账）**：`holoToolText` 等 8 个 Tool 令牌的 `.colorset` 是并行「温润纸感」批次未跟踪文件（`?? Assets.xcassets/Colors/Tool*.colorset/`）。干净检出 HEAD（如 worktree 隔离验证）构建可过但运行时颜色解析为透明——全部正文文字「隐形」，仅 `.holoPrimary` 橙与图形可见。本轮 worktree 验证时拷入色集资源后恢复。**该欠账属 V1 批次提交不完整，需并行纸感批次收口时入库**；在此之前「干净检出渲染正常」不可作为验收口径。
2. **DateInterval.contains 是闭区间语义（含 end）**：与 §10 半开窗口契约冲突，`HabitRangeSnapshot.containsDay` 显式手写 `[start, end)`；日历格与选中日失效判断统一走它。测试曾 3 红即此因。
3. **补录规则采纳 V1 真源而非 HTML 演示简化**：HTML 原型把「超出 7 天窗口」显示为不可补，属演示简化（未实现 backfill 额度链）。按方案 §10「补录沿用现在的业务规则」，单习惯回顾日期明细的补录资格用 `retroactiveMode`（窗口内 sign / 窗口外 backfill，Plus 额度链完整），不可补原因按 §7.3 列示。
4. **xcstrings 键序重排挂账**：入库脚本按 HEAD 键序 + 新键尾部追加重排（Xcode 本地化比较序无法用脚本复现）；键序对功能无影响，Xcode 下次保存会自动重排。并行批次对 xcstrings 的在途改动（484 增/63 改/8 删）已忠实保留。
5. **UITest 走查在 en 系统语言模拟器上跑**：月份显示「2026/10」、按钮文案走 en 翻译；走查查询已改用 identifier / MATCHES 适配。真机 zh 环境显示「2026年10月」。
