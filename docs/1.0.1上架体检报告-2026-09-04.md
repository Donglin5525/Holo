1. **中国大陆销售范围 + 备案（P0 级决策）**：2023 年起中国区上架必须有 ICP 备案（App 备案）。`api.holoapp.cn` / `www.holoapp.cn` 的备案状态需要东林确认。若首版不确信材料齐全，可先排除中国大陆（前版体检报告同样建议）；同时 metadata 全部语言不得出现 ChatGPT/GPT/OpenAI/Claude 等第三方 AI 品牌词（当前后端用 DeepSeek，App 文案未提品牌词，风险低，仍建议提交前过一遍描述与关键词）。
2. **多语言一期在途改动：按已拍板决策「不随 1.0.1」执行**（CHANGELOG 2026-09-03 收口记录）。已核实：干净基线（release/1.0.1 分支 07ed65983）不含多语言；推送权限修复已提交进该基线；**明天归档必须从干净工作区做**（Xcode 归档打包的是磁盘上的工作区，不是 git——带着 354 个在途改动归档会把多语言连带打进包里）。词表繁体覆盖率实测 97%，显示回退安全，但这批改动留给 1.0.2。
3. **年订定价确认**：本地测试配置为 月¥12 / 年¥128；此前讨论过年订建议 ¥88。请确认 ASC 上配置的实际价格与意图一致（本机无 Apple key，无法代查 ASC）。
4. **「删除账号」缺服务端删除（新发现，P1）**：App 内删除流程只清本机数据（Core Data/文件/钥匙串/撤销 Apple 凭证），**没有调后端接口删除服务端账号记录**（账号、额度使用记录、设备推送 token 等仍留存服务器）。审核员看不出、短期拒审风险低，但属隐私合规实质缺口（删了账号服务器还留数据）。修复需新增后端接口+App 调用，不建议发版前夜动；建议排 1.0.2 首项，需要东林拍板。
5. **DeepSeek 余额监控**：当前余额 ¥48.98 可用；欠费=全 App AI 瘫痪（有前科）。两档告警方案（阈值预警+402 即时）仍待拍板通知渠道（飞书 vs 企业微信）。
6. **在途未提交批次的去向**（不阻塞发版，等东林定）：多语言一期（约 330 文件）、上架素材批（App 图标全套+商店截图+seeder）、若干文档类。建议发完 1.0.1 后分批入库。
