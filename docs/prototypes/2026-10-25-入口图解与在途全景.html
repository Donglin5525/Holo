「入口」= 用户点哪里能进到「记忆管理」这个新页面。目前计划了两个：
① 个人页：已经接好了，开关一开用户就能用。
② 聊天页：就是聊天打字那个页面的右上角加一个「记忆」按钮。还没接——因为聊天页的代码这几天正被另一个任务大改，我现在硬改它，两边容易互相踩坏（之前吃过这种亏）。

第二件事：「清空在途、一起发」的任务全景按你的拍板重排

在途的事状态发版前要做什么、谁来
记忆中心（本会话） 差收尾 补三语词条 + 开关设为开 + 大字体/iPad 走查 → 我来，约半天
其他会话的功能批（想法修复、习惯结算、目标闭环、埋点等，已在代码里） 差提交 各自收尾提交 → 需各会话收口，或授权我做切片提交
聊天页大改 + 「一个发现」（另一会话正在改的就是聊天页） 进行中 等它改完提交 → 你催那个会话收口；收完我再补聊天页「记忆」按钮（半小时）
真机验收欠账（几批修复都写着「待真机验证」） 红线 装包后你本人真机过一遍（我给验收清单，约 20 分钟）——这条不做不能发
后端发版依赖（「今晚时段词」修复需要后端一起发） 待办 我按发版技能部署后端（含在你授权下执行）
版本号 / 打包 / 提审材料 流程活 全部我来 → 最后你上传 App Store Connect
按「一起发」的顺序，接下来发生什么：
① 你拍板：聊天页入口等那个会话收完我再接（推荐，不冒险）还是我现在就接（要冒险改正在被改的文件）。
② 我先把记忆中心收尾（词条/开关/走查）。
③ 各会话收口提交（你催或授权我切）。
④ 我打整包 → 你真机验收 20 分钟 → 我传归档 → 你上传提审。
风险提示：全都在途一起发 = 包很大，任何一件没验收完都会拖住整版。这是「一起发」的代价，你知情即可。
