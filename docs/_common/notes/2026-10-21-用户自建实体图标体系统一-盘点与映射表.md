## 一、现状盘点：三套图标语言的完整地图

### 1.1 三处主战场

| 实体 | 数据字段 | 字段可存内容 | 选择器 | 渲染中枢 |
|---|---|---|---|---|
| 习惯 | `Habit.icon: String`（CoreData） | SF Symbol / emoji / `habit_nosmoking` 资产 | `IconPickerSheet`（AddHabitSheet.swift 内）：经典 9 组约 76 个 SF Symbol + **Emoji 全库**双页签 + 12 色点 | `HabitIconRenderable.iconImage(size:)` 三分支，emoji 走彩色 Text |
| 财务项目 | `FinanceProject.icon: String`（CoreData） | emoji（默认 📁）+ 颜色 hex | `EmojiIconPickerSheet` 全量 emoji 库 | 裸 `Text(icon)` 彩色，8 处（列表/明细/分析两页签） |
| 记账分类 | `Category.icon: String`（CoreData） | emoji / `finance_*`·`income_*`·`cat_*` 资产（186 个）/ `holo.category.*` 自绘 / SF Symbol / `icon_` 旧名 | `IconPickerGrid`（CategoryManagementView）：经典 12 组约 300 个（资产+SF Symbol 混排）+ **Emoji 全库**双页签 | `categoryIconGlyph` 五分支；图表/列表全走它或 `CategoryIconBadge` |

任务书说「习惯=SF Symbol 精选宫格」——实际习惯的选择器**也已接入 Emoji 全库页签**（EmojiCatalogGrid），且存量用户可能已选 emoji。即三处都存在 emoji 入口，统一动作 = 三处选择器的 Emoji 页签全部退役。

### 1.2 范围外的同型 emoji 使用方（拍板问题①）

| 使用方 | 字段 | 现状 |
|---|---|---|
| 目标 Goal | `iconEmoji: String?`，nil 走领域默认 emoji（📚💪💼💰✨🚀🎯） | EmojiIconPickerSheet；`displayIcon` 彩色 Text（GoalListView/GoalDetailView） |
| 纪念日 | `icon`（AnniversaryType 默认 emoji） | EmojiIconPickerSheet；渲染已有 emoji/SF Symbol 双分支 |
| 想法主题 Topic | `iconEmoji` + TopicIconProvider 关键词启发式 | EmojiIconPickerSheet（TopicDetailView），6 处渲染 |
| AI 聊天卡 | ChatCardData `type.defaultEmoji` | 纯展示 |

若只切三处，目标/纪念日/主题仍是 emoji，跨模块「三套语言」只解决一半。

### 1.3 emoji 的纯装饰位（保留 emoji，不受本次影响）

分享卡（ReportShareCard / AnniversaryShareCard / ThoughtShareCard）、庆祝动效、ChatCardData 表情性展示等。这些是「氛围/情绪」位，不是「实体身份」位。

### 1.4 渲染面统计（映射层落点）

- 习惯：`iconImage(size:)` 13 个消费文件（今日/回顾/看板/提醒/补打卡…）
- 财务项目：8 处裸 `Text(icon)`
- 分类：`categoryIconGlyph` / `transactionCategoryIcon` / `CategoryIconBadge` 全财务模块（记账列表、统计图表、预算、筛选抽屉…）

映射做成一个独立解析器（emoji → SF Symbol / 资产名 / nil），三个渲染中枢各加一个分支即可全覆盖，不逐页改。

## 二、统一方案要点

1. **新组件 `MonochromeIconPicker`**（名字实现期定）：单页分组网格、44pt 热区、图标 ≤120、选中态与现 IconPickerSheet 同语言（§8.7 定式7 先找同构：沿用现有圆角磁贴+描边高亮）。色点不入组件（习惯 12 色/项目/分类色保持各模块自有行）。
2. **精选集 ≤120**（第四节全表）：SF Symbol 为主 + 高频自绘资产（finance 食物族 8 个 + habit_nosmoking），全部逐个验证可解析。
3. **展示层映射**：`emoji → 单色图标名`，命中→按 SF Symbol/资产单色渲染；未命中→原样彩色 emoji（兜底，不闪断）。
4. **选择器 Emoji 页签退役**：习惯 IconPickerSheet、分类 IconPickerGrid 的 Emoji 页签删除；EmojiIconPickerSheet 对项目（及范围①拍板后的目标/纪念日/主题）的调用替换。EmojiCatalog/搜索索引本体保留（未切模块仍用）。
5. 存量数据零改写、CloudKit schema 零改动。

## 三、待拍板问题（3 个）

**① 范围**：A=严格三处（习惯/财务项目/分类）；B=连目标/纪念日/想法主题一起切（推荐 B，否则跨模块仍两套语言；主题的 TopicIconProvider 启发式池需同步换单色名）。AI 聊天卡纯展示不动。

**③ 领域默认图标**：Goal 七领域默认 emoji、纪念日类型默认 emoji，若拍板 B，默认值同步换成单色（领域小徽章本来就是 SF Symbol，改动小）。随①走。
