# 个人页、我的积累与发现开启修复

## 产品结论与根因

东林反馈 Plus 图形挤占整行、我的积累长期只显示同步提示且底色不满、一个发现开启失败但原因不明。检查范围为个人页会员入口、积累总览及二级页面、发现授权/开启/接管/关闭重开与设置说明。

1. **Plus 的布局失控**：旧图形中的渐变 mask 没有限定自身宽度，放入 HStack 会吃满剩余空间，麦穗被撑到两端。重做为固定宽高的星芒图形，免费与 Plus 两态，复用全 App 的语义色；小尺寸不使用细线插画。
2. **积累与同步错误耦合**：服务只有在 `!isDownloading` 时才发布快照，哪怕本机查询已成功，也会丢弃所有计数。现在同步只阻止里程碑写入和庆祝，允许展示当前设备已有记录，并提示数字仍会更新。临时快照不成为下一轮庆祝基准。没有本机记录且仍在同步时，展示接收状态，不误报“还没开始记录”。
3. **积累底色未铺满**：稀疏内容没有明确撑满容器，背景也没有覆盖安全区。总览、明细、历史、日期和说明统一处理全幅背景，保留 iPad 内容列限宽。
4. **线上协议不兼容**：2026-10-27 20:15（北京时间）只读请求线上 `/v1/discovery/capabilities`，实际返回 HTTP 200、`enabled: true`、`policyVersion: "v1"`。客户端将该字段声明为 Int，第一步就抛出解码错误。修复支持正整数、`"1"`、`"v1"`；未知格式明确拒绝，不静默降级到旧版本。
5. **失败被误报为取消**：能力查询、控制查询、开启、本地保存的错误都返回 `.cancelled`。新增具体失败类型、阶段与请求关联日志；UI 保留选择和同意状态，展示原因并滚到错误说明，接管页同样显示错误。提交时冻结范围与同意项，关闭表单会取消请求；服务端已确认的开启会回滚，防止关闭后仍悄悄开启。
6. **控制状态漏洞**：先落本机控制快照再发布开启，保存失败会关闭本机并补交服务端关闭；等待服务端确认期间撤回总授权也回滚。离线关闭的待提交意图在重开前先确认；其他设备已经关闭时不再要求接管。
7. **设置说明与功能不一致**：服务未开放时增加重新尝试入口。来源目前通过“关闭→重新开启选择”修改，界面明确说明；隐藏偏好目前支持一次恢复，不再承诺不存在的类别明细列表。明确自动发现不读取长期记忆，也不会自动写入长期记忆，避免与用户手动保存混淆。

## 验证与边界

- Debug 模拟器构建通过，View Weight Guard 通过。
- 发现的授权、规范解码、控制流程、来源适配、检索、证据构建/引用、失效、存储与 JSON 规范化独立候选共 **145 个测试，0 失败**。包括线上真实能力包、数字/字符串版本兼容、失败分类、离线重开、无效接管、在途撤权回滚，以及 Plus 在宽父布局中仍保持 36×36pt。
- 生产积累规则 **25 项断言**通过；生产模型与独立内存库 **29 项存储/状态验收**通过，新增覆盖同步期间数字可见、不写里程碑、同步收尾不庆祝，原有失败保留快照与重试恢复继续通过。
- 专用无头模拟器操作总览→想法积累明细→返回→统计说明，确认总览/明细均为 126 条想法；402pt 屏宽上的统计行宽 362pt，两侧各 20pt，返回和说明可达。
- 验收仅使用独立内存库与模拟器，不修改用户原始数据、不触碰 CloudKit 开发库、不更改生产授权、不执行模型请求。没有后端代码或配置变化。
- 尚不能声称真机观感、真实大数据性能、跨设备同步及生产开启的全链路通过；真实数据的自动发现质量也不由这些测试证明。
