# 深度报告可读性与目标复盘改版 · 实施方案

> 2026-11-20 · 视觉稿：`docs/design-mockups/2026-11-20-deep-report-redesign.html`（第一部分满配、第二部分降级样例与积木门槛表）
> 东林拍板：总分总结构 ✓、数据组件「先试」✓、段落把握长短 ✓、自我说明合并 ✓、分享图一屏出结果 ✓、「开工」✓

## 一、结论先行（产品语言）

1. **读着累**不是排版问题，是「数字全写在句子里」：后端 `deep_report` 引擎把整段自由文本原样当正文，App 只有字没有组件；对话卡片还因为缺「一句话回答」字段，把第一节整段搬了上来。
2. **答非所问**有两个断点：① 对话里问目标不会进入目标回顾链路，而是走 180 天全库快照；② 深度报告引擎遇到目标回顾直接失败（`cloudAnalysisExecutor.js:1143`「目标回顾暂不支持深度报告引擎」）。
3. 改法：**数字交给程序，判断交给模型**。程序在事实清单之外再算一份「组件数据」，App 用组件渲染；模型只写解读段落。数据不够时组件按门槛自动不出现，报告随之降级，不会塌。

## 二、现状证据

| 现象 | 根因 | 位置 |
|---|---|---|
| 对话卡片一大坨字 | 新引擎不产 `directAnswer`/`keyInsight`，卡片回退到 `sections.first.body`（整段），且 15.5pt 半粗、不限行 | `mapper.js` result 构造；`AgentDeepAnalysisCard.directAnswer()` |
| 详情页全是字 | 一段 = 一条 claim 原文；`metricAssertions` 恒空；`chartHint` 恒 null；首句加粗时首句常 40+ 字 | `mapper.js`；`AgentDeepReportView.boldLeadSentence` |
| 分享图被压缩 | 分享卡读旧 narrative 模型（不读 reportStructure），13pt 宋体全量塞入，>8000px 降 scale | `ReportShareCard.swift:46` |
| 目标问题答非所问 | 聊天自由问句不走 `GoalReviewCoordinator`；新引擎拒绝 goalScope | `GoalReviewCoordinator.startOrOpenReview` 仅目标详情页调用 |
| 健康类目标云端看不到结果 | 11-17 目标方案决定「云端复盘不读健康进度」；goal 快照只带 goal/habit/task/finance 数据集 | `GoalReviewCoordinator.swift:130`；`relevantDatasetNames` |

## 三、目标架构

```
iOS 快照（不变，加密上行；目标回顾附 goalReview 事实快照）
  ↓
deep_report 引擎
  1. factComputator：事实清单（已有） + goalFacts（新，goalScope 时）
  2. componentComputator（新，纯 JS）：按门槛产出组件数据，每个组件挂 factIds
  3. writer：目标回顾用「总分总」骨架提示；通用报告沿用现有提示 + 段落长度约束
  4. 数字核对 / 语义核对 / 修复（已有）
  5. mapper：段落长度兜底拆分；directAnswer = 导语首句群；组件按「首个引用其 factIds 的小节」就位
  ↓
CloudResult 新增可选字段 reportComponents（旧 App 忽略，零兼容成本）
  ↓
iOS：组件库渲染（详情页 / 对话卡片取前 2 个组件 / 分享图一屏取摘要组件）
```

### 3.1 组件契约 `reportComponents`

```json
{ "id": "c1", "kind": "habitStrip", "anchorSection": 1, "factIds": ["F012"],
  "payload": { ... kind 专属 ... } }
```

| kind | payload 要点 | 出场门槛（程序判定） |
|---|---|---|
| `progress` | current / start / target / unit / fraction / timeFraction / status(ahead\|behind\|stale\|early) / lastObservedAt / projections[] | 目标有结果指标；stale = 最近观测 >7 天；预测需 ≥3 周、每周 ≥1 点 |
| `kpiTiles` | 1–3 个 {label, value, unit, delta, tone} | 有可比较的本期/上期或前后段 |
| `trendLine` | 周均点（≤12）、可选计划线、高亮区间 | ≥4 个周均点 |
| `barSeries` | 按月/周计数（≤12 根） | ≥3 根且非全零 |
| `habitStrip` | 每习惯 {name, sub, rateText, status, days:[0/1]×≤56} | 关联/涉及习惯且窗口 ≥7 天；>5 项时取变化最大 4 项 + 「其他 N 项稳定」 |
| `periodCompare` | 前段/后段标签 + 3 行指标 | 程序检测到转折点且两段各 ≥2 周 |
| `gapCards` | {title, body, action} ≤3 | 无结果指标 / 结果过期 / 关键维度未关联 |
| `milestones` | 「再记录多久能看出什么」 | 目标创建 <14 天或有效数据 <10 天 |

状态标签规则（程序）：稳 = 后段完成率 ≥ 前段 × 0.8；掉档 = < 前段 × 0.7；已停 = 最近 ≥14 天 0 次；跟随 = 与另一习惯打卡日重合 ≥85%。

### 3.2 写作约束（prompt）

- 段落 2–4 句、70–110 字；超过 150 字 mapper 按句号拆；不足 30 字与相邻段合并（同小节）。
- 组件已展示的数字，正文最多引用 1–2 个，禁止罗列序列（「8 月 22、9 月 23…」）。
- 「数据里没有/判断不了」类说明全文最多 1 次，其余进「数据说明：」段。
- 目标回顾骨架：`## 结果` / `## 关联事项` / `## 还缺什么` / `## 下一步`；没有结果指标则不写「结果」，没有缺口则不写「还缺什么」——由程序在 user content 里给出「本次可写小节」清单。

### 3.3 模型能力的兜底

- 组件全部由程序产出，模型失败也照常渲染；正文失败 → 任务失败走现有文案（不半新半旧）。
- 上线前用 `scripts/deep-report-eval/` 加 4 个目标人设（满配 / 新建 5 天 / 3 周没称重 / 无结果指标单习惯）跑生产同款 deepseek-flash，闸门：数字核对零残留、段落长度 80% 落在 60–130 字、单份耗时不劣于现状 +20%、失败率 ≤ 现状。

## 六、对抗性自审

| 风险 | 对策 |
|---|---|
| 与「懂我」方案 P3 同改 writer prompt | 目标骨架做成**独立 prompt 段**（goal 分支拼接），不改通用 writer 正文；合并前对一次 defaultPrompts.json diff |
| 目标/习惯模块 76 个未提交文件（11-17 目标方案 WIP） | 本方案 iOS 改动集中在 `Views/Chat/Analysis/` 与新文件；D 期才碰 `GoalReviewCoordinator`，届时先确认 WIP 已落库 |
| 旧报告无组件 | 字段可选；无组件走 A 期的可读性版式 |
| 旧 App 收到新字段 | 解码器忽略未知字段（CloudResult 为 Decodable，未声明字段不报错） |
| 组件与正文数字打架 | 组件和事实清单同一次计算、同一 factIds；正文数字仍过数字核对 |
| 分享图固定画布内容溢出 | 一屏模式按优先级取：标题 → progress/kpi → habitStrip(≤4 行) → 下一步 1 条；放不下的直接不放 |
| 成本 | 组件纯程序零 token；目标骨架提示 +~300 token 输入 |
| goal 任务在新引擎曾被显式拒绝 | 拒绝原因是「设计期非目标」，不是技术不兼容；C2 先在评测器验证再解除，灰度沿用 `HOLO_DEEP_REPORT_DEVICE_IDS` |

## 七、模型实测（2026-11-21，生产同款 deepseek-flash，scripts/deep-report-eval）

| 用例 | 结果 | 耗时 | 成本 | 观察 |
|---|---|---|---|---|
| G1 满配（体重+4 习惯） | ✅ | 95–122s | ¥0.16–0.20 | 四节骨架完整；6 个组件全部就位；守住「同时发生≠因果」；未罗列逐周序列 |
| G2 起步期（建 5 天） | ✅ | 85s | ¥0.14 | 不预测、交代再记录多久；里程碑组件出现 |
| G3 结果中断（3 周没称） | ✅ | 77s | ¥0.14 | 直说判断不了、建议先补称；行为侧照常分析 |
| G4 过程型无结果 | ✅ | 70s | ¥0.12 | 不写「结果」节、不编分数；英语「已停」 |
| A1/C1 非目标回归 | ✅ | 72–147s | ¥0.14–0.27 | 版面要求未带坏通用报告；习惯条落在讲健身的小节 |
