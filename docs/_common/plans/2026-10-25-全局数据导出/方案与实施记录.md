> 2026-10-25 立项交付。来源：`holo-memory-center-plan-prototype-1023` 产品债挂账「全量导出/备份功能缺失，待独立立项」。
> 东林拍板：**一期只做导出**（恢复导入二期）；**敏感记忆包含**（「所有数据」名副其实，导出页明示）。

## 一、产品形态

**入口**：设置 → 数据与同步 → 数据管理 → 「导出全部数据」（数据概览之后、删除类区块之前，正向操作独立成行）

**流程**：说明卡（导出范围 3 项 + 排除 2 项 + 明文警示）→ 开始导出 → 进度（来源名 + 百分比，可取消）→ 完成（文件名 + 大小 + 警示 + 分享）→ ShareLink 分享 / 存到文件 App

**产物** `Holo备份_yyyyMMdd_HHmm.zip`：

| 内容 | 说明 |
|---|---|
| `manifest.json` | 格式版本(1)/App 版本/导出时间/各来源实体计数/跳过项说明 |
| `data/<来源>/<实体>.json` | 每实体一个 JSON 数组文件（全部字段、行间换行可 diff） |
| `blobs/<来源>/<实体>/<行键>/<属性>.bin` | 二进制：附件原图、头像、记忆正文包 |
| `finance.csv` | 复用 DataExportService（UTF-8 BOM，Excel 可读） |
| `README.txt` | 用户视角一页说明 |

## 二、导出范围

| 来源 | 处理 |
|---|---|
| 主库 63 实体（CloudKit 全模块） | 全导含软删行 |
| 敏感记忆库 HoloSensitiveMemory.sqlite | 导（经 HoloMemoryRuntime.persistenceController().sensitiveContainer） |
| Discovery 库 7 实体 | 导；打不开跳过不阻塞（manifest 如实缺席） |
| 缩略图 thumbnailData | 跳过（原图可再生派生数据，省体积，manifest 记录） |
| Keychain / HealthKit | 不导（安全 / 不在库内，页面文字说明） |

## 三、技术设计要点

1. **动态遍历模型，不手写实体清单**——从 `managedObjectModel.entities` 枚举，模型加新实体导出自动覆盖。这是根治「导出永远落后于模型」的结构性保证。
2. **流式导出**：每实体 `newBackgroundContext` + `fetchBatchSize(500)` + 逐条 JSONSerialization 写 FileHandle，内存 ≈ 单条记录；blob 逐个落文件。
3. **行键规则**：优先 `id` 属性（UUID/String），兜底 objectID URI（HoloMemoryRecordMO 等无 id 实体实测走到）；关系只导对端行键（to-many 排序），自引用/M2M 环在导出侧无嵌套风险。
4. **值转换**：Date→ISO8601 毫秒；UUID→字符串；transformable（NSArray/NSDictionary）递归；未知类型记 `__unknown` 不静默丢。
5. **取消**：每实体粒度 `Task.checkCancellation`；页面 onDisappear 取消，无孤儿任务。
6. **非核心分级**：main/sensitive 失败即失败（核心数据不容缺席）；discovery 打不开跳过。
