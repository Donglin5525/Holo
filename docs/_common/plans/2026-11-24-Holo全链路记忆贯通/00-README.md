2026-11-24｜东林已拍板方向（见下方拍板记录）｜状态：方案 v1 + 第一轮对抗审查完成，待东林过目后开工

## 一句话

**让用户填过的、Apple 健康读到的、用户认可过的 AI 结论，都能被之后任何一个 HoloAI 入口按需拿到；在一处纠正，处处生效。**

做法不是"把所有数据塞给模型"，而是三件事：

1. **一个本子**：所有"Holo 对你的理解"只存在统一知识库里（现在有三个本子）。
2. **一个认可入口**：确认、准确、收藏、纠正、不再参考——不管从哪个页面点，都走同一个服务写进同一个本子。
3. **一个读取入口**：聊天、分析、深度报告、一个发现都通过同一个组装器取记忆，按场景分配篇幅。

外加一个新能力：**趋势记忆**——程序在本机把一年内的健康、消费、习惯数据压缩成"和你自己过去比，变了什么"的几句结论，只把结论给 AI，不给原始数据，用很少的 token 看到长周期趋势。

| 新增 Core Data 实体或属性 | 新字段一律放进已有的 blob（`recordData` / `revisionData`），避开 CloudKit schema 变更；如执行中发现绕不开，**停下来问东林** |

## 全局红线（每个任务都适用，07 的 prompt 里已重复写入）

1. 工作区有多个并行会话：**提交只能按路径 `git add <自己改的文件>`**，禁止 `git add -A` / `git add .` / `git commit -a`。
2. 禁止 `!` 强制解包、`try!`、`as!`、`print()`、`uniqueKeysWithValues`；日志用 `Logger`。
3. 日期显示必须用 `DateFormatter` + `Locale(identifier: "zh_CN")`，禁止 `date.formatted()` 和 `Text(date, style:)`。
4. `ScrollView` 必须 `showsIndicators: false`。新增 SF Symbol 先验证：`swift -e 'import AppKit; print(NSImage(systemSymbolName: "名字", accessibilityDescription: nil) != nil)'`。
5. **工程文件规则**（2026-11-24 核实 `project.pbxproj`）：
   - App 源码目录 `Holo/` 是 Xcode 同步文件夹（`PBXFileSystemSynchronizedRootGroup`），**新建业务源文件自动入工程，不要碰 pbxproj**。注意它同时被 `HoloMac` target 同步，若 HoloMac 编译报错，参照 pbxproj 里 `membershipExceptions` 已有条目处理并写进实施记录。
   - `HoloTests/` 下的 **XCTest 文件是显式登记的**：**不新建 XCTest 文件**，追加到 04 指定的既有文件。
   - 纯逻辑（零 App 依赖）测试走项目已有的 **standalone 模式**：测试文件放 `HoloTests/...`，由 `scripts/run-*-standalone.sh` 用 swiftc 直编运行（参照 `scripts/run-understanding-standalone.sh`），**不入 pbxproj**。04 里允许新建的 standalone 文件和脚本会逐个写明。
6. 构建和测试一律走 `BuildScripts/holo_build.py`（`build` / `test --only HoloTests/<类名>`），不要手敲 xcodebuild 管道。
7. 不改 `Localizable.xcstrings`（pre-commit 会拦，且有别的会话在改）。
8. Core Data：**不新增实体和属性**；需要新字段时加在 Codable 结构里（随 blob 存），新字段一律 Optional，解码缺省为 nil。
9. 后端部署、真机安装、远程开关放量都属于对外动作，**必须先问东林**。
10. 同一问题连续两轮没修好 → 停下来，在 08-实施记录里写清现状，交回东林。
11. 每个任务开工前先读 08-实施记录，确认前置任务状态；完成后立刻回填（提交号 + 测试结果），聊天记录不算数。
12. **并行会话保护**：开工前对本任务要改的每个文件跑 `git status --short <文件>` 和 `git diff --stat <文件>`。若已有不属于本任务的未提交改动：不覆盖、不回退、提交时不带上别人的 hunk（用 `git add -p <文件>` 只选自己的块）；无法分离时停下，在实施记录登记并交回东林。
