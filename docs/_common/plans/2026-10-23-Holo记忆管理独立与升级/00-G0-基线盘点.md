## 4. 写路径现状（M03/M04 改造对象）

- **FeedbackService**（HoloMemoryFeedbackService.swift）：.accurate/.inaccurate → markUserDecision(.confirmed/.rejected)（仓库侧 confirmed/corrected→state=.active+confidence≥0.95；rejected→.suppressed，CoreDataHoloMemoryRepository.swift:268-304）；.noLongerUse → 先 saveTombstone（identityKey=record.id、canonical anchors、userDecisionVersion 递增）再 suppress（:49-82）；correct（:85-133）改 displaySummary/aiUseSummary/personalContext.statement，userDecision=.corrected、recordVersion+1、predecessor 链。
- **ForgettingService**：forget → 墓碑+markUserDecision(.forgotten)→state=.tombstoned 且清 displaySummary/aiUseSummary/evidenceRefs/counterEvidenceRefs（仓库 :293-298）；invalidateMemories(dependingOnSourceID:) → state=.invalidated（:129-163）。
- **开关写路径**不经 FeedbackService（UserDefaults + HoloMemoryControlStateMO）。
- **关键语义债**（M03 要根治）：.rejected 同时承载「不准确」与「不再使用」，只能靠墓碑有无区分（有墓碑=不再使用路径）；存量无法区分时按方案 §14.1 标「此前已停用」。

## 5. 模型与查询契约（M02 输入）

- **HoloMemoryRecord**（Models/AI/HoloMemoryRecord.swift）：state 九值（candidate/active/disputed/superseded/invalidated/archived/suppressed/tombstoned/deleted）；userDecision 六值；persistenceClass 四值（currentState/phase/durable/permanentFact）；validFrom/validTo/lastSupportedAt/expiresAt；recordVersion+predecessorVersionID+supersedesMemoryID；usageCount/lastUsedAt 可选（专用通道）；personalContext 与 decisionMetadata 均为容错信封。
- **决策信封**（MemoryCore/HoloMemoryDecisionPolicy.swift）：HoloMemoryDecisionMetadataEnvelope{schemaVersion,v2?,opaque}（未知版本原样保留 isReadable=false）；V2{useLevel: factEligible/qualifiedAdvice/observeOnly/blocked, attentionPolicy: silent/askWhenRelevant/neverAsk, sourceAuthority, evidenceVerdict, persistencePermission, reasonCodes, clarification}；clarification 无 resolved 标记（presence=待澄清）。
- **Repository 协议**（MemoryRepository/HoloMemoryRepository.swift:65）：query 仅 active/all/domain 三种；markUserDecision/supersede/replaceRecordForUserControl/saveTombstone；migration 专用三方法不得业务调用；recordUsage 专用通道。
- **收件箱口径**：HoloMemoryAttentionPolicy（MemoryCore/）每日确认收件箱默认下线，回滚位 `holo_memory_dailyConfirmationInboxDisabled`。
