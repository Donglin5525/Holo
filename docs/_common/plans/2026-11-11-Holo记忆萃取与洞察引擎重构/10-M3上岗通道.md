## 架构结论（摸底后定稿）

**不新建记忆通道——影子候选翻译成 HoloMemoryRecord，走既有 HoloKnowledgeIngestion.ingest 全链**。一次接入白得四件现成防线：

| 既有防线 | 引擎侧对应物 |
| --- | --- |
| HoloKnowledgeAdmission 准入（remembered/worthConfirming 分级） | 二次审：闸后的候选再过知识准入（双闸冗余，防影子闸演进回归） |
| 幂等（同语义只刷证据快照，不反复确认） | 同主题多轮影子跑不重复写记忆 |
| 墓碑防复活（rejected/forgotten/tombstoned 记录拒 ingest + 控制操作限制） | 用户删过的理解不因影子重跑复活 |
| CloudKit 冲突确定性归并 | 双设备同步不炸 |

读侧同样现成：resolver → 记忆中心展示；aiUseText + allowedUses → AI 上下文 envelope。写入器接通 = 上岗闭环成立。
