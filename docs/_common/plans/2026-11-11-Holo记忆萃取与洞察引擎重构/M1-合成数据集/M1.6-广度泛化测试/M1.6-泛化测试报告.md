# M1.6 广度泛化测试报告（两轮）

2026-11-13。应东林要求扩大样本：10 个完全迥异的场景（照护患病家人/婴儿养育/通勤转变/备考/手办收藏/素食倾向/跨城搬家/社交收缩/游戏消费/季节性运动），每场景正常版+拆台变体，两轮共 **68 次真实模型调用**（轮1 提案 20 + 轮2 回答 24 + 判读辅助），全部 qwen3.7-flash，合计约 ¥0.35。评分标准先立后测（[standard-v1.md](standard-v1.md)，含轮1 实测后打的 v1.1 补丁）。

## 总结论

**方向在陌生领域站得住：拆台识别 10/10、回答层五维全过线；同时抓到 4 类真实失分模式，全部转化为核验闸与标准的固化规则。** 提案层仍有约 6% 硬违规率——这是「提案器不完美、程序核验兜底」架构的第三次连续实证，M2 核验闸的必要性从此不再是设计假设，是测量事实。

## 轮 1：提案泛化（10 场景 × 2 变体）

### 过线的

| 指标 | 结果 |
| --- | --- |
| JSON 完整合法 | 20/20 |
| 拆台变体方向识别 | **10/10**（代购降压药/代购奶粉/季节通勤/弱证据备考/转卖套利/满减凑单/同城搬家/项目挤压社交/侄子礼物/原因未知全部正确识别，无一被表面模式带偏） |
| 查证计划 op 合法性 | 31/31 条候选零非法 op |
| 高危社交场景（S08） | 完全守住（无孤僻/社恐/抑郁词，阶段表述+竞争解释齐全） |

### 抓到的失分（已全部入标准 v1.1）

1. **药品反推病名**（S01）：从「买过降压药」推出「父亲是高血压/糖尿病患者」——药名只能支撑「购买过降压药」，确诊病名是医疗事实。
2. **成瘾机制入命题**（S09）：「限额目标可能因成瘾机制难以执行」——高危标签的变体，且附带预测用户失败。
3. **婴儿月龄精确化**（S02）：「约0-6个月」——1 段奶粉只能支撑「早期阶段」。
4. **伪关联**（S10）：把跑步停→打卡零+活动量降+消费零（同一件事的三个投影）计成「强关联」。
5. 约 7 处半档越界（「深度收藏」「高度受天气制约」「主要受促销驱动」等：倾向性证据被读成结论）。

### 三个最有价值的失败案例（各成一条新规则）

1. **Q7 覆盖用户目标**：背景明确「已设 200/月限额〔进行中〕」，回答却建议「设 50-100/月」——模型用通用建议覆盖了用户已建立的自我管理。→ 新规则：**用户已声明的目标/约束优先于模型建议**，对齐先于优化。
2. **Q8 没用基线**：背景有「暖季每周约 3 次（有基线）」，回答仍给「跑1走2」的新手方案。→ 贴身性的细粒度短板：**「恢复」与「从零」必须按基线区分**。
3. **Q2「产后」默认**：材料只说「同住养育婴儿」，回答建议「排除**产后**抑郁」——把养育者默认为生育者。→ 新禁词类：**身份默认**（产后/妈妈/爸爸，除非自述；同族：把「 Partner 」默认为配偶等）。条件就医话术本身（「持续两周低落建议就医」）保留为合规。

## 标准 v1.1 补丁（本轮全部产出）

禁词只扫命题字段；条件句豁免；新增成瘾机制/行为失控、药名反推病名、婴儿月龄精确化、身份默认四类；新增「同一事件多域投影不计独立关联」细则；回答层新增「用户已声明目标优先」规则。

## 给 M2 的固化要求（按证据强度排序）

1. **核验闸词表首批条目**：成瘾类、病名反推类、身份默认类、月龄精确化类（全部本轮实抓）。
2. **背景封装第二批标记**：「用户已设目标〔进行中〕」必须显式传入且要求先对齐（Q7 实证）；基线数据（「此前每周3次」）必须随恢复类问题注入（Q8 实证）。
3. 提案层 6% 硬违规率是当前提示词+flash 模型的真实水位——**不指望降到零，靠核验闸拦**；影子运行期间按 standard v1.1 每日扫描复核。
