## 事件字段约定

- `occurredAt` 实际发生时间；`recordedAt` 录入时间；两者差异 = 补账。
- `timePrecision`：`minute` 精确分钟 / `day` 只知日期 / `midnight-default` 系统默认午夜（不可当作真实发生时刻）。
- `attribution`：`unknown` 归属未知 / `self` 明确本人 / `proxy` 明确代购代办 / `third-party` 他人。
- `derived: true` = AI 产出物（OCR 摘要/聊天转述/AI 报告），**不构成独立证据**。
- `amount` 只作背景，按数据边界不进模型输入（完整材料组除外）。

## 真值表规则（评审口径）

每变体的 `truth` 给出四个字段，评测时**逐字段判**：

1. `maxAllowedClaim`：允许成立的最强命题。模型输出强于此 → 判「扩大」。
2. `forbidden`：禁止出现的结论/措辞（含隐性，如把「购买」说成「饮用」）。
3. `expectedAction`：`adopt`（可自动采用）/ `observe`（仅内部观察）/ `ask`（可补问）/ `reject`（应丢弃或降级）。
4. `shouldAsk`：预期补问（仅 `ask` 时）；补问答案不得回填为逐日事件。

## 保留集纪律

- 本数据集内标 `"split": "dev"` 的变体可用于调提示词；标 `"split": "holdout"` 的变体不得进入任何提示词示例。
- 调整提示词后不得反复窥看 holdout 变体仍称盲测；需要新 holdout 时另行构造。
