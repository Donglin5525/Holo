# 01 · 产品交互与设置迁移

## 1. 胶囊与展示规则

常驻行：深度分析／一个发现（符合条件才有）／周期回放／规划目标。其他三个沿用当前真实流程。

胶囊文字固定「一个发现」，不出现隐私摘要。新内容图标与背景可用轻量品牌色；已看变普通样式；无数字、红点、闪烁、催看。未开启时不展示“发现待解锁”占位，不暗示已经后台分析过。

| 状态 | 对话页 | 设置子页 |
|---|---|---|
| 默认未开启 | 无胶囊 | 已关闭，可开启 |
| 首次确认后 | 无胶囊 | 正在准备；无需等待 |
| 材料不足／无合格候选 | 无胶囊 | 有足够依据时再呈现 |
| 有有效且未看发现 | 淡橙色胶囊 | 有一个发现 |
| 已看但仍有效 | 普通胶囊 | 已看，可重读 |
| 有效内容过期／来源失效 | 立即撤下 | 等待新的线索 |
| 网络失败／预算不足 | 有效旧内容可继续读，否则无胶囊 | 暂未更新，不催用户重试 |
| 撤权／关闭 | 立即撤下并终止详情阅读 | 已关闭／授权已撤回 |
| 后端不支持 | 无胶囊 | 暂不可用，开关不可完成开启 |

已打开一条发现时，不被新结果替换；用户退出后才切换。遇撤权、证据失效则必须立即关闭／替换为失效说明，不因“阅读稳定”继续暴露旧内容。

## 2. 发现详情

底部阅读面板，适配大字体与 iPad。以下顺序冻结，视觉间距遵循项目设计规范：

1. 「记录里的一个发现」与关闭。
2. 一句观察标题，建议 12～30 个汉字；最多两行是常规目标，大字体不能截断意义。
3. 一段具体解释，建议 60～140 字，可含时间范围和不确定性；不采用长报告、评分或跨领域 KPI。
4. 「看看依据 · N 段记录」展开实际支持来源，N 是真实独立来源数量，不是模型输出数；单个来源可有多片段，标注清楚。
5. 可选反馈「有点像」「不太准确」；不要求回答。
6. 「聊聊这个」进入可编辑草稿；另有低强调「管理一个发现」。

来源展示实际日期与类型、必要片段，点来源可打开真实原记录。无法跳转的聚合事实提供可核对的计算范围和明细入口；不能做一个无响应箭头。

“支持依据”与“限制／反例”分开：存在改变解释的反例，正文必须体现边界，不能藏在折叠后。没有必要就不展示「AI 已核验」徽章或置信百分比。

### 合格示例（虚构）

标题：这两次重新开始，你都把第一步变轻了。

解释：恢复运动时，你先出门走了十分钟；重新开始阅读时，你放下了每天读完一章的要求。这两段记录有相似之处，但还不能说明这种方式一直对你有效。

依据：运动原文、阅读原文。**不能**改成「你最适合小步开始」「所以这周请坚持运动」或「你已经克服了拖延」。

## 3. 反馈与续聊

| 操作 | 产品后果 | 数据后果 |
|---|---|---|
| 有点像 | 显示已收到，不弹新任务 | 针对此候选认可；不自动写长期记忆 |
| 不太准确 | 先撤下，再可选原因 | 已生成最小否定记录，点击后无需等联网 |
| 依据不对 | 不再展示 | 撤销该候选，检查底层取数或引用错误，不仅降权 |
| 理解不对 | 不再展示 | 抑制同主题同含义改写，待明确新证据才复核 |
| 现在不适用 | 不再展示 | 标时效失效，避免解释为用户否定历史事实 |
| 不想看这类 | 不再展示 | 本机持续抑制该观察类别／主题，可在子页恢复 |
| 关闭或不点击 | 退出即可 | 不产生认可、不推断不感兴趣 |

同一次动作幂等，连续点击不重复写入或触发 AI。允许管理反馈：子页「已隐藏的发现」展示类别与操作，不泄露被排除原文；可恢复偏好，不直接恢复已失效候选。反馈明细首发本机，不上传文本。

「聊聊这个」的草稿同时携带发现上下文，但必须在 UI 显示对象与来源范围。草稿非空时给“保留原草稿／替换”选择，不覆盖。模型只获得仍有效的获授权来源，不读取发现以外的长期记忆来补充此来源包。

普通续聊走既有聊天额度／授权路径，不触发深度分析次数。如果用户明确改成深度分析，显式展示模式并走原确认路径。首发遇活跃规划或草案待确认，保留草稿并提供新会话进入发现讨论，不自动取消正在进行的规划。恢复未发送草稿后再次发送也要重新核验来源。

## 4. 统一 HoloAI 设置

正式入口一：HoloAI 右上角设置，Debug 与 Release 都可见。正式入口二：系统设置 → HoloAI。两处同一个页面／路由。

| 分组 | 条目 | 对应能力 |
|---|---|---|
| 主条目 | 一个发现 | 功能开关、状态、允许来源、已隐藏发现、处理说明 |
| 关于你 | 个人档案 | 原档案编辑器 |
| 关于你 | 长期记忆 | 原自动形成记忆、记忆辅助回答、记忆长廊管理 |
| 自动处理 | 想法智能整理 | 原整理、主题、相关笔记控制；内容管理仍在想法模块 |
| 自动处理 | 周期回放 | 自动周观察、自动日／月回放、周月提醒及时间 |
| 数据与隐私 | 数据处理授权 | 原全局授权服务 |
| 数据与隐私 | 不参与 AI 的想法 | 原标签级全局排除 |
| 数据与隐私 | 云端处理说明 | 区分主动分析、发现自动理解等实际场景 |

开发者 Provider、Key、温度、Token、Prompt、Agent 调试不进入正式用户页，仍独立 Debug。不可把现有 `AISettingsView` 去掉 `#if DEBUG` 当成完成归拢。

## 5. 首次开启与撤销

开启流程：检查登录与 capability → 全局授权（如缺失）→ 本功能自动理解说明与勾选范围 → 同意并开启 → 服务端确认控制与单设备租约 → 保存本机许可并排队。任一步取消／失败保持关闭。

首次来源为空，不预选；至少选择想法／任务／习惯中的一种。V1 不读其他来源。说明里明确必要片段会通过 Holo 后端交第三方 AI，不承诺只在本地推理；不承诺每日、实时或一定有发现。

开关语义：一个发现独立开关只控制本功能。V1 不读写长期记忆，所以用户无需打开自动记忆或回答注入。关闭不会删除原始记录或用户已有记忆。

关闭流程先本机生效：递增控制代数 → 隐藏内容 → 取消任务 → 删除派生候选／来源摘录／检索缓存 → 发服务端禁用。离线关闭时保留待提交的禁用意图，在重新联网后优先提交，在确认前禁止重新发送材料。

全局授权撤回同样本机立即停止，发现本机许可重置关闭。恢复总授权不会自动打开本功能。已发出的第三方请求只能尽力取消，迟到结果永不采纳。

来源缩小时撤销旧批次、清掉受影响发现，更新范围版本并等待新理解；来源扩大要用户再次确认新增范围。后台策略调整不能自行扩大来源。关闭后保留不含原文的最小否定 HMAC 指纹以避免重新开启后再推荐；提供“重置本功能反馈”单独清除，不清业务数据。

## 6. 设置迁移逐项要求

| 现存来源 | 动作 | 不能改变的值／语义 |
|---|---|---|
| `SettingsView.aiOrganizationSection` 全局授权 | 改同页入口 | 原 `HoloAIDataProcessingConsent`，不重新授权 |
| `PersonalView` 个人档案 | 保留快捷链，编辑器统一 | 原档案内容及保存机制 |
| `PersonalMemorySettingsView` | 作为统一设置子页，原入口跳转同一处 | 自动形成记忆与辅助回答两份既有状态 |
| `ThoughtOrganizationSettingsView` | 复用控制源，内容管理留原模块 | 整理、新主题、相关笔记的原 AppStorage 键 |
| `ThoughtAIScopeSettingsView` | 全局隐私子页与原快捷入口 | 开启表示排除；不能反转为允许 |
| `MemoryInsightScheduleSettings` | 统一周期回放子页 | 周月提醒、时间、原后台生成值 |
| `NotificationSettingsView` 回放提醒 | 同一时间编辑源 | 通知不重复注册、不重置提醒时刻 |
| Chat 顶部 Debug 设置 | 新正式页＋独立 Debug 子入口 | 不暴露开发者模型配置 |

### 6.1 已知周观察开关缺口

当前 `MemoryInsightBackgroundService` 的上周观察不受旧后台日／月开关控制。新增一个明确的周观察自动生成控制，覆盖后台与前台补偿的所有周观察自动调用，不能只改 UI。

- 「自动生成每周观察」：迁移初值保持此前产品策略在该用户上的真实有效状态；未授权时显示被总授权暂停，不假装已经在运行。
- 「自动生成日／月回放」：继续使用旧 `backgroundAutoGenerationEnabled` 值，不改变用户已关闭的选择。
- 两者与周月提醒均独立，提醒开启不自动生成，生成开启不自动开启通知。
- G0 必须列全触发点和旧状态；如真实语义与旧注释冲突，按代码路径修订映射，并写迁移说明。

迁移是可重入、无网络／AI 调用的偏好映射；完成标记只在全部成功后推进。不得修改业务 CloudKit schema 或做全量数据重算。

## 7. 原型到生产的差异

原型内容全部虚构，初始已开启便于评审；生产默认关闭。原型内存状态、网页事件绑定、演示 Prompt、伪来源、演示回复不能搬成生产能力。采用现有 SwiftUI 组件与设计 tokens，构建真实 DTO、权限、证据跳转及状态持久化。

已发生“按钮点不动”的原型反馈。生产验收必须执行真实点击、VoiceOver／大字体和复进页面，不能只凭截图或静态检查宣布可用。
