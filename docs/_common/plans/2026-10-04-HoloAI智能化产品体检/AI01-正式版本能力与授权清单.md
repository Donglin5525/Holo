# HoloAI 正式版本能力与授权清单（AI01）

日期：2026-10-04。配套[产品报告](HoloAI智能化产品体检与改进报告.md)整改项 AI01：先形成一张正式版本能力清单，说明每条能力的用户授权、灰度、可用范围和回退——**本清单只盘点不改动，任何开关变动单独拍板**。代码依据为同日只读核实（六断点全属实），行号见[实施方案](G0纳入判断与实施方案.md) §2。

## 一、普通 Release（商店包 / TestFlight 默认态）能力矩阵

### A. 正式可达，无需额外授权

| 能力 | 说明 | 回退方式 |
|---|---|---|
| 自然语言记录（记账/建任务/想法） | 批量解析 + 确认卡；本地与云端轨道均可用 | AI 数据处理同意撤回后停用 |
| 云端深度分析（首轮） | 多轮 Agent 循环 + 交付核验；额度 free 2/天、plus 10/天 | 额度拒绝时诚实失败，不降级伪装 |
| 交付核验防线（本批 AI02 后） | 编造金额/无证据定性结论被撤回；正常事实不受影响 | 后端行为，客户端无需操作 |
| 快照截断标注 + 核验警告标注 | 范围行显示「部分数据已按上限截断」「部分结论未通过核验」 | iOS 端随版本生效 |
| 报告追问 | 父结果血统 + 相邻追问路由，4 小时继承窗 | — |
| 周计划 / 报告续问（本地轨道） | 本地 agent runtime，记忆/档案预取注入 | — |
| Today 减负（基础形态） | 挑少量任务 + 明确开始步骤 + 可撤销；**无真实日程约束与任务时长（AI04 未接）** | — |
| 快捷记账票根识别 | deepseek-v4-flash-vision，拒识通知必达 | — |

### B. 正式可达，但受用户开关控制（新装默认关）

| 能力 | 开关 | 缺省 | 说明 |
|---|---|---|---|
| 记忆 rollout | 服务端 .full（两类门槛不混谈） | — | 引擎层已全量 |
| 记忆辅助回答注入 | 设置「记忆辅助回答」 | 关 | 控制相关记忆是否进入回答上下文 |
| 自动记忆萃取 | 设置开关（走迁移缺省） | 关 | 与上一开关共同构成记忆三闸中的用户侧 |

### C. 普通 Release 不可达（内部测试态）

| 能力 | 门槛 | 现状 |
|---|---|---|
| 个人情境萃取 / 检索 / 规划注入 | `isInternalAccount`（Debug / INTERNAL_DIAGNOSTICS 为 true，普通 Release 恒 false）+ 用户开关 + kill 开关 | 三闸全关；异步云规划同源同关 |
| 洞察反馈 / 学习 / 重排 / 每日感知 / 行动候选 | `InsightFeatureFlags` 按 DEBUG 区分，普通 Release 默认 false | 健康素材例外（单独默认开） |
| 回看闭环（基线/到期/继续决策） | 无开关——`pendingReviews`/`generateReview` 无业务调用方（死存储） | 接线属 AI07（G2），放量前不存在用户价值 |

## 二、开发包与正式包的用户体感差异（一句话版）

开发包里「更懂我」的体验（个人情境规划、洞察学习、记忆主动融入回答）**正式用户当前全部拿不到或默认关闭**；开发验收结论不能直接当作正式版体验结论。这不代表正式版「不聪明」——记录、查询、深度分析、Today 减负、报告追问都是正式可达的；差异集中在「个性化情境」一层。

## 三、灰度建议（待东林拍板，本清单不执行）

按体检报告 §10 依赖规则：**G0 事实门槛（本批 AI02）发版验证通过后，才谈灰度**。建议顺序：

1. **第一步（低风险，随下个 iOS 版本）**：核验警告标注、截断标注默认生效（本批已实现，无开关）。
2. **第二步（需产品拍板）**：记忆辅助回答/自动萃取的新装默认值是否改开——涉及隐私心智，建议保持默认关 + 首次价值引导。
3. **第三步（需后端配合 + 授权补课）**：个人情境灰度——放量前必须补：用户授权文案、删除/遗忘路径、时效失效、最小必要外发验证（报告 §10 回退规则）。不建议直接改 isInternalAccount 判定替代灰度。
4. **第四步**：洞察五开关随 AI05/AI07 场景接线逐个开，不打包全开。

## 四、回退与安全边界

- 个人情境三闸各有独立 kill 开关（UserDefaults 缺省 true=允许，置 false 即关）。
- 洞察开关为本地 feature flags；记忆 rollout 服务端可控。
- 交付核验防线是后端行为，出问题回退=后端回滚发版，与客户端版本解耦。
- 所有「AI 已创建/已保存」类动作的真相源在客户端实体层，核验防线不改变保存语义。
