### 4.3 机械格式核对

对每个PNG读取真实像素尺寸和色彩模式，检查文件能完整解码、RGB、1320×2868；然后计算SHA256并与同名JSON的`output_sha256`相等。报告中的所有`source sha256`也必须逐项等于raw-index。不要只看扩展名或文件大小。可以用以下只读脚本检查当前目录中的50张文件：

```sh
python3 - <<'PY'
import hashlib, json
from pathlib import Path
from PIL import Image
root = Path('../Holo-ASO-交付草稿/关键词候选/iphone-large')
for png in sorted(root.glob('*.png')):
    meta = json.loads(png.with_suffix('.json').read_text())
    with Image.open(png) as image:
        image.verify()
    with Image.open(png) as image:
        assert image.size == (1320, 2868), (png.name, image.size)
        assert image.mode == 'RGB', (png.name, image.mode)
    assert hashlib.sha256(png.read_bytes()).hexdigest() == meta['output_sha256']
    assert meta['release_mapping_status'] == 'unverified'
    print(png.name, 'OK', meta['output_sha256'])
PY
```

机械核对不是视觉验收，也不代表App Store最终编码、颜色配置、应用版本或发布后台配置通过。
