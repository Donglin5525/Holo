## 2. 已读到的accessibilityIdentifier

这些不是拟议的新标识。动态部分要填实际对象ID或枚举rawValue，而不是蓝图字符串。

| 场景 | 标识/构成 | 使用注意 |
| --- | --- | --- |
| 今天快速记录 | todayQuickRecordButton | 在TodayOverviewSection |
| 想法样式菜单 | thought.style.choose | 先打开编辑页“…”；value可为真实样式名 |
| 任务新增 | todoAddFAB | 不保证所有新旧容器都同样可见 |
| 新任务视图范围 | tasks.scope | TaskExperienceView |
| 任务视图切换 | tasks.view.<mode.rawValue> | rawValue读TaskPresentationState，不猜英文 |
| 任务行 | task.row.<真实任务UUID> | 新体验组件；先从fixture-id-map取得ID |
| 任务完成操作 | task.completion.<真实任务UUID> | 不能只tap后就宣称保存，需重新读状态 |
| 任务创建保存栏 | taskCreationSaveBar | 真实创建页 |
| 习惯新增 | habit.add | HabitModuleContainer |
| 习惯行主体 | habit.rowbody.<实际snapshot.id> | id可能不是直接UUID拼法，读快照模型 |
| 习惯记录 | habit.row.<实际id>.record | 只对可见目标操作 |
| 习惯数值加减 | habit.row.<实际id>.increment / decrement | 先核对习惯类型和value单位 |
| 今日习惯主操作 | habit.todayrecord.primary | HabitTodayRecordSheet |
| 今日习惯历史 | habit.todayrecord.history | 跳转回顾后验证标题 |

| 习惯回顾月份标题 | habit.review.monthTitle | 它是标题，不一定可点击 |
| 单习惯范围 | habit.single.range.past / month / d30 / d90 | 先读可见标签和逻辑，不根据名字假设“全历史” |
| 项目列表行 | project.row.<项目名称> | 演示名称城市漫游 |

| 项目编辑/菜单 | projectDetail.edit / projectDetail.menu | 同一详情页 |

没有列出的按钮不能假定有一个“看起来很合理”的标识。真实页面可用label且isHittable时直接用；重复label则限定容器和对象。必须新增标识时，仅做不改变业务含义的辅助，并通过编译与对应页面检查。
