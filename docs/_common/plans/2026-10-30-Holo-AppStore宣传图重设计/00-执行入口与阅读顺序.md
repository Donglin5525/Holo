# Holo App Store 宣传图生产交接包

东林已认可产品主线和关键词分组。本包把它拆成可逐步执行的生产任务。截至2026-10-31，交付目录现有135张有效本地候选：8张历史中屏草稿、2张新中屏R41候选、60张iPhone 6.9英寸候选、58张既有iPad候选、4张REC-01待确认/已入账单状态稿及3张新两步FLOW稿；135张均已逐图只读视觉通过。它们仍来自隔离演示数据和开发构建，发布包映射均为`unverified`，没有上传。R41补齐K01-A/B-06三设备同日回看候选；REC-01现有7张iPad页面候选（D00-04、K01-A/B-01/02/03），但iPhone和中屏仍缺合格识图来源，R07多笔能力未通过。17号文档列出已实际产出的关键词套组、建议前三张顺序和来源阻塞；106张/设备仍是计划目标，不是当前完成数。R01 AI混合输入经真实实测仅部分通过；相关页面保持阻塞，不能沿用旧配置直接渲染。

## 最终要交什么

- 默认页 D00：10 张。
- K01–K08 八个搜索需求，每组 A/B 两套，每套 6 张：96 张。
- 合计 17 套、每个内部创意设备组 106 张。Apple 要求 iPhone Dynamic Island 中屏至少一张截图覆盖；支持 iPad 时要求 13 英寸 iPad 截图。iPhone 6.9 英寸大屏 1320×2868 是本方案的高分辨率创意母版，iPad 13 英寸 2064×2752 是独立母版；按两组完整候选库计算共 212 张。若 iPhone UI 在尺寸间一致，App Store Connect 可将大屏图缩小到中屏；发布前必须检查 Connect 预览是否覆盖中屏、缩放后文字是否清楚。只有预览/可读性不通过或真实布局不同，才追加独立的 6.3 英寸中屏 1206×2622 创意库；三种规格全覆盖则是 318 张。每个产品页最多上传 10 张，CPP 配置 6 张；106 张是内部候选素材库，不是单页上传数量。
- 大屏、中屏和 iPad 独立保留设备原图；复用数据和文案，不把 iPhone 图片拉伸为 iPad。当前已有7张中屏原生原图，R41补采一张真实设备尺寸候选；中屏全创意库仍未制作，最终发版前须在 App Store Connect 核对缩放预览与可读性。
- 同时交原始截图、实际分享导出、可复现渲染工具、配置、证据、逐套预览、上传清单和验收结果。
- 17 套是候选素材库，不意味着 17 个页面同时发布。每个搜索主题从 A/B 选一套作为 CPP 候选；具体发布另行处理。

## 不需要重新问东林的事

已确认：产品主线、默认页职责、八个搜索意图、A/B两种表达、多套候选、真实模拟器界面、接近日常的虚构数据。R01实测后，“自然语言转账目与待办”降为部分通过：不能再宣传AI正确分类/自动保存；相应5张页面保持blocked，继续沿用其余已通过方向，不需要重复询问产品主线。

默认决定：简中、竖版、亮色为主、品牌米白与橙色、单进程单设备分阶段生产、优先原生 Swift/AppKit 合成、用固定配置生成全部图、数据不接日用 iCloud。

## 必须如实保留的边界

本轮“继续”已授权在隔离模拟器和本地目录内推进方案对应的造数、拍摄、渲染与审阅。不得把这项授权扩展为后端部署、真机安装、改签名/Bundle ID、App Store上传提审或生产数据操作；这些仍按实际会话授权与项目规则处理。

没有通过的能力不能靠写一段理想回复或画一个不存在的按钮补齐。受限项可按拍摄卡降级，但要在 capability-matrix.json、受影响成片和交付说明里一起标记。

## 低成本执行纪律

1. 每轮只读当前阶段需要的文件；不要把所有源文件和本包全文反复塞进上下文。
2. 先生成一次公共素材库，再合成 106 张；不要为相同页面重复打开 17 次。
3. 同一故事在必需的6.9英寸iPhone与13英寸iPad各捕获一次；如果6.3英寸UI与可读性无需独立定制，则由App Store Connect缩小主组图。不同文案候选复用对应设备的原图。
4. 先验收 D00 前三张和 K01/K04/K06 各一张，再批量合成，避免 106 张一起返工。
5. 旧素材可用于构图参考，不能顶替要求新数据和新链路的原图。
6. 不使用子代理，除非东林明确授权。模型没有读图能力时先完成机械工作并保留视觉待验状态，不能把 OCR 通过写成视觉通过。

07文件很长，不要每次全读。用工具在不回传全文的情况下筛选当前系列，例如：

```python
import json
from pathlib import Path
root = Path('/Users/tangyuxuan/Desktop/Claude/HOLO/docs/_common/plans/2026-10-30-Holo-AppStore宣传图重设计')
m = json.loads((root/'config/production-manifest.json').read_text())
selected = [p for p in m['pages'] if p['series_id'] == 'K01-A']
print(json.dumps(selected, ensure_ascii=False, indent=2))
```

同理按R编号筛选capture-manifest。模型需要思考的是当前六张和实际异常，不需要重复消耗整套文档的上下文。

继续执行起点：先读 task_plan.md、progress.md 最新条目、findings.md、16号R01报告和17号当前候选建议；核对 production-manifest 的实时状态及交付预览文件。当前已实际生成并复核60张 iPhone 大屏、65张 iPad 13 英寸（含REC-01七张本地候选）、2张中屏R41候选；计划库仍是106张/设备，K01-A/B-01/02/03/06仅部分设备覆盖；整套识图流程未完成，K07/K08无可用套图，部分组也因来源质量或设备差异不完整。下一步只从有新证据或可安全复用且增加不同用户收益的页面继续；保持R01的自动记账/跨域混合主张阻塞，避免恢复已排除的重复页。历史段落中较早的“R01未发送”只描述当时状态，后续progress条目已更新授权结果。继续操作限隔离模拟器与本地素材；不能上传或声称线上发布。
