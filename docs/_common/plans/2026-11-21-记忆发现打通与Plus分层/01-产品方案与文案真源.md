## 2. 用户动线（落到真实 App）

入口：对话页 →「一个发现」胶囊 → `DiscoveryReviewSheet` 弹层。

### 2.1 免费用户

```
打开「一个发现」
 ├─ 本周额度还在 → 自动生成 → 「今天的发现」卡（Holo 看出来的一件事）
 │     └─ 点「对，记住」→ 写进「Holo 记住的你」+ 存进往期发现
 ├─ 模型说没有值得说的 → 空态「这次没有值得专门告诉你的事」（不算次数）
 └─ 本周额度已用 → 撞墙卡
       「这周的发现你已经看过了」
       「Holo 还注意到 3 件事，还没来得及细看」+ 3 个具体问题
       [让 Holo 帮我看看] → Plus 说明页 → [开通 Plus] → 系统付费墙
       「不开通也没关系，11 月 27 日（周五）会有下一件」
底部：「往期发现 N 件 ›」→ 往期发现页（免费）
```

### 2.2 Plus 用户

```
打开「一个发现」
 ├─ 自动生成今天这件（每天最多自动 1 件）
 ├─ 今天这件处理完 / 今天没有 → 「Holo 还注意到的事」列表
 │     每行一个具体问题 + [帮我看] → Holo 专门看这件
 │        ├─ 有结论 → 出现一张新的「今天的发现」卡
 │        └─ 没结论 → 回执「Holo 看了看，这件事暂时没什么值得说的。这次不算次数。」
 │     每天最多点名 2 次；本周 5 件用完 → 「这周的 5 件都看完了」
 └─ 刚开通 → 撞墙标记被清除 → 自动生成一件
```

### 2.3 记忆与发现怎么打通

- 发现卡点「对，记住」→ 已有逻辑 `DiscoveryInsightFeedbackBridge.confirm` 会写进画像（「Holo 记住的你」里可见），本轮不改这条链路。
- 「Holo 记住的你」里已确认的画像条目，已经是发现的输入（`DiscoveryInsightCandidateBuilder` 读 `PortraitStore`），本轮不改。
- 本轮新增的「打通」是展示层：记忆中心顶部明确写「永远免费」；发现卡和记忆中心使用同一套大白话。

## 5. 预告问题拼装规则（D3 的具体口径）

1. 原料是本次组装好的 `InsightInputPacket.features`，每条特征在本机另有一句**用户能看懂的短句**（I2 生成，不上传）。
2. 两条**不同领域**的特征配对：`{短句A}，同一段时间{去掉开头「最近」的短句B}。`（2026-11-22 东林拍板精简：去掉尾部问句「这两件事有关系吗？」）
3. 落单的特征：`{短句A}。`（同轮精简：去掉「Holo 想帮你看看是为什么」）
4. 最多 3 个问题；已经出现在今天发现卡依据里的特征不进预告。
5. 任何问题文本里出现数字（`InsightNumberDiscipline.containsNumerals == true`）就丢弃这条。
6. 模型明确说「没有值得说的」那天，**清空预告**：模型看过、确实没话说，再写「还注意到 3 件事」就不诚实了。
7. 撞墙那天（模型没看过）和成功出卡那天（还剩没用上的特征）才保存预告。
8. 预告保存 3 天有效；Plus 点名看过的那条从列表里移除。

短句表（I2 实现，逐字照抄）：

| 特征来源 | 短句 |
|---|---|
| 异常 `sleep_short` | 最近你睡得比较少 |
| 异常 `sleep_later` / `sleep_late` | 最近你睡得越来越晚 |
| 异常 `activity_drop` | 最近你走路、运动少了 |
| 异常 `numeric_habit_up` | {习惯名}最近记的数值在变多 |
| 异常 `numeric_habit_down` | {习惯名}最近记的数值在变少 |
| 异常其他代码 | （不生成短句） |
| 打卡习惯趋势 up | {习惯名}最近打卡比之前多了 |
| 打卡习惯趋势 down | {习惯名}最近打卡比之前少了 |
| 财务反复消费 | 你经常买{概念名}（有时段时追加`，多在{时段}`，时段含数字则不追加） |
| 睡眠时长变短 / 变长 | 最近你睡得比之前短了 / 最近你睡得比之前长了 |
| 步数变多 / 变少 | 最近你每天走的路比之前多了 / 最近你每天走的路比之前少了 |
| 挖掘器提案 `f_miner_*` | （不生成短句——v3 统计口径，基线已定谳为纯复述） |

`{习惯名}` / `{概念名}` 用现有 `wrappedName(_:)`（会带「」并剥数字，空名返回「某个习惯」）。

示例：
- 「最近你睡得越来越晚，同一段时间你走路、运动少了。这两件事有关系吗？」
- 「「跑步」最近打卡比之前少了，Holo 想帮你看看是为什么。」
