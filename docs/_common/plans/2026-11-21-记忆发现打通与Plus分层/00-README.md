## 任务依赖图

```
B0 开工检查 ──┬─ B1 额度信息回传 ─┬─ B2 点名看（focusFeatureIds）─ B3 部署（需东林同意）
              │                  │
I0 开工检查 ──┼─ I1 契约 ─────────┼─ I2 本机短句 ─ I3 预告问题拼装 ─┐
              │                  │                               ├─ I5 服务层 ─ I6 撞墙卡 ─ I7 Plus 说明页 ─ I8 评审页接入 ─ I9 记忆中心文案+权益表
              │                  └─ I4 本机存储（墙/快照/预告/存档）┘
```

- 后端 B1/B2 与 iOS I1~I4 可并行；I5 起必须串行。
- **同一时间只允许一个任务跑 xcodebuild**（项目红线），所以 iOS 任务全部串行执行。
- 任何任务都不得跳过「开工检查」。

## 范围外（本轮不做，原型里有但已决定延后）

| 原型里的东西 | 为什么不做 | 以后怎么做 |
|---|---|---|
| 「看看是什么」点开才生成 | 真实 App 在打开评审页时自动生成，增加一次点击没有收益 | 不做 |
| 「和 Holo 聊聊这件事」 | App 里没有「带一条发现进对话」的现成入口，新做需要另起方案 | 单独立项 |
| 预告里「你 10 月定了目标……」这类意图类问题 | 意图短句和特征没有可靠的对应关系，拼出来容易张冠李戴 | 等记忆引擎 M3 把意图和特征连起来后再做 |
| 原型里底部三个 Tab | 真实 App 里发现在对话页的「一个发现」弹层，记忆在个人页「Holo 记住的你」，不新增 Tab | 不做 |
| 开通后立刻弹「想先看哪一件」 | 开通后会自动生成一条，已经满足「付费当下就有回报」；点名列表在今天这条处理完后出现 | 看数据再决定 |

## 全局红线（每个任务都适用，prompt 里已重复写入）

1. 工作区有多个并行会话：**提交只能按路径 `git add <自己改的文件>`**，禁止 `git add -A` / `git add .` / `git commit -a`。
2. 禁止 `!` 强制解包、`try!`、`as!`、`print()`、`uniqueKeysWithValues`；日志用 `Logger`。
3. 日期显示必须用 `DateFormatter` + `Locale(identifier: "zh_CN")`，禁止 `date.formatted()` 和 `Text(date, style:)`。
4. `ScrollView` 必须 `showsIndicators: false`。
5. 新增 SF Symbol 名称必须先验证存在：`swift -e 'import AppKit; print(NSImage(systemSymbolName: "名字", accessibilityDescription: nil) != nil)'`。
6. **不新建测试文件**（新测试文件要挂 pbxproj，低阶模型容易翻车），测试一律追加到本方案指定的既有测试文件。
7. 构建和测试一律走 `BuildScripts/holo_build.py`，不要手敲 xcodebuild 管道。
8. 不改 `Localizable.xcstrings`（pre-commit 会拦，且它被别的会话改着）。
9. 后端部署、真机安装都属于对外动作，**必须先问东林**。
10. 同一个问题连续两轮没修好 → 停下来，在 07-实施记录里写清现状，交回东林。
