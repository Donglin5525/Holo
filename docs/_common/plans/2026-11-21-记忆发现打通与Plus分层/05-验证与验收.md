## 三、东林验收清单（真机，按需）

1. 免费设备：看完本周一件后，撞墙卡上的问题读起来是否**像在说你自己的事**、是否让你想知道答案。
2. 撞墙卡上的恢复日期，到那天是否真的能看到下一件。
3. 说明页读完，能否一句话说出「免费和 Plus 差在哪」。
4. Plus 设备：点名看的结果，是否确实在回答你点的那件事。
5. 「Holo 记住的你」顶部横幅是否让你确信记忆不会被收费。

## 四、上线后看的数据（埋点都走 `discovery_today_action`）

| action | 用途 |
|---|---|
| `quota_wall_shown`（带 state） | 撞墙曝光，区分有无预告问题 |
| `quota_wall_plus_tap` | 撞墙卡点击率 |
| `plus_explainer_upgrade` | 说明页 → 付费墙转化 |
| `focus_pick_tap` / `focus_pick_result`（带 outcome） | 点名使用率、没结论比例 |

决策口径：撞墙卡「有预告问题」相比「无预告问题」的点击率至少高出一截，才说明预告问题有效；`focus_pick_result` 里 `nothingWorthSaying` 超过一半，说明短句挑的特征太弱，需要回头调 I2 的短句表或 I3 的配对规则。
