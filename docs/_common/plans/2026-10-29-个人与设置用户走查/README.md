# 个人页与设置页：用户走查结论与改造记录

日期：2026-10-29。范围：iOS 个人页、设置首页、关键子入口、会员入口及会员中心。结论基于当前工作区源代码、改造前后同一模拟器实拍、真实点击与返回；并非只审查设计稿。

## 产品结论

原页面的主要问题是**入口的组织方式失去统一标准**。内容入口、行为设置、数据权限、账号操作、开发工具混用不同层级；首屏资源分配也没有按用户任务排序。只放大 Plus 或补一两个图标，解决不了“找不到、看不懂、不敢点”的问题。

本轮整理了 **33 项问题**，逐项见下表。常规入口实拍中，没有复现“整行图标完全不渲染”；确实观察到会员徽章过小、对比弱，以及代码中长文案可挤压图标/当前值的约束缺口。子页另实拍复现了记忆管理空态的小芽 emoji 显示为问号方框，已改为系统图标。不同原因分开记录，不把推断当复现。

改造原则：个人页回答“我是谁、我的内容在哪里”；设置页回答“如何使用、如何保护与管理数据”。个人页保留设置直达，设置保持首页原入口。

## 改版后的结构

| 页面 | 顺序 | 内容与意图 |
|---|---|---|
| 个人 | 1 | 头像、昵称和编辑入口；未设置昵称显示“我的资料” |
| 个人 | 2 | 独立 Holo Plus 横条，56pt 徽章、真实免费/会员状态和进入箭头；常规高度 80pt |
| 个人 | 3 | 我的内容：我的目标、Holo 记住的你、我的积累，使用同一种入口行 |
| 个人 | 4 | 个人档案：角色与偏好，与头像昵称分开说明 |
| 个人 | 导航栏 | 关闭、设置；设置关闭后回个人，重看引导时退回首页 |
| 设置 | 1 | 资料与 Apple 登录状态；账号状态和 iCloud 状态分开表达 |
| 设置 | 2 | 使用偏好：外观、通知 |
| 设置 | 3 | 数据与同步：iCloud、最近删除、数据管理、账单导入导出、日历接入 |
| 设置 | 4 | 隐私与安全：应用锁、AI 授权、AI 排除范围、小组件原文、隐私政策 |
| 设置 | 5 | HoloAI 与想法：AI 行为统一设置、主题标签与整理 |
| 设置 | 6 | 帮助与反馈：使用帮助、意见反馈、关于 Holo |
| 设置 | 底部 | Debug 开发者选项；退出登录与删除账号独立放在底部 |

个人页里的“内容管理”和设置里的“行为开关”可以保留指向同一能力的入口；它们服务不同任务。周期回放则不再保留两套内容不同的设置页。

## 33 项问题与处理

标记：P1 = 影响发现、理解或操作；P2 = 影响效率、观感或适配。“实拍”指常规模拟器中直接观察；“代码”指明确的结构或约束问题，不能等同于每种状态都已在真机复现。

| # | 优先级 | 原问题与用户影响 | 依据 | 本轮处理 |
|---|---|---|---|---|
| 01 | P1 | 个人页先会员后资料，身份入口夹在 AI 档案中，用户难以建立页面认识 | 实拍 | 头像与昵称提升为页首独立入口 |
| 02 | P1 | Plus 入口徽章仅 36pt，精细侧脸与桂冠缩成很小一团 | 实拍、代码 | 换为确认的 A2 肖像麦穗；10-30 个人页收为 56pt 徽章及 80pt 横条，会员中心/升级页保持 72pt |
| 03 | P1 | 免费用户只看到“免费版”，首屏没有 Holo Plus 名称，不像会员入口 | 实拍 | 固定展示 Holo Plus，免费/已开通作为状态说明 |
| 04 | P2 | 免费态银灰徽章放浅底，线稿辨识弱；会员入口与普通设置行无明显层级 | 实拍 | 复用既有 Plus 深色主题，提高徽章与文字可见性 |
| 05 | P1 | “个人资料”和“个人档案”挤在同一组，用户不清楚各自负责什么 | 实拍 | 页首编辑头像昵称；角色偏好放“让 Holo 了解你” |
| 06 | P1 | 档案入口主标题是“未配置/已配置”，状态代替了功能名称 | 实拍 | 主标题始终为“个人档案”，状态降为辅助信息 |
| 07 | P1 | 只有一条欢迎笔记时，“我的积累”入口也占约 182pt，入口像详情面板 | 实拍、AX 坐标 | 改为摘要行，完整统计留在积累页 |
| 08 | P1 | 目标、长期记忆被大卡片挤到首屏底部甚至屏外 | 实拍 | 三个内容入口合组，目标与记忆优先排列 |
| 09 | P1 | 在个人页想改通知/外观，需退回首页再找设置 | 实拍、代码 | 右上角增加设置入口，复用同一设置页 |
| 10 | P2 | Debug 个人页把 AI 实验室当普通内容展示，干扰日用路径 | 实拍 | 实验室归到设置的开发者选项，个人页撤下 |
| 11 | P2 | 记忆摘要使用顶部悬浮覆盖，关闭图标小，可能挡首屏内容 | 代码 | 改用底部安全区，关闭热区 44pt |
| 12 | P1 | 个人页右滑调用系统 dismiss，关闭按钮却走宿主回调，iPad 页面层行为不一致 | 代码 | 两种关闭方式统一调用 close，保留子页系统返回让位 |
| 13 | P1 | 设置首页优先铺开 AI，外观和通知放在后半段，需要长滚动 | 实拍 | 使用偏好前置；AI 成为独立后置组 |
| 14 | P1 | 找回误删记录必须进入“数据管理”再找最近删除，紧急恢复入口过深 | 代码、实拍路径 | 设置一级直接进入最近删除，复用原恢复页 |
| 15 | P1 | 设置没有账单迁移入口，用户需要自行想到财务模块里寻找 | 代码 | 增加“账单导入与导出”，复用原流程，明确只含财务 |
| 16 | P1 | AI 数据授权放 AI 组，隐私政策藏在关于页，隐私组反而没有这些内容 | 实拍、代码 | 授权与政策在隐私组直接可达 |
| 17 | P1 | 排除私密想法需进入 HoloAI 的多层页面，高敏感控制难找 | 代码、路径 | “不参与 AI 的想法”提升到隐私组 |
| 18 | P1 | “AI 回放”和“周期回放”两处设置内容不同：一处三开关，另一处还含每周观察 | 代码 | 删除旧的三开关页，统一进入完整周期回放；通知页继续负责提醒时间 |
| 19 | P1 | HoloAI 设置作为 sheet 没有明显关闭按钮，退出依赖下拉手势 | 代码、路径 | 增加明确关闭按钮，保留子页面返回 |
| 20 | P1 | 行标题强制一行、副标题固定 12pt、图标可压缩，长文案/大字下可读性与完整性不足 | 代码 | 使用共享语义字号、允许换行、固定图标底座，开关有完整朗读标签 |
| 21 | P2 | 两套分隔线缩进混用；HoloSettingsSection 已加内边距，分隔线又重复计入，错开正文 | 代码、实拍 | 区分整卡与卡内分隔线，均对齐正文起点 |
| 22 | P2 | 40pt 方砖和 36pt 圆形图标并存，箭头、颜色、卡片描边不统一 | 实拍、代码 | 个人与设置入口共用 HoloSettingsRow、圆形底座和标准箭头 |
| 23 | P1 | 外观行同时列选项和当前值，空间竞争导致当前值显示不稳定 | 实拍、代码 | 普通字号只在右侧显示当前值；辅助字号移到正文列 |
| 24 | P1 | 外观改变通过 .id 重建整个设置，存在滚动与弹层状态被重置的风险 | 代码 | 移除重建标识，直接响应当前外观；实走切换与返回 |
| 25 | P2 | iPad 设置分组导航固定 40pt 高，文字也强制一行 | 代码 | 改为至少 44pt，允许标题换行 |

## 能力边界与后续

1. 当前导出能力是财务账单导出，不是全 App 可恢复备份；JSON 也不能因此被宣传为全量恢复。本轮增加的是现有能力入口，明确标注范围。完整备份/恢复应单独建设数据能力。
2. 会员视觉使用本地 Debug 权益覆盖验收；真实购买、恢复购买、Apple 登录、生物识别与跨设备 CloudKit 同步仍需对应真机/沙盒环境验收。空数据模拟器不能证明这些外部能力已通过。
3. 这次不执行删除账号、清空数据、恢复/重拉云端库或启用 AI 授权；危险操作只核对入口和确认机制。
4. 当前工作区包含其他会话的在途修改；本轮只调整页面与共享展示组件，不把其他改动计作本轮成果。
