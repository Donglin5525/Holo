# Task Plan：HoloAI 个人情境规划一致性与可信交互实施文档

## 目标

基于 2026-09-09 真机录屏与当前代码，输出一份可直接交给 GLM 实施的完整方案，覆盖意图一致性、持久运行状态、云端阶段流、证据跳转、日期语义和结果可信度。

## 阶段

- [x] Phase 1：复核录屏现象、当前代码与历史产品约束
- [x] Phase 2：读取现有个人情境和 Agent 生命周期方案，确定复用边界
- [x] Phase 3：编写产品、状态机、数据契约、前后端改动与迁移方案
- [x] Phase 4：补齐测试矩阵、灰度、发布、回滚及 GLM 执行顺序
- [x] Phase 5：自审文件路径、章节完整性、技术锚点和未验证项

## 已定原则

- 明确的规划请求必须稳定进入同一能力，不允许模型随机分流。
- UI 状态必须来自持久化 run/message 状态，不能依赖页面内存变量。
- 流式展示阶段事件，不展示模型隐藏推理过程，不伪造百分比。
- “你的记录”必须能追溯到真实来源；权限或遗忘后按历史快照与当前可访问性分别表达。
- 日期的“未设置”与“今天”必须是两种不同状态。
- 外部事实未核验时不得显示为确定结论。
- 本任务只写文档，不修改业务代码、Prompt、配置或 Git 状态。

## Errors Encountered

| Error | Attempt | Resolution |
|---|---:|---|
| 项目根目录已有其他任务的规划文件，且缺少 progress.md | 1 | 不覆盖；为当前任务建立独立伴随目录 |
| 第一次补写 findings 时目标段落名与实际文件不一致 | 1 | 先读取实际文件，再按现有章节追加；未覆盖原内容 |
