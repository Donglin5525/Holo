## 关键问题
1. 当前四个胶囊如何触发，是否需要用户确认后发送？
2. 深度分析八个场景如何让用户理解适用性而不挤占输入区域？
3. “一起想清楚”能否成为规划目标的单一入口，旧目标和手动创建如何保留？
4. 今日状态是否可以退出常驻横排，而周期回放和报告如何定位？

## 已定方向
- 保留“深度分析”显性主入口，提供可理解的用户问题与可信的数据预检；不把全部域名直接平铺为第一屏。
- “一起想清楚”取代胶囊“规划目标”的入口名称，不取代 Goal 管理与手动创建；按现有灰度门禁分阶段合并旧 AI 规划。
- “今日状态”退出常驻行，“周期回放”保留为第三入口；状态恢复占运行态横幅而不加第四常驻胶囊。
- 深度分析 Prompt 优化先确认真实字段保真与可用证据，不能只把场景问句写长；最终方案要区分场景引导、云端分析 Prompt、结构化输出与阅读层。
- 最小复现已证实云端 query engine 忽略 `plan.timeRange` 且把 `groupBy: month` 合并进全量桶；`final_claims` 无 claim 也能通过结构校验。先补正确性再发新版强问句。
