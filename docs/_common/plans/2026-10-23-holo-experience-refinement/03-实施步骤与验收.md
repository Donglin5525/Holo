# Holo 日常体验实施步骤与验收

## 1 阶段顺序

阶段估算以当前源码复杂度给出工作量级别，实际排期由 GLM 完成 E0 后确定。下面是建议顺序，不是承诺完成日期。每阶段通过相应门槛再进入下一阶段；不把三页全部改完后才第一次运行。

| 阶段 | 工作与产出 | 依赖/完成条件 | 建议工作量 |
|---|---|---|---|
| E0 现实盘点 | 记录分支/HEAD/脏文件/有效开关；复核原型、源码入口、两并行项目进度；抓改前代表状态与操作录屏；确认编辑器保存语义 | 形成文件归属表、基线图/录屏、原型差异表、风险和实际支持设备/系统 | 半天到一天，取决于在途集成 |
| E1 想法样板 | 日期分组、正文优先行、元信息/附件、范围/搜索、计数、保存/返回；保持旧业务回调 | T01–T16 及相关空态/交互用例通过；与旧样式同数据对照 | 约 2–3 个开发日 |
| E2 长廊承接 | 空章节压缩、最近资格/日期查询、预览与跳转、积累短入口、无记录文案；四尺度回归 | G01–G16 通过；180天旧记录、软删、部分失败、请求乱序可证明 | 约 2–3 个开发日 |
| E3 HoloAI 层级 | 简化视觉身份、保留语音/报告/状态；结果卡信息主次、能力行；接已存在设置/发现/记忆路由 | A01–A15 通过；ChatView 红线与真机门禁执行 | 约 1–2 个开发日，独立项目缺口另列 |
| E4 联调与调校 | 同一组来源/日期/草稿往返；深色、空态、长文、大字体、iPad；修复可见性与命中问题 | C01–C10，视觉挑刺三问，原型差异有结论 | 约 1–2 个开发日 |
| E5 交付与回退 | 整理自有改动、功能差异/未完成项、门禁证据、内部回退演练；准备包 | 五大入口冒烟；涉及 Chat 的真机两个门禁；数据不变量成立 | 按设备与质量结果安排 |

上述开发日是未被并行改动阻塞时的粗估，不包含 Discovery 引擎/记忆管理的全部开发和独立发版。先交付 E1 的代表性样板可帮助发现方向偏差，已授权方向内的常规实现无需每个小任务再问东林。

## 3 想法验收 T01–T16

| ID | 前置/操作 | 可观察预期 |
|---|---|---|
| T01 | 6条跨6天想法，打开列表 | 正文先读到；日期分组与真实日期一致；数量不是硬编码；没有重复年月日/大空卡 |
| T02 | 当天两条、前一天一条；改变旧记录正文 | 更新原行，计数不增加，不挪到今天 |
| T03 | 一条/纯图/无标签三种样本 | 三态都体面，正文/图可打开，没有为填满页面堆统计 |
| T04 | 正文→现有编辑器→返回 | 初始不误弹键盘；回原范围/锚点；读写未分叉 |
| T05 | 全部范围新建并保存 | 成功后定位新ID，一次轻反馈；持久化后重进能找回 |
| T06 | 模拟保存失败、附件转正失败 | 草稿/附件保留，计数不变，不出现成功反馈 |
| T07 | 标签范围新建不匹配标签的内容 | 原范围不被清空；有准确已保存提示与明确查看入口 |
| T08 | 置顶、归档视图、同时间记录 | 置顶语义保留，归档规则不变；稳定身份、无重复行 |
| T09 | 搜索/标签/主题交集→原文→返回 | 查询和范围/位置保持，清关键词不清范围 |
| T10 | 搜索无结果、全库空、查询失败 | 三种文案和恢复动作可区别；错误不显示0条 |
| T11 | 多标签、超长主题、引用失效 | 折叠/展开和真实目标成立；长文可读，失效不跳错记录 |
| T12 | 点击正文、标签、图片、更多；侧滑/抽屉/左缘返回 | 各自命中，无透明层吞点击，无返回误开侧栏 |
| T13 | 1000条合成内容、快速滚动与开关菜单 | 图片懒加载、无明显卡顿/错图；菜单不触发全库重算 |
| T14 | 编辑中后台/重启/中文组字 | 使用已有草稿恢复；无丢字、乱码、双份记录 |
| T15 | 同步新记录/重复UUID/删除后恢复 | 无重复、无云同步庆祝重播；软删不泄漏到活列表 |
| T16 | 从长廊/发现进入同一想法编辑后返回 | 各来源现场可恢复；标签/原记录和发现有效性正确更新 |

## 4 长廊验收 G01–G16

| ID | 前置/操作 | 可观察预期 |
|---|---|---|
| G01 | 今天有想法/账目/完成事项 | 真实内容接在章节头后，无多余“最近”卡争首屏 |
| G02 | 今天无记录，昨天一条想法 | 今天说明紧凑、最近片段在常规首屏可发现；日期准确 |
| G03 | 只在180天前有一条记录 | 能找出并导航，不因±20/60天窗口空就判全库空 |
| G04 | 全库确空 vs 一模块查询失败 | 只有前者出现首次使用空态；后者有错误/部分范围说明 |
| G05 | 最近记录在回收站/父容器已删 | 不作为预览/计数；不凭缓存暴露正文 |
| G06 | 预览点开之前来源被另一设备删除 | 明确不可用并重新选择，不跳相似记录、不崩溃 |
| G07 | 从预览回到昨天→原文→返回→今天 | 聚焦日与视口可解释，历史到今天章节连通 |
| G08 | 月点某日→当日预览→回放这一天 | 按既有两步进入，保持选择；雾蓝色阶/橙色今天正确 |
| G09 | 日/周/月/轴来回切 | 四者确实不同，围绕同一 focusedDate，无四套selectedDate |
| G10 | 快速跨月/跨年，故意延迟旧请求 | 迟到结果不盖新标题；范围内的空洞不冒充已加载 |
| G11 | 模块筛选无记录、待办到期维度 | 提示当前范围；不清筛选、不把到期当已完成 |
| G12 | 历史补记/导入当日无时刻 | 归属历史业务日，不假造今天记录或凌晨时刻 |
| G13 | 我的积累→详情→返回 | 共享真实服务快照，数字一致，返回保持长廊现场 |
| G14 | 时间轴未来日程/系统授权关闭 | 原安排能力和范围不被本包禁用；关闭权限不泄漏详情 |
| G15 | 多记录日滚动/向过去翻页 | 保留Lazy行；追加在底部不突然跳动，末行不压手势区 |
| G16 | 跨午夜/切时区/重复同步事件 | 今天更新合规、历史不自动跳走；同事实只计一次 |

## 5 HoloAI 验收 A01–A15

| ID | 前置/操作 | 可观察预期 |
|---|---|---|
| A01 | 普通文本回答、长回答、语音输入 | AI身份清楚且不重复堆装饰；语音、流式/停止仍能用 |
| A02 | 记账待确认→确认成功→查看账目 | 保存前不显示已记下；成功后金额/币种/分类真实，ID落点正确 |
| A03 | 两项成功一项失败 | 分项状态明确，失败可恢复，不出现笼统全部完成 |
| A04 | 历史卡关联实体被改/被删 | 不从快照重建；可查看当前值或准确不可用说明 |
| A05 | 长草稿→设置/记忆/报告→返回 | 文本、会话、规划现场和滚动不丢失 |
| A06 | 深度分析/周期回放/规划目标 | 进入现有真实流程，未出现网页范围说明或假规划冒充能力 |
| A07 | 发现未开/准备/无候选/失效/能力未部署 | 无占位胶囊；设置状态与服务真实一致 |
| A08 | 有效发现→依据→源记录→返回 | 计数准确、原文可核对、回同一条发现且展开状态保持 |
| A09 | 阅读发现时有新结果/来源撤销 | 新结果不抢阅读；撤权/失效立即移除敏感正文与相关动作 |
| A10 | 有点像/不太准确/暂时不说/重复点击 | 成功/失败状态真实，否定先撤下并落最小记录，幂等，不写长期记忆 |
| A11 | 聊聊这个，无草稿/有草稿/取消 | 只预填，不自动发；保留原稿不加隐藏上下文 |
| A12 | 关闭发现/离线撤权后继续输入 | 原草稿文字保留，失效上下文移除，迟到响应不重新出现 |
| A13 | 首次开启/无来源/取消/服务失败 | 生产默认关闭，首次无预选；未完成条件不开启 |
| A14 | 两处统一设置与独立记忆入口 | 同页同状态，设置不复制；记忆管理落到独立中心而非长廊重复列表 |
| A15 | 多语言/大字体/窄屏/VoiceOver | 记忆/设置可发现，能力可横滑，发送/停止与底部操作不被盖住 |

Discovery 的AI语义质量测试、两阶段真实模型试评、费用/调度验收仍由其独立包执行；本表不能替代它们。无真实服务时可通过合成fixture验证UI状态，但必须标注未完成真实链路。

## 7 合成测试材料

只用专门测试库或 Debug 注入的值快照准备数据，不往东林日用 CloudKit Development 库批量造样例。本库就是用户真实数据，禁止 reset/清空来准备空态。

| 材料集 | 组成 | 覆盖 |
|---|---|---|
| F00 | 无记录，各模块查询成功 | 真正首次使用 |
| F01 | 昨天1条想法带1图，今天空 | 核心稀疏承接 |
| F02 | 6天6条想法，含长文、2图、无标签、多个标签 | 内容层级、日期和附件 |
| F03 | 同日想法/两笔不同币种收支/一次习惯/已完成与未完成任务 | 日聚合、金额、资格差异 |
| F04 | 180天前1条、当前缓存窗口空 | 全局最近索引 |
| F05 | 软删、父链缺失、归档、重复UUID | 数据隔离与既有语义 |
| F06 | 某模块读取失败、同步未完成、旧请求迟到 | 加载/失败/乱序 |
| F07 | 有效发现与2个独立真实fixture来源、已读/无发现/失效/撤权 | 发现状态与续聊 |
| F08 | 中文长文/英文长标签、AX大字、窄屏 | 布局与可访问性 |
| F09 | 1000条想法/200张缩略图、跨月日期 | 滚动、懒加载、日期范围 |

输入时间应按测试时的 today 派生，不把网页的2026-10-23硬写进测试。未来事件与历史记录分开，来源字段引用真实fixture记录ID，不能只把漂亮文本放进UI数组。

## 8 验证粒度与证据纪律

- 分组/最近资格/请求版本等新增确定性逻辑做有意义的单元测试：重点覆盖真实语义差异、错误分支、软删和乱序，不为样式常量写镜像测试。
- 组件细调中只做对应页面冒烟；装包交付前才合并五大入口。不要每改一个间距都全量重测，也不能用静态代码阅读替代实点。
- 浏览器HTML检查只证明原型；SwiftUI构建只证明编译；模拟器测试对真机栈溢出无证明力。各证据按实际范围表述。
- UI主会话生成截图、机械操作；图片判读遵循当前宿主与 HOLO/AGENTS.md。若规则要求只读判读代理，按该规则执行。未获得图片/设备证据必须写“未验证”。
- 用户数据不出现在交接包、公开日志或新增截图附件里；审美样本用合成数据。原文调试日志不得为检查界面方便而全量打印。

## 9 交付内容

1. 自有文件变更与对应任务/验收ID；注明并行项目接口及冲突处理。
2. 想法丰富/单条/空态，长廊今天空＋历史/180天旧记录，AI真实结果/发现/设置的浅深色对照。
3. 新建保存、原文返回、最近日跳转、发现依据续聊与关闭的实际操作录屏。
4. 自动检查、模拟器与真机命令/设备/日期/结果/证据路径；失败与未运行分别列出。
5. 原型差异表、未完成清单、可回退步骤；有后端变化时附发版需求和未部署限制。

“完成”要求真实数据接通、主路径点击成功、极端状态可用、必要闸门通过。若其中一项被环境阻断，交付中明确范围，不补写通过，不要求东林自行发现未实现的按钮。
