## 冻结的实施边界

1. 有圆球的首页布局、光球绘制与动效、五个模块位置、首页底部导航均保持现有契约。必要路由接线不得借机改首页。
2. 保留品牌橙、暖米底、雾蓝热力图、用户分类/习惯配色、现有数据所有权和 iCloud 同步方式。
3. 想法继续使用现有侧栏、标签/主题体系、搜索、富文本编辑器、归档、引用与分享能力；原型没有画全不代表删除。
4. 长廊继续使用现有日/周/月/时间轴、聚合口径、筛选和日期状态；不新建第二套日历。
5. HoloAI 保留对话/报告、语音、发送/停止、结果卡、证据与错误恢复。压低重复品牌装饰，不隐藏实际状态。
6. 本批默认为 iOS 呈现与只读查询改进，不新增 Core Data/CloudKit 实体，不改签名、Bundle ID、订阅权益、额度或 AI 授权。
