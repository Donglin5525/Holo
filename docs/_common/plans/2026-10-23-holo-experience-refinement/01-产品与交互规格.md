# Holo 日常体验产品与交互规格

## 1 设计目标与判定方式

本批的气质是温暖、克制、有私人记录感，操作直接。用真实原文、图片和事情建立个人感；排版和内容层级承担主要变化。

验收观察三个问题：打开想法后最先读到什么；今天没有记录时能否立刻找到一段已有内容；AI 完成一个动作后能否看懂结果并打开它。字体、圆角对齐只是基础，不据此推断留存提升。

### 1.1 页面编号

| 编号 | 页面/状态 | 对应原型 |
|---|---|---|
| T01 | 想法内容流 | 外层「想法」 |
| T02 | 浏览范围/标签主题侧栏 | 「全部想法」操作，正式版复用现有侧栏 |
| T03 | 搜索与筛选结果 | 「搜索」、正文下标签 |
| T04 | 现有想法阅读与编辑 | 轻点正文，复用现有编辑器 |
| T05 | 新建、保存与未保存返回 | 右下角新增或首条记录按钮 |
| G01 | 长廊日回放有记录 | 外层「记忆长廊」＋日常记录 |
| G02 | 今天空白但已有历史 | 少量记录状态 |
| G03 | 首次使用/加载/失败 | 首次使用与本规格补充状态 |
| G04 | 周/月/时间轴与历史日期 | 尺度切换、回到今天、日期跳转 |
| G05 | 我的积累与原记录 | 顶部积累短入口、事件正文 |
| A01 | 对话与结果 | 外层「HoloAI」 |
| A02 | 一个发现与依据 | 有效胶囊→发现→展开依据 |
| A03 | 反馈、续聊、失效 | 发现面板内操作 |

### 1.2 呈现规范

| 项 | 正式要求 |
|---|---|
| 颜色 | 全部走现有 Tool/品牌/图表语义 token。主背景 `holoToolBackground`、正文 `holoToolText`、辅助 `holoToolTextSecondary`、主动作 `holoToolAction`；不全局更换品牌色 |
| 页面边距 | `HoloSpacing.page` 20pt；原型里 26px 不直接照搬 |
| 字号 | 页面大标题 pageTitle 28、正文 body 17、辅助 supporting 15、元信息 metadata 13；动态字体随系统缩放。标题只占一次主要视觉层级 |
| 内容流 | 连续内容优先不包独立白卡；日期章节和轻分隔表达关系。独立交互面板才使用 surface，不给每个小块套卡 |
| 热区 | 所有可点击图标、标签、返回和展开至少 44pt；短文字不靠缩小字号塞入 |
| 强调 | 品牌橙用于当前操作、选中与必要提示；保留功能色及用户自选色。不要让工具按钮、标签、正文都同等醒目 |
| 弹层 | 复用 `HoloSheetScaffold`。标题/关闭、滚动内容、底部动作分区；遮罩不吞下层退出后的点击，底部不压住 home indicator |
| 动效 | 复用 `HoloMotionFeedbackCenter` 与已有按压/到达反馈。普通动作约 150–300ms 级，取项目 token；用户可继续操作，不以动画结束为提交条件 |
| 成功反馈 | 局部状态变化＋已有触觉；不用网页全局 Toast 模式。失败有明确错误与恢复入口，不把仅点击当作成功 |
| 图像 | 使用已有缩略图和附件浏览器；原型云照片只是示例，不内置到用户记录。不生成用户没有的照片/摘要 |

## 2 T01 想法内容流

### 2.1 从上到下的页面结构

1. 顶栏：最左返回首页；当前浏览范围（全部想法/标签/主题，点击进入现有侧栏）；右侧搜索。三者热区不交叠。
2. 内容标题「想法」与真实计数。内容流已经进入某个标签/主题时，范围名作为次级上下文，不再加第三层大标题。
3. 若有筛选，紧邻内容起点显示简短摘要与清除动作；不默认堆一屏可选标签。
4. 日期章节：今天、昨天、其他具体日期，按记录日期组织；跨年必须有年份。
5. 正文/图片、元信息行。正文是每条的第一视觉元素；元信息放正文之后。
6. 右下角新增按钮，避开最后一条内容、键盘与底部手势区域。

日期标题后可接细分隔线。今天用小面积品牌色标记，不能仅靠颜色表达“今天”。无内容时不要先放巨型统计、装饰插画或五个空模块。

### 2.2 分组、排序与计数

- 日期与排序沿用当前 Repository 的创建日期/置顶规则，本批不改为“最后编辑时间”。编辑旧想法不变成今天新写的记录。
- 有置顶内容时保留独立的「置顶」区域，正文外观与普通行一致；同一想法在当前列表仅出现一次。常规内容再按创建日分组。
- 日期分组在当前筛选结果形成，不能先按全库分组后在组内留空洞。相同时间用稳定 ID 次序，避免刷新时抖动。
- 原型的「N 条记录」不采用 `当前已加载数组.count` 冒充总量。已有可靠全量计数则按当前浏览范围显示；若暂时只有分页计数，写「已显示 N 条」或暂不显示数量，不能展示错误的全量数。
- 搜索时使用「找到 N 条」且计数与同一查询结果一致。计数未完成时不用 0 代替加载。
- 同步副本按业务 ID 去重；回收站不计入。归档视图继续按现有明确规则显示归档内容，本批不修改原有归档语义。

### 2.3 单条想法的内容与命中区域

| 区域 | 呈现 | 点击/长按 | 状态要求 |
|---|---|---|---|
| 正文 | 正文 token；常规最多约 5 行，长文保留可辨识的起始语境；动态字体可增加行数，不能截掉全部正文 | 单击打开同一想法的现有编辑器，初始不自动弹键盘；显式进入编辑或点正文才进入编辑 | 保留富文本、引用和正文解析，不复制只读正文到第二个详情页 |
| 图片 | 一张时宽幅预览；多张沿现有附件组件，首屏最多 3 张缩略图＋总数 | 点图片打开现有附件大图；关闭回原位置 | 只加载缩略图。坏图保留占位与记录正文，不伪造图片。纯图片想法也成立 |
| 时间 | 显示可靠的时刻；日期已在章节中，卡片内不再重复年月日 | 普通元信息不可伪装为按钮 | 没有可靠时刻不虚构为 00:00；编辑不改变原记录日期 |
| 标签 | 默认最多 2 个完整标签，其余「还有 N 个」 | 标签进入既有范围；「还有 N 个」展开这条的完整标签，可收起 | 手工/AI 标签区分遵守既有语义，不改变认可或排除规则 |
| 主题 | 需要展示时一行轻量主题入口，超长合理截断，详情可看完整 | 轻点进入真实主题详情；更改/移除留在既有菜单 | 不把主题变成装饰文字，也不在此新建另一种分类 |
| 引用 | 有引用时保留真实引用数/已有入口 | 按当前引用流程打开 | 删除或失效引用显示真实状态，不能指向另一条相似想法 |
| AI 排除 | 已排除记录保留轻量盾牌与无障碍说明 | 沿现有管理入口 | 弱化装饰不能让用户失去隐私范围的可见性 |
| 更多/滑动 | 保留归档、分享、主题管理、删除等既有动作 | 使用现有菜单与手势 | 正文、图片、标签与滑动命中互不抢占；列表根不加覆盖子控件的点击层 |

本次只读与编辑继续共用 `ThoughtEditorView`。原型“想法阅读→编辑”分两层是网页演示简化，不能据此在 iOS 新建一套详情页和第二份草稿。

### 2.4 保存与返回

| 场景 | 动作 | 成功后的可见结果 | 返回和失败 |
|---|---|---|---|
| 从列表新增 | 点新增，打开现有编辑器并聚焦 | 保存一条新记录，关闭编辑器后定位该 ID 所属日期，播放一次现有到达反馈 | 保存失败留在编辑器并保留内容/附件，不增加计数 |
| 从标签/主题范围新增 | 打开编辑器 | 保持该范围现有创建/归属规则。新记录不满足当前筛选时，不静默清空筛选；给「已保存，可查看」局部入口 | 点查看才进入其实际可见范围并定位；不能错误暗示“记录丢了” |
| 编辑已有想法 | 阅读后编辑，沿现有保存链 | 更新原 ID，不增加条数，不改变创建日；返回原列表位置 | 若编辑使其离开当前筛选，移除该行并给出说明，原筛选保留 |
| 取消未保存修改 | 返回/边缘手势/关闭 | 沿现有草稿与未保存保护 | 「保存并返回 / 放弃修改 / 继续编辑」；失败仍留草稿；不能把界面关闭当保存成功 |
| 背景/进程中断 | 系统切走 | 复用已有 recovery store/自动持久化语义 | 不写第二套草稿存储，不因为新样式损坏输入法组字与恢复 |
| 返回列表 | 正常关闭阅读 | 恢复浏览范围、搜索词、筛选、顶部可见记录 ID 与偏移 | 内容被删除时定位相邻有效记录，不强制滚到顶部 |

如当前编辑器已自动保存，优先沿用已确认的保存语义，并在 E0 记录具体回执点；禁止为贴合网页“保存按钮”重写其生命周期。

### 2.5 T02 侧栏与 T03 搜索

- 「全部想法」点按复用 `ThoughtsView` 已有侧栏，不照抄原型的简化底部范围列表。左缘返回、正文区域侧栏手势、标签 chips 横滑的优先级保持。
- 搜索初始可收成顶栏文字入口；点开显示输入与取消，空关键词显示当前范围内容，不请求 AI。保留现有语义搜索/筛选的真实模式提示，本批不重新实现算法或降低已有能力。
- 搜索和标签/主题范围取交集。点搜索结果打开记录后返回，查询、结果位置和键盘收起状态保持。清除关键词不清除浏览范围。
- 顶栏「收起」的行为为退出搜索并清空搜索关键词；筛选 chip 的 X 仅清该条件；独立「清除筛选」不等于返回首页。
- 搜索零结果显示「没有找到相关想法」＋当前条件＋清除关键词/筛选入口；不能显示首次使用文案。
- 当前范围无记录显示「这里还没有想法」＋可执行动作；全库未使用显示「先留下一句话」＋新建入口。
- 首次加载/拉取失败与真正为空分开，失败保留现有可信内容并就地重试；无可信内容时显示错误，不把错误当零条。

### 2.6 稀疏与极端内容

一条记录仍采用正文排版，不放进占半屏的大白卡，不强行补齐日期或统计。纯图片、纯引用、超长标签、无标签、长文、全部置顶、归档视图必须能读。附件有两张以上时可看到总数；无障碍读出图片数量与正文，不重复朗读装饰日期线。

## 3 G01–G05 记忆长廊

### 3.1 顶部与范围

保留现有「日历 / 洞察」两种页级视图。日历视图包含轻量「我的积累」入口、统一日期章节与日/周/月/时间轴。积累入口不再是一张与内容竞争的大统计卡；个人页积累详情仍复用现有页面。

原型右上角「洞察」只弹一个转向 HoloAI 的说明，是演示占位。正式版必须打开原有洞察阅读能力，并与独立「Holo 记忆」项目接线，不能删除报告、理解内容或把管理内容再堆回长廊。

### 3.2 默认打开与焦点日期

- 用户从普通入口新开长廊，沿现有默认日尺度、今天日期；从来源/日期深链进入则尊重其明确目标。
- 同一会话切换日历/洞察、进详情再返回，保留尺度、模块筛选、待办时间维度、聚焦日与滚动位置。
- `focusedDate` 是唯一日期事实源。周/月/日切换围绕同一天派生，不各维护一份 selectedDate。
- 跨过午夜：用户正在读历史不跳走；返回到今天或重新普通进入时使用当前系统今天。时区与历法沿项目日期口径，不把所有记录统一按 UTC 截断。

### 3.3 G01 今天有记录

今天的具体记录紧接章节头出现，不额外放“最近记录”推荐卡。内容沿既有 `CalendarDayPresentation` 的块/时刻组织，按现有日回放“新到旧、无可靠时刻沉底”的顺序，不照抄网页时间正序。

想法突出原文/图片；账目突出事项和真实金额；完成任务突出具体任务；习惯显示真实记录。已存在的相邻聚合、同分钟账目、模块筛选继续生效。金额、单位、收入/支出方向不能为审美弱化到看不清。

### 3.4 G02 今天空白但有历史

这是本批重点。保持今天章节，展示「今天还没有留下记录」与「记下此刻」；紧接一段可点击的历史预览。空态按内容自适应，不能继续用近一屏 minimumHeight 把历史挤出首屏。

| 部件 | 正式行为 |
|---|---|
| 标题 | 「最近留下的一段」，紧随具体日期；跨年带年份 |
| 预览 | 最多一段真实原文或一项真实事件，常规 3–5 行；有图片可显示一张缩略图；来源类型可辨识 |
| 选择 | 先找最近有合格记录的业务日，再从该日选可读内容。想法原文/照片优先，其次完成事项、习惯记录、账目；均无条件才不展示。不能拿“更文艺”代替日期最近 |
| 点预览/回到这一天 | 同时调用现有聚焦/加载/章节定位流程，进入那个日期的完整日回放；不是直接替换“今天”页并切断时间河 |
| 点预览内部明确原记录入口 | 经现有来源解析打开该记录，关闭回到长廊原预览位置 |
| 回到今天 | 使用既有动作回今天，已选模块筛选保留；今天仍为空时再次呈现准确空态 |
| 历史日期空白 | 文案「这天没有留下记录」。可提示此前最近有记录的一天；只查该日之前的日期，不能用未来记录填进去。没有更早记录时提供选其他日期/回今天 |
| 全局历史不在缓存窗口 | 执行独立的有界索引/Repository 查询寻找最近日期；不能把 ±20/60 天窗口为空判断成全库没有记录 |
| 部分模块失败 | 明确当前资料未取全。可展示已知真实内容并说明「部分记录暂未加载」；不能称其为全局最近或把总数说完整 |

预览是当前范围的真实内容导航，不新建「每日故事」库，不调用模型，不按心情生成一句话。它可以与完整日章节共享同一事实，但不再叠加最近日子横向卡片、日报或另一组概览。

### 3.5 G03 状态矩阵

| 状态 | 呈现 | 动作与禁止误判 |
|---|---|---|
| 正在首次取数，无可信快照 | 保留顶栏/日期，内容区域轻量加载 | 加载完成前不先闪“没有记录” |
| 已确认全库无合格记录 | 「生活慢慢写，这里慢慢有内容」＋简短说明＋记一条想法 | 如果有模块未加载成功，不能使用这个状态 |
| 今天无记录，最近日期查找中 | 今天真实空态＋历史预览位置轻量加载 | 不阻止记下此刻或切其他日期 |
| 只有很久以前一条记录 | 显示它真实日期/内容，允许跳转 | 不要求满 7 天/30 天才出现，不显示过期的“正在积累”占位 |
| 空筛选 | 「这个范围内没有记录」＋清除筛选 | 不清除用户范围去展示其他模块内容 |
| 部分失败、有旧内容 | 旧内容保留，失败提示/重试就地出现 | 已知快照不是实时全量；标签措辞准确 |
| 查询全部失败、无可信内容 | 明确加载失败＋重试 | 不显示 0 天，不显示全库无记录 |
| 来源删除/移入回收站/权限变化 | 移除受影响预览并重新选择 | 绝不继续用已失效缓存正文；跳转二次检查 |
| 切日期请求被后来的请求覆盖 | 只接纳与当前日期/筛选版本匹配的结果 | 不把上一日迟到内容显示在今天标题下面 |
| iCloud 下载中 | 保留已知结果并标同步状态 | 不因为瞬时无数据判空，不播放“重新积累”动画 |

### 3.6 G04 四种尺度

| 控件 | 操作 | 保持与变化 |
|---|---|---|
| 日 | 切至日回放 | 围绕聚焦日期；保留既有连续章节与过去方向，翻页追加在底部 |
| 周 | 切至聚焦日所在周 | 默认周起点沿现有设置，不硬编码周一；点某日先在周内选择/预览，已有“进入日回放”动作才切日 |
| 月 | 切至聚焦日所在月 | 继续雾蓝色阶；点日期更新下方当日预览，沿现有「回放这一天」进入日。网页“点月历直接切日”不照搬 |
| 时间轴 | 进入已有 0–24 小时时间轴 | 展示现有任务时段/系统日程及已有来源，不替换成网页几条记录的竖线。未来安排继续按既有合法范围可达 |
| 日期标题/选择日期 | 打开现有日期选择器/时间门 | 尊重现有手势与可选范围；不硬编码 2026 年 10 月或禁止所有未来时间轴 |
| 回到今天 | 聚焦今天并必要时取数/定位 | 不重置模块筛选和待办时间维度；连续回看上界仍是今天 |

日/周/月中的“没有记录”文案必须只描述数据，删改「这一天很安静」等根据空数据推断生活状态的措辞。

### 3.7 G05 积累和详情

- 顶部短入口由 `HoloGrowthService` 的同一可信快照提供数据，不复用原型“想法日期去重”的简化天数。计数口径与既有“我的积累”一致。
- 查看积累进入已有总览/单项/里程碑，返回保留长廊现场。未使用模块不堆零；同步/失败使用既有状态，不在本包另起成长系统。
- 想法来源进入现有编辑器，初始不自动弹键盘；账目/任务/习惯走既有详情，按钮文案只承诺当前真正能到达的层级。
- 若现有习惯解析只能到习惯详情，写「打开习惯」；需要落到某日记录的动作必须额外携带业务日/记录 ID。不能用详情首页冒充“已定位该次打卡”。
- 来源已删除/当前不可访问：在当前界面说明并允许返回；不自动恢复记录、不打开相似记录、不失去筛选。

## 4 A01 HoloAI 对话与结果

### 4.1 顶部与消息层级

顶部使用既有标题 token 展示「HoloAI」。保留返回、对话/报告切换、会话历史等既有功能。与独立记忆管理项目协调后，右侧优先安排「记忆」「设置」；大字体拥挤时设置进入现有更多菜单，记忆仍可发现且点击域不相撞。

普通助手回答不再重复堆头像＋Holo 名称＋AI 徽标。页标题/会话上下文清晰标识 AI 身份；每段回答仍给 VoiceOver 正确的发言者。错误、思考/执行中、工具执行结果、引用与确认状态不能一起隐藏。

用户消息、助手正文、结果卡、输入区形成清楚顺序。普通回答以正文为主；真正的账/任务/习惯结果以其事实为主。聊天文案与人格不属于本批 Prompt 改造。

### 4.2 动作回执与来源

| 状态 | 画面 | 可操作性 |
|---|---|---|
| 模型识别出拟写内容 | 显示识别结果/待确认 | 保留核对/确认，不写“记下了” |
| 业务写入进行中 | 明确执行中 | 防止重复提交；仍可停止模型输出或按原规则取消 |
| Repository 确认写入 | 现有结果卡强调事项、金额/日期、真实分类 | 查看该记录，保留现有纠错/编辑/删除入口 |
| 多动作部分成功 | 每项分别显示真实状态 | 不能用一个“已完成”掩盖失败项或遗漏第 N 项 |
| 写入失败 | 本项失败原因与恢复动作 | 不增加账目、不把失败消息渲染为成功卡 |
| 旧消息关联内容变化 | 历史卡反映当时回执，进入时解析当前实体 | 编辑后金额变化不重写旧聊天事实；可说明当前记录已更新 |
| 原记录已删 | 历史回执保持有界说明，入口显示不可用 | 不从旧 extractedDataJSON 恢复当前可编辑实体 |

财务仍使用 Decimal 与现有币种/格式器，不能硬编码人民币、两位小数或用浮点字符串代替真实金额。网页例子只说明信息主次。

### 4.3 输入与能力行

- 输入区保留文本、多行、语音、发送/停止、权限/额度状态。原型省略的按钮不是下线授权。
- 深度分析、周期回放、规划目标继续走现有流程。能力行用轻背景/描边或文字降低强调，主操作与正文更突出；窄屏可横滑，不能挤成肉眼难读小字。
- 「一个发现」沿冻结位置在深度分析之后、周期回放之前；有有效内容才出现。未开启、准备中、无合格内容、过期、失效均无占位胶囊、红点和数字。
- 打开/关闭设置、记忆管理、发现详情或报告，不覆盖会话草稿，不改变当前输入法状态，不主动发送或取消进行中的规划。
- 点击空发送的处理沿原输入器；原型“先写一句话”Toast 不迁入正式版。

## 5 A02–A03 一个发现

本章规定本批呈现与接线要求。发现的授权、数据源、调度、AI 生成、核验、成本、生命周期与反馈规则，继续以独立 Discovery 实施包为真源。本次不新增“已核验”徽标、评分、通知或个性画像。

### 5.1 胶囊与详情

| 状态/动作 | 交互规定 |
|---|---|
| 有效未读 | 轻量淡橙胶囊，固定文字「一个发现」，不展示敏感摘要 |
| 读过且仍有效 | 普通低强调样式，可重读 |
| 点击 | 调服务读取当前有效结果，不点开后才做全量分析。无有效结果时收起入口/说明失效，不能用缓存假内容填满 |
| 详情 | 底部阅读面板；标题「记录里的一个发现」→观察标题→解释与必要限制→依据入口→反馈→聊聊这个→管理链接 |
| 初始高度 | 使用现有 medium/large detents；正文和动态字体增大时能滚动/扩展，底部动作不盖正文 |
| 展开依据 | 在当前面板展开真实独立来源；可收起，计数由服务提供，不根据 UI 段落数凑 N |
| 打开来源 | 显示真实日期/类型/摘录；解析有效原记录后进入。返回回到同一发现与展开位置 |
| 阅读中来新发现 | 当前内容稳定；退出后才更新。来源失效/撤权例外，必须立即撤下原文 |
| 手动关闭/下拉 | 仅结束阅读；不推断赞同、否定或喜好 |

### 5.2 反馈

- 「有点像」：调用真实反馈服务，成功后面板内显示已收到；失败有可重试状态。不会自动写入长期记忆或把全部相关候选变成已确认。
- 「不太准确」：先在本地撤下此候选并写最小否定，再可选原因。用户点「暂时不说」仍必须保留已撤下与最小否定，不能因为未选原因重新出现。
- 四原因：依据不对 / 理解不对 / 现在不适用 / 不想看这类。语义、抑制范围、恢复按 Discovery 协议；反复点击幂等，不产生多份否定。
- 否定面板退出回原会话，输入草稿保持。已隐藏列表只管理相关偏好，恢复偏好不立即复活已失效内容。
- 当前 `DiscoveryDetailSheet` 注释仍提示“暂时不说无法落最小否定”的接口缺口。实施者须核对最新实现；若仍存在，转 Discovery 项目补齐并附回归证据，不能只改文案或本地 hide 标志宣布完成。

### 5.3 续聊与草稿

| 前置状态 | 点击「聊聊这个」后的行为 |
|---|---|
| 无草稿、可续聊 | 构建可编辑草稿，携带当前有效的发现 ID/版本和限定来源上下文；输入区显示对象与来源范围；不自动发送 |
| 已有草稿 | 提供「保留原草稿 / 替换为发现讨论 / 取消」；保留原草稿时内容不变，也不静默加上发现上下文 |
| 正在规划/有待确认草案 | 走独立包已定的新会话/保存现场方案；不偷偷丢弃现有规划 |
| 草稿存在但来源已失效 | 发送前重新核验；不带失效正文。保留用户输入文字，说明相关依据已不可用，允许移除上下文后普通发送 |
| 用户点上下文 X | 清除仅本次的来源上下文，保留用户已写文字；不关闭全局发现功能 |
| 设置里关闭发现/撤权 | 立即停止采纳派生内容，清除仍引用它的上下文，保留用户自己的草稿文字 |

续聊沿普通聊天授权与额度，不偷切深度分析。真正进入深度分析时使用现有显式模式与确认流程。

## 6 A04 设置与独立记忆管理

直接复用 `HoloAIUserSettingsView` 及原子页，不照抄网页的假开关/每次默认勾选值。正式入口同时存在于对话设置和系统设置→HoloAI，二者共享状态。

| 条目 | 点击后 | 返回后 |
|---|---|---|
| 一个发现 | 现有发现设置子页 | 胶囊/状态实时同步，未开启不暗示已有分析 |
| 首次开启 | 校验 capability/主体→已有总授权（如缺）→解释＋来源选择→明确确认→真实控制完成 | 未选来源、取消、失败均保持关闭；生产首次来源不预选 |
| 允许来源 | 修改本功能来源；增加需明确确认，缩小使受影响候选失效 | 不改想法全局排除键或长期记忆开关 |
| 关闭 | 本机立即生效，按独立包执行清理/取消与服务端禁用 | 原记录保留；离线也先隐藏，不等待网络成功才关闭 |
| 个人档案 | 既有编辑器，展示原值 | 真保存后回显；不复制新昵称字段 |
| 记忆 | 对接独立「Holo 记忆」管理/记忆设置子页 | 自动形成记忆、辅助回答开关沿原键和值；保留其冻结文案与能力边界 |
| 想法智能整理 | 既有设置页 | 不把改样式变成默认开启后台处理 |
| 周期回放 | 既有生成与通知各自设置 | 自动生成不等于提醒；不重复注册通知 |
| 数据授权/不参与 AI/处理说明 | 正式用户页 | 不暴露 Debug Provider、Key、温度、Token、Prompt |

后端不支持/服务不可用时，发现设置准确显示暂不可用，功能不能假开启。样式改造和其余两个页面可独立交付。

| 原型控件/逻辑 | 正式实现 |
