Holo · iPad 版全面重构 · 原型总入口

2026-11-14 · v1.1 · 全模块产出 · 东林验收包

目标：让 Holo 的 iPad 版达到可对外交付的水准。本包是第一阶段产物——全部模块的 iPad 高保真原型（横竖屏 + 键盘态 + 最惨稀疏态），按「原型即契约」惯例，东林确认后逐模块 1:1 落进 SwiftUI。功能一项不删、一页不漏，覆盖度以页面功能底表为账本逐项打勾。

设计方向：把 Holo iPad 版做成「摊在桌面上的生活工作台」——手机上「一页一事」，iPad 上「一屏一事一上下文」：任何对象打开时，它的清单、上下文和下一步动作同屏常驻。
保留：光球（永转）· 品牌橙 · 暖纸 Tool 色板 · 卡片语言 · 44pt 热区 · 全部功能。重构：导航密度 · 列表-详情 · 弹层策略 · 键盘 · 横竖屏。规则细则见 01-设计语言与布局规则.md。

横屏 1194：侧边栏 232 + 内容 962 → 宽档·双栏
竖屏 834：图标条 68 + 内容 766 → 标准档·单列限宽
13" 竖屏 1032：图标条 68 + 内容 964 → 宽档·双栏
  • 宽档 ≥1024（实得宽度）：列表 360 + 详情右栏，切换对象只刷右栏，正文限长 640。
  • 标准档 680–1023：单列内容限宽 720 居中；网格/看板 2 列。
  • 窄档 <680：单列，与手机同构。
  • 竖屏侧边栏：收成 68pt 图标条（内容优先）【拍板点 P5】。
  • 旋转/分屏：只换布局档位，不清空选中、筛选、草稿、聊天现场。
  • 深链 28 条：先选中侧边栏目的地，再落到模块内位置；逐条对照表随验收包交付。
