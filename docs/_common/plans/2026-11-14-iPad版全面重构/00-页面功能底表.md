# Holo 页面功能底表（iPad 重构覆盖度核对用）

> 产出：2026-11-14，由只读代理对代码全量盘点得出（五处源头交叉：常驻模块栈 + HomeView 弹层 + Settings 树 + Chat 弹层枚举 + DeepLinkTarget）。
> 用途：iPad 重构「功能不删减、页面不遗漏」的核对底表。每个模块的原型完成后，逐项对照本表打勾。
> 路径约定：相对路径位于 `Holo/Holo APP/Holo/Holo/`（下称 ROOT）。

## 一、壳层与主导航结构

1. **App 外壳**（ROOT/HoloApp.swift）：`WindowGroup → ZStack{ ContentView + AppLockOverlayView(应用锁闸门) }`；根部另挂两个全局 fullScreenCover：`HoloPlusPaywallView`（付费墙，全局协调器触发）与 `CSVQuickImportView`（外部"打开方式/拖拽"导入 CSV/TSV/XLSX/ZIP）。DEBUG 分支可替换根视图。
2. **iPad 系统菜单栏**（HoloApp.swift 内 `HoloIPadCommands`）：「前往」⌘1–⌘8 模块直跳、⌘9 个人、⌘, 设置；「文件」⌘N 新建、⌘W 关闭当前模块；「编辑」⌘F 当前模块搜索。经 `HoloShortcutBus` 广播，iPhone 外接键盘同样生效。
3. **主导航**（ROOT/ContentView.swift）：compact（iPhone）= 三主 Tab（今天/对话/我的）；regular（iPad）= **v2 侧边栏骨架** `HoloSidebarView`，10 个目的地：今天 / 想法 / 财务 / 任务 / 习惯 / 记忆长廊 / 健康 / AI 对话 / 个人 / 设置；底部「快速记录 ⌘N」按钮与收起/展开（常驻 232pt ↔ 窄条 60pt）。右侧宿主是 `HomeView`。
4. **模块宿主**（ROOT/Views/HomeView.swift）：7 个常驻全屏模块 `ActiveScreen`（ai/finance/habits/tasks/memoryGallery/health/thoughts）挂 ZStack 常驻栈（`ResidentScreenRouteStack`），切换不销毁、保滚动与聊天现场；设置/个人在 iPad 为页面层（非弹窗），iPhone 为 sheet。今日看板为 fullScreenCover。
5. **深链系统**（ROOT/Services/DeepLinkState.swift）：`DeepLinkTarget` 28 个 case，覆盖通知点击、小组件 `holo://` URL、AI 卡片跨模块跳转、报告证据核对等。
