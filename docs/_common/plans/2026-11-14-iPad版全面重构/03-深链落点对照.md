# Holo iPad 版 · 28 条深链落点对照表

> 规则（01 设计语言 §6）：**先确保目标模块在侧边栏选中 → 再落到模块内正确位置**。宽档（≥1024 实得宽度）下对象类深链落在右栏详情；标准/窄档落 push 详情页。旋转/分屏不清现场。
