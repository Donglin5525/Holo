## 四、最后一公里的解剖（五层修复史 + 当前断点）

链路：`promoteEligible → makeRecord（翻译 HoloMemoryRecord+payload）→ applyObservationBatch → upsertRecord（✅record 表实证有行）+ HoloKnowledgeIngestion.ingest → HoloKnowledgeAdmission.assess → 通过则 upsertKnowledgeRevision（写 ZHOLOMEMORYKNOWLEDGEREVISIONMO 表）→ resolver（resolvedKnowledgeAll）算 decision 档 → 记忆中心 ViewModel 过滤展示`

已修的五层（每层都有真机实证拒因）：
1. 触发通道：`devicectl launch -e` 传环境变量间歇失灵 → 改 XCUITest launchEnvironment（可靠）；注意 App 每次装包/测试后 CoreDevice 通道常崩（ecid 1011 错），需拔线重插
2. `catch { return nil }` 吞错 → makeRecord 改 throws，四类拒因进浮层文案（PromotionError）
3. **过期误判**：payload.temporal.validTo 和 record.validTo 曾填「最后证据时刻」，而知识系统语义=「适用期终点」（isExpired 首条 validTo<now 即弃）→ 修为 ongoing 不填终点
4. **跨域身份**：`makeStableID` 的 .domain scope 要求 `sourceDomains == [primaryDomain]`（戒烟主题含打卡+想法跨域成员被拒 invalidDomainScope=NSError 错误2）→ 修为按主域单域登记
5. **准入模板闸**：直出候选曾归 epistemicStatus=.inferred → formation=behavioralInference → `assessInference` 要求 evidence.templateID 非空（guard else internalOnly .templateNotRegistered）→ 修为直出候选（契约=statement 含「习惯进行中」且 phaseState）归 .observed → formation=sourceLinked

**当前断点（未实证，两个候选）**：
- **候选 A**：observed→sourceLinked 后 Admission 走 `sourceLinked` 分支（HoloKnowledgeAdmission.swift ~66 行）：`if evidenceForm == .independentEventSet, independentEventCount < 2, !windowRule.isBounded → internalOnly(.routineFlowWithoutValue)`。直出候选的 evidenceForm 推导在 HoloKnowledgeIngestion.evidenceForm(for:)：phaseShift claimKind → `.sampledNumericSeries`——不撞 independentEventCount；但 independentEventCount 来自 evidenceSnapshot(from:record)——若为 1 或 0 也可能走别的分支。**需要拉库看这轮 revision 写没写**（写了→断在 resolver；没写→断在 Admission 某分支）
- **候选 B**：revision 写了，但 resolver（`CoreDataHoloMemoryRepository.resolvedKnowledgeAll`）算出的 decision 不是 `worthConfirming` 也不是「已记住」侧的 `confirmedValid`（比如落 `internalAccumulating`/`remembered`——记忆中心 ViewModel 只显示 worthConfirming 和 confirmedValid 两档，`HoloMemoryCenterViewModel.swift` ~455-465 行）。若落 remembered 档，需要决定产品上让它进哪个分段（记忆中心「已记住」顶部=confirmedKnowledge 分组）
