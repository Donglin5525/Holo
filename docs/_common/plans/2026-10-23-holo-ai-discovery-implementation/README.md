## 1. 一句话目标

AI 在用户明确开启后，提前理解获授权的记录，经过反例检查与逐句核验，安静地展示一条具体、可追溯、可纠正的发现；同时把分散的 HoloAI 用户设置统一到正式设置页。

**质量优先于产出率：可以没有发现，不能用流畅的话掩盖证据不足。**

## 3. 已确定的产品／实现决策

| 决策 | V1 必须执行 |
|---|---|
| 入口 | 「一个发现」替换「今日状态」；深度分析、周期回放、规划目标保留 |
| 自动理解 | 开启后提前生成，点击读缓存；不在点开时才做首次全量理解 |
| 用户选择 | 默认关闭，首次明确同意；至少选择一类来源 |
| 首发数据 | 想法、任务、习惯；不直接读财务账目、HealthKit、日历、相册或聊天全文 |
| 长期记忆 | V1 不读取或写入长期记忆；不依赖自动记忆或记忆辅助回答开关。更广上下文留后续独立评审 |
| AI 主链路 | 本地材料与检索 → 一次候选生成 → 本地反例召回 → 一次独立核验 → 本地发布；无候选时只一次调用 |
| 真实性 | 原文或确定性事实支撑，模型自评分不做发布依据；数值由代码算 |
| 输出 | 每次最多一条有效展示；首版类型为两次经历的联系、有限情境重复、两时段变化 |
| 原始记录 | 本地只读。发现、反馈、临时索引存新本机 store，不加入业务 CloudKit 模型 |
| 敏感边界 | 不主动发布医疗／心理诊断、亲密关系、财务困境等敏感推断；用户选想法不等于授权读其他领域 |
| 干扰 | 无通知、无红点、无角标、无自动弹窗、无循环换一批 |
| 反馈 | 认可不自动成为人格记忆；否定立即撤下；浏览与关闭不推断偏好 |
| 次数与成本 | 与用户主动聊天／深度分析／回放次数分离；纳入后台总成本硬闸。V1 首发两种会员档均每日最多一个自动批次 |
| 多设备 | 后端控制代数与单设备生成租约，设备本地显式开启；V1 同账号同时只允许一台设备准备发现 |
| 设置归拢 | 正式用户 HoloAI 设置页；旧页面入口指向同一子页、状态源，Debug 配置仍内部使用 |
| 服务不支持 | 后端 capability 不可用时解释未开放，不偷偷走普通 chat 模拟发现 |

**相较早稿的工程收敛：** V1 完全不消费长期记忆，避免未经验证的上游摘要和记忆开关语义影响发现；“可以复用记忆基础设施”只指实现方法／工具，不指直接把记忆条目当发现。

## 4. 实施阶段：完成一个阶段再进入下一个

| 阶段 | 任务 | 通过证据 |
|---|---|---|
| G0 | 重新盘点数据、授权、现有设置、当前改动与部署版本 | 源码位置表、字段映射、阻塞项、设置状态基线 |
| G1 | DTO／schema／本地 store／权限纯逻辑／合成材料读取 | 契约与权限测试，schema 正反例，零真实数据写入 |
| G2 | 取数、召回、反例、源版本失效、去重 | 原文往返、事件独立性、反例可检索、删除失效测试 |
| G3 | 后端控制、单设备租约、两阶段接口、成本与日志隔离 | 路由与身份、CAS 撤权、幂等竞态、预算、隐私日志测试 |
| G4 | 两个 Prompt、语义核验、本地发布策略 | 合成集与真实配置模型试评记录；mock 通过不代表 AI 通过 |
| G5 | 统一设置、胶囊详情、反馈、续聊、原偏好迁移 | Release 可达、各状态可操作、无双存储与双通知 |
| G6 | 调度、断网、后台、取消、重启、多设备、性能与成本 | 端到端运行记录和中断／撤权证据 |
| G7 | 有范围的交付与部署准备 | 闸门全通过，后端能力识别、新旧版本兼容、回退验证 |

阶段是依赖顺序，不是省略质量的开关。G5 漂亮但 G4 不通过，不能宣称本功能完成。不能以“临时模板返回一个发现”“永远返回空数组”通过验收。

## 5. 必须继续验证、但已有明确默认的事项

- 首发阈值、预算、窗口按本包初值实现为可注入策略常量，先测再调；不做用户设置项。
- 模型沿后端当前可用路由配置选择，通过试评再冻结；本包不依据旧注释指定某个商用模型。
- 测试账号无稳定的服务端登录主体时，只能通过 mock 验证，不能伪称账号跨设备控制完成；正式开启要求有效 Holo 登录主体。
- 若某个来源缺少变更版本或可靠删除通知，先补齐变更适配器；不能省略就绪复核。
- V1 不承诺原始数据零上传：开启说明必须解释必要片段将交给外部 AI；不宣称端侧模型推理。
- 已发给第三方的请求不能撤回为“未发生”；关闭时必须停新请求、尽力取消、拒绝采纳迟到结果。

## 6. 给 GLM 的工作要求

1. 先读 G0 指定源码及当前项目开发／Prompt／设计规范，记录现实差异后再改。历史路径和行号不是现状保证。
2. 不重置／清空用户业务库，不更改签名或 Bundle ID，不覆盖其他会话修改。新 store 独立、增量、可清理；上线回退不删业务数据。
3. 调用链、数据、权限都要真实接通；禁止用问句预填、固定文案或假来源替代 AI 主链路。
4. 提示词在服务端注册；客户端只传结构化数据。不要为新功能改通用人格前置或放开客户端自定义模型路由。
5. 每个任务回填完成／未完成／阻塞、变动文件、执行命令、结果和证据；没有跑的检查写“未执行”，不能补写成功结论。
6. **后端代码、路由、Prompt、预算或配置变化，需要部署后端才会生效。** 完成部署准备后提醒东林，部署另需明确授权；不把本地测试或推送当成生产生效。
