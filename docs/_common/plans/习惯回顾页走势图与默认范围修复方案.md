# 习惯回顾页修复方案 —— 走势图错乱与「只看到本月」（2026-10-26）

> 来源：东林 10-26 实机截图反馈（体重习惯 ·「全部」范围三连截图圈红）。
> 三个问题 + 连带 1 处误导文案，全部定位到根因。纯 iOS 改动，**免后端发版**，随 1.1.4。

## 一、根因（为什么会长这样）

### 问题 1：底部日期挤成一团（3/184/24、9/1910/26）
图由全项目共用的财务图表组件绘制（`HoloCartesianChart.swift`）。横轴日期标签有两个算术缺陷叠加：

1. 「这行能放几个标签」的预算按每个标签 44pt 计算（`HoloChartGeometry.tickIndices`：`width / max(fontSize*4, 44)`），但实际给每个标签留的框是图宽的 1/5、下限 32 上限 80pt（`tickLabels` 里的 `min(max(plot.width/5, 32), 80)`）——预算 44 < 实际框宽，导致排出的标签数超出能容纳的量，相邻标签的框互相侵入；
2. 两端标签为防出界被强制向图内收（`min(max(...))` 钳位），恰好压到旁边标签——所以呈现为「3/18 和 4/24 贴死」「9/19 和 10/26 贴死」，中间标签因文字本身窄而侥幸无碰撞。

### 问题 2：趋势图乱糟糟（断档期碎片化）
横轴是「一天一格」：3/18→10/26 共 223 个自然日铺满绘图区，每槽仅约 1.4pt。测量型数据只有记录日有点：

- 连续记录日（3 月中下旬密集段）→ 相邻点连线被压进 1.4pt 横向空间 → 视觉上成一根根「竖线」；
- 断档后的孤立记录日（5/31、7/7、8/13）→ `contiguousSegments` 只连相邻日 → 孤点、线断裂。

数据越稀疏图越碎——画法（日历槽位柱状语义）与数据形态（断续采样）不匹配，不是数据错误。

**连带交互缺陷**：223 槽下点按/拖动按「最近槽位」命中（1.4pt 精度），经常选中空日子并实时改写下方明细区（截图中选中 10/19「无记录 + 补录这一天」即误触产物）。

### 问题 3：只看到本月，9 月的数据藏起来了
数据完整（「全部」能看到 3 月以来所有点），是**默认视野**问题：

- 进页默认范围 = `.month(overviewMonth)`；从习惯列表点名称进来时容器强制 `.month`（`HabitModuleContainer.swift:182`），页面兜底也是它（`HabitSingleReviewView.initializeState`）；
- 「本月」范围下日历**没有翻月箭头**（`calendarView` 对 `.month` 范围隐藏 `calendarMonthNav`，这是 2026-10-09「显示月必须等于范围月」的既定约束）——本月之外的数据在该范围内无入口。

断续记录的数值习惯在「本月」默认下基本只剩当天一笔。

### 连带问题 4：「全部记录 82.2 KG · 还没有更早的记录」误导
该行是「本期 vs 上期」对比卡：82.2 为全部记录均值；「还没有更早的记录」本意是「`.all` 无上一周期可比」（`periodComparison` 对 `.all` 恒返回 previous=nil），但措辞读起来像「不存在更早的数据」，与问题 3 叠加后加重「数据被吞」的错觉。

## 二、改法（四处）

### A. 图表组件：刻度标签预算修正（治问题 1；财务/健康图同步受益）
- `tickIndices` 的容量预算改用与 `tickLabels` 实际框宽**同一个数**（`labelWidth = min(max(width/5, 32), 80)`；`capacity = max(2, width / labelWidth)`），不变量「相邻标签框中心距 ≥ 标签框宽」进单测锁定；
- 首尾标签贴边对齐（首个左对齐、末个右对齐），不再向内钳位互撞；
- 行为收敛：同宽度下标签数比现在少 1-2 个，不再重叠。

### B. 图表组件 + 习惯页：测量型走势改「记录点连线」（治问题 2 及误触）
体重这类测量型习惯，回顾页走势图从「日历槽位」改为「按真实时间定位的记录点折线」（Apple Health 体重同款画法）：

- 只为**有记录的日子**建 bucket，`position` 传真实时间偏移（kit 已支持连续坐标域，心率图在用；`xDomain` 对 position 桶自带 1.5% 边距）；
- 相邻记录点直接连线（跨断档也连——趋势关心变化方向，断档在时间轴上一眼可见，不造断线）；点**始终可见**（kit 加 `alwaysShowPoints` 参数，默认 false，财务不受影响）；
- 命中从「最近槽位」变「最近记录点」：点图只会选中真实记录日，拖动沿途浏览不再跳出空日子的「补录这一天」；
- 范围内仅 1 条记录时由 position 域边距自然形成呼吸位，不会画成占满全图的孤点；
- **不动**：计数型日柱（每天的量是当天事实，柱状正确）、打卡型周柱、日历、今天页 7 天小图（`sparseCollapse` 路径原样保留）。

### C. 习惯回顾页：数值习惯默认范围改「近90天」（治问题 3）
- 测量型/计数型：进页默认 `.lastDays(90)`；打卡型维持 `.month`（月历语义不变）；
- 默认值收敛到一处（`HabitModuleViewModel` 提供统一入口），当前两处各写一份（容器 182 行 + 页面兜底）一并改；
- 今天页弹层「查看长期回顾」的近 30 天入口不变（近况语义）；「全部/本月/近30天/近90天」胶囊全部保留。

### D. 对比卡文案（治问题 4）
- `.all` 范围下副行不再显示「还没有更早的记录」，改为「共 N 天有记录」类总量事实；
- 其他范围（真无上一周期，如习惯创建未满两期）保留原文案。

## 三、不动什么
首页（冻结铁律）；整体回顾页月度结构；习惯日历/周柱/今天页小图；补录、编辑、删除既有交互；财务图表一切语义（只修标签排版缺陷）。

## 四、影响面与验收标准
改动文件约 5 个：`HoloChartGeometry.swift`、`HoloCartesianChart.swift`、`HabitSingleReviewView.swift`、`HabitModuleViewModel.swift`、`HabitModuleContainer.swift`。

1. 「全部」范围横轴标签互不重叠（最挤场景单测锁定不变量）；
2. 断续记录的测量习惯：趋势为一条连续点线，无「竖线段」伪影，点全部可见；
3. 点/拖趋势图只命中真实记录日，下方明细不再落到空日子；
4. 数值习惯进页默认近90天，9 月与 10 月数据同屏；「全部」下对比卡无误导文案；
5. 财务统计三页 + 健康图回归走查：标签不重叠、数量 ≥4、其余视觉无变化；
6. 单测三组全绿（刻度不变量 / 记录点布局 / 默认范围）；模拟器五大入口走查过闸门后交东林真机验收（体重习惯实测）。

## 五、拍板与实施记录（2026-10-26）

**东林拍板**：按方案实施；默认范围**不走固定时间窗**——改为「最近记录」档（最近 30 个记录日的窗口），保证低频习惯（半年一记）也能一屏看到最近一批记录，不假设记录节奏。

**已落地（本分支未提交，随 1.1.4）**：
- A 刻度标签：`HoloChartGeometry.tickIndices` 预算改与实际框宽同源（`tickLabelWidth`），首尾贴边对齐；新增 `tickIndicesForPositions`（position 域按像素最小间距贪心取刻度、末桶必留）
- B 测量型走势：`ReviewTrendChartLayout.measurePositions` 记录点布局 + kit `alwaysShowPoints`；点即数据、连线贯通断档、命中只落真实记录日
- C 默认范围：`HabitReviewRange.recentRecords(count:)`（30 记录日）+ `HabitModuleViewModel.defaultSingleReviewRange(isCheckIn:)` 统一入口；打卡型维持本月；数值型胶囊条 = 本月/最近记录/全部
- D 对比卡：`.all`/无上期语义改为「共 N 天有记录」；追加修「前 0 天」（previousLabel 拿真实窗口长）与「上期均值 0」→「上期无记录」（均为走查实锤的同族文案）
- 三语词条：最近记录 / 共 %lld 天有记录 / 上期无记录（文本级插入），孤儿词条「还没有更早的记录」已清
- 单测 60 绿（投影 38 + 图表几何 22，含刻度预算不变量/记录点布局/最近记录窗口五例）；模拟器走查判读 7/7 PASS（默认态/点按命中 7/7/全部/日历/财务总览图）

**验收通道**：单测已绿 + 模拟器判读过；待东林真机验收（真实体重数据）。装真机包前照旧过五大入口全量走查。
