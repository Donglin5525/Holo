# 07 · 预算墙（2026-11-21 东林拍板）

## 决策

- **免费用户：每周 1 条**洞察；用完当周额度后，评审页「今日一条」区块展示升级引导卡。
- **Plus 用户：每周 5 条**（自然上限本就是每天最多 1 条且宁缺毋滥，5 条≈实际不限，具体数字利于售卖页表达）。

## 实施口径（对拍板的两处修正，均已向东林说明）

1. **计数按「实际送达的卡」**，不按请求：none_worthwhile / gate_rejected / disabled / quota_exhausted 的响应不烧名额——否则免费用户某天模型没产出（设计内行为）会白烧当周唯一额度，撞墙却一张卡都没见过。
2. **撞墙不回落 v3**：墙是成本墙+权益墙双重语义，回落即破功。iOS 收到 `quota_exhausted` 后不出卡、只做当日展示标记。

## 技术口径

| 项 | 实现 |
|---|---|
| 计数权威 | 服务端（防重装绕过）；新表 `insight_deliveries(device_id, delivered_at)`（自迁移，无内容） |
| 窗口 | 7 天滚动（对外说「每周」），撞墙检查在模型调用**之前**（零 token 成本） |
| 参数 | env 可调：`HOLO_DISCOVERY_INSIGHT_FREE_WEEKLY`（默认 1）/ `HOLO_DISCOVERY_INSIGHT_PLUS_WEEKLY`（默认 5）；置 0 = 不限（排查用） |
| 层级判定 | entitlementResolver（Plus 覆盖表与生产同源） |
| 响应契约 | `noneReason: "quota_exhausted"`（与 disabled/gate_rejected 同族，selected=null，HTTP 200） |
| iOS 行为 | 不回落 v3；TopicStore 记当日墙标记；「今日一条」空位展示 `DiscoveryQuotaWallCard`（了解 Holo Plus → `HoloPlusActionCoordinator.requirePlus(context: .discoveryInsightWeekly)`）；「等你确认」列表照常（本机免费） |
| v3 存量卡 | 照常消化（成本已付、展示零边际成本），不额外挡 |
| 日志 | ai_call_logs gate.quota {used, limit, tier} |

## 测试

- 后端 4 例：免费超额零上游调用 / none 与 gate_rejected 不烧名额 / Plus 第 6 条撞墙 / freeWeekly=0 不限（841 全量绿）。
- iOS：墙标记当日有效、次日重探（13/13 绿）。
- 跨端：quota_exhausted 已入契约注释族；端到端墙展示待真机验收（免费层行为，东林设备走 Plus 桶，需用免费层级设备或临时改 env 验证）。
