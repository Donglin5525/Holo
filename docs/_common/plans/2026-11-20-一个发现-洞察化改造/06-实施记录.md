## 四、实施中发现并修复的坑

1. **数字纪律字符集误杀（双端同修，从 v3 继承的坑）**：v3 的单字符集含裸「之/几/分」，「**比之前**更晚」「**几乎**每次」「**部分**」整句被误判含数字——实测 `入睡时间比之前更晚` 命中之(U+4E4B)。v4 判断句高频用「比之前」，双端（insightGate/InsightNumberDiscipline）改为：裸字符集去三字+补「半」、复合模式「几分之」。测试向量双端同步加反例。v3 controller 未动（其模板已避开该模式，冻结语义）。
2. **uniqueKeysWithValues 守门拦截**：Service 里两处被 BannedAPI Guard 编译期拦下（iCloud 副本重复 id 抛 ObjC 异常红线），已改 first-write-wins 循环。
3. **`defer` 关键字 / 模板缩进 / private 可见性**：三处常规编译错，均已修。
