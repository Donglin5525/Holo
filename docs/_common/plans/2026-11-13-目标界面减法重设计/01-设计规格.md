## 〇、方向选择

| 方向 | 一句话推演 | 结论 |
|---|---|---|
| 一「档案卡墙」 | 每目标一张带进度环的大卡，双列网格，视觉重 | 落选：目标多时密度爆表，进度环在列表场景是装饰不是信息 |
| 二「账本式纯行」 | 保持行式，只加分组和微进度条 | 落选：仍是文字堆砌，层级没立起来，解决不了「丑」 |
| 三「轻卡 + 单进度条」 | 单列轻卡片，领域图标做视觉锚点，量化目标配一条 4pt 进度条，状态用胶囊 | **选定**：与模块既有 GoalJourney 字段语言（12 圆角 / 0.5 描边 / action 色）同构，密度适中 |

表单方向：从「字段表格」改为「一句话开头」——大号无框输入开场，类型三选卡，条件字段按类型浮现，可选字段全部删出创建流。

## 一、诊断（现状问题清单）

**列表页**
1. 目标行是纯文字行（标题+摘要+状态字+箭头），无图标、无进度、无视觉锚点——「一堆文字」的直接来源。
2. 状态用文字（进行中/已完成/已暂停）混排在一列，无分组无筛选，扫读成本高。
3. 空态堆了 1 个主按钮 + 2 个下划线链接，三处入口抢注意力。
4. 摘要行的防御性占位（「正在读取进展」「进展暂时无法读取」）是内部状态词，不该见人。

**表单（重灾区）**
5. 四段平铺说明文：「以现在为起点，之后记录当前水平，进度按…计算」「按全账本净结余计算（含信用卡负债）」、类型 descriptor 常驻、口径错配橙色长句——全是替用户思考的作文。
6. 11 个字段全部平铺展开：说明/期望结果/动机/图标/AI 上下文五个可选项占了半屏，创建目标只需「名字+数字」。
7. 「目标说明（可选）」「为什么要这个目标」占位符是说明书腔。
8. 「目标信息」卡片头 + 分隔线是无信息的装饰 chrome。
9. 达标型的「基线」概念用文字解释，其实「75 → 70」一个箭头就能画清楚。

## 三、屏幕 A：目标管理列表页

### A0. 文案稿（成稿）

| 位置 | 文案 |
|---|---|
| 导航标题 | 我的目标 |
| 新建菜单（右上 +） | 一起想清楚（lightbulb）／ 让 HoloAI 规划（sparkles）／ ——分隔线——／ 手动创建（square.and.pencil） |
| 恢复条 | 有一个想到一半的目标 ＋ 原文一行 ＋ 继续 ＋ 右侧小 X（点击=放弃这个想法，废弃共创会话、条消失） |
| 分段 | 进行中 ／ 已完成 |
| 卡片状态胶囊 | 待回顾 ／ 已暂停 ／ 已完成 |
| 卡片数值行（累积型） | 128 / 300 km |
| 卡片数值行（达标型） | 已减 2.5 / 5 kg（目标大于基线时「已增」） |
| 卡片摘要行（过程型） | 取真实回顾数据（如「3 / 7 天已确认」）；无数据时整行不渲染 |
| 期限 | 12/31 截止；过期显示 已到期（警示色） |
| 空态标题 | 想先做成什么？ |
| 空态副文 | 一句话，捋成能走的目标 |
| 空态主按钮 | 和 Holo 一起想清楚（共创开闸时）／ 让 HoloAI 规划（关闸时） |
| 空态文字链接 | 或让 HoloAI 规划 ／ 手动创建（各一条，13pt 下划线） |
| 错误弹窗 | 操作失败 ＋ 知道了（保留现状） |

### A1. 信息架构

```
ScrollView（背景 holoToolBackground）
├─ 导航栏：inline「我的目标」+ 右上「+」Menu（三条目+分隔线）
├─ 恢复条（条件：有未完成共创会话）
├─ 分段控件「进行中 | 已完成」
└─ 目标卡 × N（单列；iPad 宽屏双列网格保留现有分档逻辑）
   └─ 卡片
      ├─ 行1：领域图标(40×40) + 标题 + 状态胶囊(右)
      ├─ 行2：数值/摘要(左) + 期限(右)
      └─ 行3：进度条（仅量化且进行中）
```

### A2. 布局数值

- 水平边距 22，卡片间距 16。
- 卡片：内边距 16，圆角 16，minHeight 84，底 holoToolSurface，描边 0.5pt，无阴影。
- 行1：图标 40×40 圆角 12（底=领域色 @12%，emoji 20pt 居中）；图标→标题间距 12；标题右侧到胶囊最小间距 8。
- 行2：与行1间距 6；数值行 15pt medium 等宽数字；摘要行 12pt 次文字，二者取其一；期限 12pt 次文字右对齐。
- 行3：与行2间距 10，进度条通栏卡内宽（314pt）。
- 分段控件：上下边距 8 / 4，左右缘与卡片对齐（22）。
- 恢复条：内边距 16，圆角 12，底 GoalJourneyAction @8%，位于分段控件上方。
- 对齐断言：卡左缘=22；卡内文字左缘=90（22+16+40+12）；数值/摘要行、进度条左右缘=卡内边距。

### A3. 分组与排序

- 「进行中」段：待回顾（带胶囊）置顶 → 有期限且未过期按近→远 → 无期限 → **已到期未完成（v2 下沉，不再置顶）** → 已暂停（带胶囊）垫底。
- 已到期卡：右上角「已到期」警示胶囊（与「待回顾」同构样式），行2 期限位显示原截止日期灰字（如「11/8 截止」），不用红字长句。
- 「已完成」段：无进度条，数值行显示最终值 + 达成日期，右上「已完成」胶囊（成功色 @12% 底）；**段内无目标时显示居中一行 13pt 次文字「还没有完成的目标」（v2）**。
- 已暂停卡正常渲染，仅加「已暂停」胶囊（底 holoToolBorder @50%，字次文字）。

### A4-A6. 组件 / 交互 / 边界

- 全部复用：HoloProgress（bar）、HoloPressStyle、原生 Menu / segmented、GoalBadge 领域配色；新组件仅 `GoalListCard` 一个。
- 点卡片 → push 详情；「+」菜单三项直达三个创建流；共创关闸时隐藏「一起想清楚」。
- **卡片长按菜单（v2 新增）**：长按（触屏）/右键（桌面，实现时仅触屏长按 + 详情页入口）目标卡弹出操作菜单，样式与「+」菜单同族（surface 底、圆角 14、阴影、行高 44）：
  - 进行中卡四项：**标记完成**（目标置为完成、卡片移入已完成段）／**暂停**（加「已暂停」胶囊、排序垫底；再点恢复）／分隔线／**改期限**（直接弹出编辑 sheet 预填，一步到达）／分隔线／**删除**（红色，requestDelete 确认弹窗走现有）。
  - 已完成卡两项：**再来一轮**（打开创建 sheet 预填该卡标题/类型/数字）／分隔线／**删除**（红色）。
- 状态机：加载中=居中 ProgressView（保留防闪现）／空态／正常／操作失败 alert；切分段 0.2s 淡入；新建成功返回=新卡置顶「进行中」段 → 自动 push 详情（不加 toast）。
- 空态四件套：target 图标 44pt + 标题 20 semibold + 副文 15 + 主按钮（48 高 圆角 14）+ 两条 13pt 下划线链接，垂直居中，top padding 80。**共创关闸时主按钮换「让 HoloAI 规划」，文字链接只保留「手动创建」一条（v2 去重）。**
- 最长文案：标题 `lineLimit(1)` + tail 截断 + `layoutPriority` 压过胶囊；数值行与期限同行时数值 `layoutPriority(1)`。

## 四、屏幕 B：创建/编辑目标表单

### B0. 文案稿（成稿）

| 位置 | 文案 |
|---|---|
| Sheet 标题 | 新建目标 ／ 编辑目标 |
| 大输入占位 | 想做成什么？ |
| 类型题头（v2） | 这个目标怎么算进度？ |
| 领域（v3 拍板：不再让用户选） | 表单无任何领域选项；AI 按标题自动认领（跑/体重→健康，存款/贷款→财务…认不出=其他），卡片图标配色照旧，详情页设置里可改 |
| 类型卡三张 | 过程型·靠行动推进 ／ 累积型·如 跑 300km ／ 达标型·如 减到 70kg |

| 数据来源行 | 「数据来源」+ 当前值（手动记录／数值习惯／账本） |
| 习惯空态 | 还没有数值型习惯 |
| 口径错配（选错才出现，v2 补动作指引，整行可点=弹出习惯选择） | 「跑步」每天累加，达标只看最新一条 —— 换「体重」这类每天记最新值的习惯 ／ 「体重」每天只记最新值，累计会把它逐日相加 —— 换「跑步」这类每天累加的习惯 |
| 期限行 | 「期限」+ 未选显示「不设」，选后显示中文日期 |
| 主按钮 | 创建 ／ 保存 ／ 保存中 |
| 禁用提示（v2 拆三态） | 标题空：起个名字就能创建 ／ 数字空：数字还没填完 ／ 累积型总量≤0：目标量要大于 0 ／ 达标型现在=目标：现在和目标不能一样 |
| 保存失败 | 保存失败 ＋ 知道了 |

**删除的文案**（原样列出供 dev 清理）：「目标信息」卡片头、三个类型 descriptor 常驻句、「以现在为起点，之后记录当前水平，进度按…计算」、「按全账本净结余计算（含信用卡负债）」、「目标说明（可选）」「达成后是什么样」「为什么要这个目标」三个字段、「图标/默认（按领域）/恢复默认」行、「AI 上下文」整卡、「还没有数值型习惯，先到习惯模块创建一个再来挂载」长句。

**移出创建流的字段**：说明、期望结果、动机、图标、AI 上下文开关 → 编辑时走详情页「目标设置」面板补。图标自动跟随领域默认 emoji。

**必填最少化**：必填 = 标题；量化类型追加 = 数字（累积型总量>0；达标型现在值≠目标值）。领域默认「其他」，类型默认「过程型」，期限默认「不设」，来源默认「手动记录」。

### B1. 信息架构（v2 顺序重排：类型紧跟大输入，领域胶囊后移）

```

│  ├─ 大输入：无框 25pt，占位「想做成什么？」，最多两行

│  ├─ 类型三选卡 HStack
│  ├─ 数字提示行（条件：过程型 + 标题含数字，见 B3）
│  ├─ 条件字段区（仅量化类型，动画浮现）
│  │  ├─ 累积型：「目标」数字 + 单位
```

### B2. 布局数值

- 内容水平边距 20，区块间距 20，条件区内部间距 12。
- 大输入：无框无底，minHeight 48，字 25 medium tracking -0.6，`lineLimit(2)`。
- 类型题头：13pt 次文字，与三卡间距 8。
- 类型三选卡：三等宽，间距 8，每卡 111pt，垂直 padding 10，圆角 12，minHeight 60；名称 14 medium，示例 11 次文字；选中=1pt 行动色描边+@6% 底+名称转行动色。
- 数字提示行：13pt 行动色，行首 sparkles 图标 14pt，整行可点；位于类型卡下方间距 10。
- 数字容器：padding 12，圆角 12，surface 底，0.5 描边，minHeight 48；行内小标签 13 次文字；数字 17 medium 等宽；单位 15（宽约 46-56）；箭头 14pt 行动色。达标型两框约 146/174pt 宽（数字区约 90/66pt，四位数字充裕）。
- 基线来源注释：12pt 次文字，「现在」框下方间距 6。
- 数据来源行：minHeight 44，「数据来源」14 次文字 + 值 15 主文字 + chevron；习惯子行同构；口径提示 13pt 警示色两行封顶、整行可点。
- 期限行：minHeight 44，「期限」14 次文字 + DatePicker compact。
- 对齐断言：大输入、题头、类型卡、条件区、chips、期限行、主按钮左缘全部=20。

### B3-B5. 交互 / 保存 / 边界

- 默认「过程型」：无数字区、无数据来源行——新建第一眼只有 大输入/题头+三卡/领域/期限 四层。
- **数字提示行（v2 P0 修复）**：类型停在过程型且标题提取到 ≥30 的数字串时，类型卡下方浮现行动色提示行「标题里有 300 —— 点一下切到「累积型」来追踪进度」；点击=切累积型+把该数字预填进「目标」框。非阻断、可无视。阈值 30 为原型演示值，实现时按单位词表（公里/km/本/篇/万/块/次…）+阈值调优，避免「每天读 20 分钟书」误触发。
- **切换类型永不改写用户已输入的标题与数字（v2 硬规则，原型演示脚本的预填逻辑不得实现）**；切回过程型再切回，已填数字保留；类型切换数据回落逻辑（来源不在可选集回落手动等）保留现有代码。
- **挂习惯自动基线（保留现状行为，v2 写入契约）**：数据来源=数值习惯时，「现在」自动取该习惯最新记录填入（现状 GoalEditForm 已有），并在框下方显示「取自「体重」最新记录（11/12）」注释行。

## 附录：v3 修订记录（东林拍板：领域选择是负担）

v3 改法：
1. 创建/编辑表单删除领域胶囊整行（v2 的「chips 自动滚入选中项」随之作废）
2. 领域由 AI 按标题自动认领：客户端本地关键词映射（跑/步/体重/睡→健康；存款/贷款/攒/还→财务；读/学/考/雅思→学习；上线/发布/项目名→项目……认不出=其他），零后端改动、零模型改动（字段与 CloudKit 兼容性不动）
3. 列表卡图标块配色照旧（认领结果决定颜色），想改领域的用户去详情页「目标设置」
4. 收益：创建路径少一排选择；代价：AI 认错时颜色不对（仅视觉，设置里可改）
