## 1. 产品范围与原型优先级

首页继续承担品牌识别、进入「今天」和快速访问功能。保留首页光球、轨道、背景、动效、快捷入口和底栏。「长廊首屏」指用户进入记忆长廊后看到的页面。新入口放在「记忆长廊 → 找日期 → 随机漫步」。随机漫步以**一个有记录的旧日**为单位，提供「看那天」「再走一天」和回到长廊继续浏览的路径。

这份规格可独立实施随机漫步，也包含长廊减法与旧入口的接线顺序。用户已选定「一束暖光」作为生产动效。完整长廊原型中的三个动效按钮和「重播穿梭」是评审工具，原生 Debug 验收入口可以提供它们中的暖光重播。生产页面只提供正常业务动作。退役与迁移按第 8 节逐项处理。

## 2. 页面规格与操作

### 长廊默认页

- 导航「返回｜记忆长廊｜找日期」。延续 Holo 业务底色、20 pt 页边距、至少 44 pt 点击热区。顶部固定。月份按年、月分组，章节标题随对应月份吸顶。最近的有记录日期排在最上，向下翻更早的记录。日期列 46 pt、与正文间隔 14 pt，用细线与小点引导。窄屏可以按原型收成 40 pt 和 11 pt。字号随 Dynamic Type 缩放。
- 每天露一条，优先带附件的想法，其次有可读正文的想法，再其次最近一条有时刻记录。同优先级按时刻及稳定身份决胜，无可靠时刻时按稳定身份落位。照片取同一条想法的附件缩略图，满宽横图约 1.88∶1。文字型想法用有层级的摘句，账单、打卡、完成任务用紧凑记录行。
- 两条及以上显示「当天 N 条记录」。点一下原地展开其余记录，收起后保留阅读位置。同一时间只展开一天。主预览保持在第一位，其余记录按可靠时刻从晚到早，无可靠时刻的置末标「当天」。进入原记录再返回，恢复日期、展开日和滚动偏移。
- 月份与日期标记来自同一份可见记录索引。「找日期」点日期直接回到该天，有多条时自动展开。主动查空白日期时临时定位该天并提供「去最近有记录的一天」。距离相同取较早日期。对未完成读取的日期显示「这一天暂无已载入的记录」。从历史定位后提供「回到最近」，回到真实的最近记录日。
- 沿用原型空、稀疏、同步和错误态。只有一笔时留一行完整记录。同步中显示可信本地内容。确认全空时显示「长廊还没有记录」和「写条想法」，接已有想法编辑器。完全失败展示重试，部分失败提示来源并保留成功项。

### 找日期与打开漫步

| 操作 | 画面和结果 |
|---|---|
| 点「找日期」 | 长廊当前位置保留。弹层显示年月、前后月、周一至周日、单点「有记录」及「回到最近」。月份默认跟随当前阅读章节，点击年月可以跨年。未来日期不可选。 |
| 点「随机漫步」 | 位于日历底部独立行，36×36 图标容器、12 pt 图标与文字间距、至少 62 pt 行高，标题「随机漫步」、副文案「去一个有记录的旧日」。就地将面板从日期选择器切到漫步，统一由同一 presentation 宿主协调。 |
| 数据已就绪 | 取得旧日快照后立刻播放暖光。第一次的出发日是今天。 |
| 数据仍在读 | 保持弹层可关闭，短请求无需闪现状态。等待超过 200 ms 显示「正在找一段旧日记录」；200 ms 为新实施默认，可在真机走查后微调。首次读取失败显示「暂时无法载入旧日记录」及「重试」。 |
| 关闭或下拉收起 | 结束当前取数或动效，恢复长廊原锚点和焦点。选择器与漫步之间只有一个有效展示状态；普通关闭回长廊，禁止叠加两个同层 sheet 产生白屏或闪回。 |

### 漫步抵达页

- 固定标题「随机漫步」，右侧「关闭」。原型移动端标题行 13 pt 上、9 pt 下，控件最低 44 pt。内容左右 20 pt，底部动作区避开系统安全区。使用当前 Holo sheet 的自适应尺寸，优先从目标结果测得合适高度，再限制在安全区可用高度内。该次出发和抵达期间固定此高度，结果区与暖光区复用同一内容矩形。显示区不足时结果正文单独滚动，标题和底部动作保持可用；辅助功能字号下动作允许换成两行。
- 日期区自上而下显示「2026 年 · 周四」、大号「5 月 21 日」和「距今天 176 天」。沿用原型结果区的 23 pt 顶部、19 pt 底部、13 pt 年份说明和约 42 pt 日期标题（默认字号，衬线，行高 1.18）。距离以日历日差计算，星期与日期使用同一日历和时区。导航标题不参与暖光淡出。
- 「那天的记录」默认最多 3 条，按可靠发生时刻从早到晚，无可靠时刻置后。若有带正文的想法且按时序落在前三之外，替换最后一条无该想法的预览再排序，让暖光中的摘句在抵达后能直接找到。多于 3 条时标题显示总数，底部为「在长廊看全部 N 条」。来源不完整时只显示已载入记录，底部使用「在长廊看这天」。单条记录直接展示。
- 列表使用已有模块语义，紧凑行约 54 pt，信息顺序为记录名、模块和时间、金额或状态。图片来自所点想法，约 2.45∶1；无图片按文字行显示。点击可以查看原记录。动作区左侧「再走一天」，右侧「在长廊看这天」。本轮全看过时左侧显示「重新漫步」；历史只有一天时隐藏左侧动作。回长廊后定位到抵达日，不重置到今天。
- 「回看一句」放在记录后方。背景使用 Holo 暖底，左侧 2 pt 橙线，右侧约 12 pt 圆角；距记录 13 pt，内部约上 12、左 14、右 13、下 11 pt。显示标题「回看一句」、正文和「查看这句的来源 ›」。没有可靠依据就省略整个区域。可读正文随字号伸展。
- 来源详情打开前校验当前可见性。复用现有详情组件或路由，返回原漫步日期、结果区偏移与来源按钮焦点。来源确实失效时说明「这条记录暂时无法查看」并刷新对应日；只在成功验证失效后撤掉对应预览和解读。仓储读取失败使用「暂时无法载入」和重试，保留可信画面。未找到对应日期时留在当前页并提示原因，避免按钮点击后静默无效。
- 首次漫步没有历史记录时显示「还没有可漫步的旧日」，正文「长廊里有了更早的记录，就可以回来走走」。来源未读完时显示「暂时找不到旧日记录」及同步或重试指引。这些状态直接显示。

## 3. 状态、路由与生命周期

用宿主维护一个展示路由，表达长廊、找日期、漫步和来源详情的关系。漫步内部阶段为 `loading → traveling → landing → arrived`，还包括可恢复的 `empty / failed`。动画输入为不可变的 `requestID / departureDay / destinationSnapshot / motionMode`。抵达提交点为过场交接结束。日期、记录和解读一起提交，返回锚点在打开弹层前单独保存。

| 事件 | 状态与副作用 |
|---|---|
| 点第一次漫步 | 建立请求，冻结本次使用的 Calendar、时区和今天。读取目标，备好结果再开始动画。首次出发日期为今天，即使长廊当前停在更早位置。 |
| 再走一天 | 只在已抵达状态接受。前一站是此次出发日期，下一站从未看过的候选抽取。旧页可在加载时继续显示，首次暂无旧页则显示加载状态。 |
| 重新漫步 | 选到新目标并成功抵达后再清空旧轮集合，计入新轮首站。候选多于一个时首站避开刚看过的日期。失败或关闭时保留原轮集合。 |
| 连点、反复打开 | 主操作同一时刻只接纳一个请求。关闭、再次打开、后台或范围变更后，所有旧任务回调必须比对当前请求身份。动画中只保留关闭操作；原记录、动作栏与遮罩以下区域对命中和 AX 均不可见。 |
| 背景、失焦或导航离开 | 动效只在场景 active、长廊有效且漫步可见时运行。离开页面取消任务。暂时后台时停止绘制；回来后有有效快照就静态落到该日，目标失效则重新验证和提示。取消且未抵达的日期不计为已看。 |
| 播放时发生撤销、删除、归档、同步或权限变化 | 只要目标涉及的记录失效，就更新快照。当前摘句已失效立即撤下光中引文；日期全部变空则取消当前过场。读取故障以数据不完整处理。时区变化重建索引，下次请求以新本地日为准。 |
| 点「在长廊看这天」 | 同一份日期身份交给长廊定位入口。确认数据窗口与列表锚点已就绪，再切回并聚焦；迁移期可复用 `focusDay`、`enterDayReplay` 与已就绪的滚动锚点。关闭后跨月仍能顺着历史翻。 |
| 复现动效 | Debug 使用原起点和终点重播，结果日期与已访问集合保持原状。样例注入从 UI 可控地开始，以便截 0 ms。生产按钮「再走一天」负责下一次旅行。 |

旁白在开始时读一次「正在回到那一天」，交接完成后把焦点放到日期标题「2026 年 5 月 21 日，星期四」。光形、装饰线、正在淡入淡出的两组日期从 AX 树排除，避免一口气读出两个日期；关闭始终在 AX 树内。长廊底下的内容随弹层隐藏。点击路径无无名按钮，图形与状态文本一起传达信息。

## 4. 「一束暖光」原生还原规格

### 4.1 图层、几何和颜色

在内容画布内从下到上叠三层：已经布局好的抵达页、暖光底板和椭圆渐变、两组日期文案。底板与光合成在一层并裁切到画布，日期是该层的上层子节点。最后一起淡出暖光层，下面的抵达页自然露出。导航和关闭控件独立于这个合成层。禁止用首屏光球组件模拟光源。暖光是纸上的一团宽、低对比度的漫射光，保持无声，正式动效无触感要求。

**对拍画布**在 393×852 的 HTML viewport 中外框为 369×338 CSS px，内层实际为 **367×336**，左、右各留 12 px 含外框。原生 Debug 对拍以 **367×336 pt** 单独量测，按 1× 输出比对。业务画布使用 sheet 可用宽高。所有位置基于实际画布计算。画布变大时渐变等比例适配，文字仍按 Dynamic Type 与日期排版规则显示。动画前后保持同一 sheet 高度和内容锚点；屏幕安全区和底部工具区不随光漂移。

| 元素 | 浅色 | 深色 |
|---|---|---|
| 暖光底板 | `#F8EEE0` | `#392B23` |
| 动效日期及摘句正文 | `#4B3224` | `#F9E4CF` |
| 年份、小标签、装饰线 | `#8B4427` | `#FFC297` |
| 光形颜色 stop（同两套） | `0.00 #FFCF858F`、`0.38 #E99A573B`、`0.70 透明`、`1.00 透明`，采用 CSS RGBA 顺序 | 同左 |

- 光层绘制框相当于 CSS `inset: -20%`，即相对画布四边各扩出 20%。设扩展框宽高为 `G_w=1.4W, G_h=1.4H`，光心在该框的 `(0.47 G_w, 0.45 G_h)`。椭圆采用原型默认 `farthest-corner`，可在归一化椭圆坐标中做径向渐变，半径为 `sqrt(2) × (0.53 G_w, 0.55 G_h)`。按 CSS 的透明 stop 做预乘 alpha 过渡，禁止把暖光改成圆形不透明亮斑。用 sRGB 色值，先对拍再处理系统色域差异。
- 光层围绕扩展框中心缩放，初态 `scale=0.74`，整体位移 `x=-0.16 G_w, y=+0.13 G_h`。终态 `scale=1, x=0, y=0`。位移作用在缩放后的整层上，文字和底板都不随光移动。渐变本身的 opacity 从 0.18 到 1，独立于 stop 内的 alpha。
- 两组文案各自水平、垂直居中，16 pt 内边距。每组的顺序是 28×1 pt 细线（0.65 alpha、线下额外 5 pt）、标签（12 pt、约 650 weight、字距 0.84 pt）、年份（13 pt、等宽数字）、日期（见下）、可选原文摘句（约 15.2 pt、衬线半粗、行高 1.55、宽度上限 24ch、额外上距 8 pt）。列内基础间距 4 pt。标签「今天」或「出发」，抵达标签「想起那一天」。
- 日期按 CSS `clamp(1.9rem, 8vw, 2.7rem)` 换算，默认 16 px 根字号下约 30.4–43.2 pt，393 pt 屏幕基准 **31.44 pt**，行高 1.25、字距约 -0.07 em。优先匹配原型中文 Songti SC 的宋体字形和视觉重量。运行时确认系统可用字型再用已有 Holo serif 回落，记录字型差异，禁止给所有中文回退到粗黑体。原文最多两行，正常字号保持在中心组内；超大字号时允许压缩留白、换行或切低动态的单日期呈现。用 `@ScaledMetric` 或项目等价字体逻辑，复现 393 pt 的正常字号只是验收锚点。
- 过场中的摘句取同一抵达日的原文，保持语义完整。它与结果页的「回看一句」是两个字段。无想法的目标只显示日期，光形完整。正文最少由能核对的真实记录支持，不借图或跨日取句。
- `holoToolBackground`、`holoToolText` 等现有 tokens 管业务页面。这里的独立色值放暖光专用语义颜色资产，深浅色走 asset variation。可复用已有资产后保持上表实际颜色匹配。时间常量接 `HoloAnimation` 的暖光专用定义，避免分散在手势、视图和控制器。

### 4.2 时间线

(t=0) 从暖光第一帧开始，排除取数和系统 sheet 打开耗时。正常主段 **1450 ms**，最终淡出 **210 ms**，记录在约 **1660 ms** 稳定。Web 在 1670 ms 左右卸载遮罩属于清理时序。保持约 1.66 s 的体感，光晕越到后段越慢。真实日期不滚动、文字不缩放、不位移、不闪屏。

| 图层 | 关键点 | 曲线 |
|---|---|---|
| 椭圆光层 | 0 ms 初始 opacity 0.18、scale 0.74、相对扩展框 -16% / +13%；1450 ms 到 opacity 1、scale 1、零位移 | CSS `ease-out = cubic-bezier(0, 0, .58, 1)`，同一进度驱动位移、缩放和亮度 |
| 出发文案 | 0–174 ms 保持 1；174–493 ms 从 1 到 0；之后保持 0 | 段内 `ease-in-out = cubic-bezier(.42, 0, .58, 1)` |
| 抵达文案 | 0–435 ms 保持 0；435–971.5 ms 从 0 到 1；之后保持 1 | 同上，只有透明度变化 |
| 暖光合成层 | 0–1450 ms 保持 1；1450–1660 ms 从 1 到 0 | 同光层 `ease-out`；仅这一层淡出，下面的结果已排版 |

### 4.3 原生实现与降级

- 使用 SwiftUI 原生视图，建议 `TimelineView(.animation(...))` 驱动**单独暖光叶子视图**，或用同等可按 elapsed 驱动的实现。数据加载、模态状态与动画绘制分离。单调时钟记录每次开始时刻。每帧只算 progress 并绘光层、两组文字 alpha 与底板合成 alpha，禁止每帧改变长廊/VM published 状态。交接使用单次完成事件，清理统一由会话控制。
- 可用 Canvas/Core Graphics 先将坐标归一化到椭圆半径再画 radial gradient，最后裁切到画布。减少重复布局与分配；日期和短摘句在开始前排好，文字透明度变化不重算行宽。CSS bezier 需要解 x 再取 y，直接用三次函数的 y(t) 或随意替换系统默认 spring 会错过交接点。
- 系统「减少动态效果」遵循选中原型：主段 **850 ms**，光形固定在终态位置和大小，光亮度改用抵达文案的淡入曲线，出发和抵达保留原百分比关键点，接 **210 ms** 合成淡出。大字号空间不足可使用该低动态样式并保留完整结果。App 内 `HoloMotionRollout.replayKey` 关闭时直接显示已加载的结果。若播放时开关改变或进入后台，释放动画任务，返回有效的静态结果。
- 现有 `holoMotionSurfaceIsActive` 和 `scenePhase` 作为可见条件。暖光每次交互播放一次。空、加载失败及没有候选时无需启动绘制。关闭随时可用。长廊和首页运行各自既有动效。

### 5.1 事实源与历史索引

复用 `CalendarEventProvider` 和 `CalendarEvent`，继续用它们的日期、模块、原记录身份和失败分项。按日索引使用相同的过滤、可见性及去重结果。目前 `CalendarViewModel` 首屏加载小窗口，再补约 ±60 天，`CalendarPresentationSnapshot` 也只知道已加载窗口。它们可以作为本地窗口缓存，**不可将其当作完整随机池**。

| 模块 | 时间口径与现行过滤 |
|---|---|
| 记账 | `Transaction.date`，沿用 `FinanceTransactionOccurrencePolicy.occurredPredicate()`，排除软删除和仍计划发生的记录，金额走原币种显示。 |
| 习惯 | `HabitRecord.date` 发生时间，保留父习惯可见性和打卡完成语义。当前 Provider 排除已归档/删除父习惯与已删除记录，保留现有数值型记录口径。 |
| 任务 | `completedAt`，使用 `.completed` 维度，排除当前 Provider 已排除的归档/软删。到期和计划时间属于日程入口。 |
| 想法 | `Thought.createdAt`，通过 `ThoughtRepository.fetchThoughts(from:to:)` 使用同一归档、软删除和同步副本语义。图片仅按需取对应缩略图。 |

- 用后台上下文读取轻量历史日期索引，优先复用 Provider 共享 predicate 和去重代码。投影字段为模块、业务 UUID、时间以及判断可见性、父记录和重复副本所需的最小字段。按日聚合前用同一现有规则选出 UUID 的存活代表。若轻量字段不足以复刻去重，改用候选批量验证并走统一规则，不能用另一套最晚记录规则伪造日期。候选聚合用唯一日，跨模块数量合并，同一记录的附件和引用不另计。禁止通过 Core Data 分组把有多个不同日期的同步副本分别计进日历。
- 区间是本地 `[startOfDay, nextStartOfDay)`，通过项目 `CalendarRangeBuilder` 或同语义的注入式版本构造。采用 Calendar 的日期运算，覆盖 DST、跨年与系统时区变更。过去的历史数据可抽到，适配多年或仅一日的库。首页可优先读近期小窗口，历史索引按需建立并在同一浏览会话复用；不要逐日发空查询或在进入首页时读全库照片。
- 原生日索引提供 `日期、记录数、成功来源、失败来源、索引修订`；按日详情输出 `日身份、记录 ID 列表、可点击预览、可选原文摘句、可选回看一句、完整性`。同一日从日期选择、随机漫步和长廊落点打开时读取同一业务口径。现有 Provider 在区间内过滤副本，若同 ID 历史副本日期不同，单日和全历史查询可能选出不同代表。先用隔离 fixture 复现，再在新读路径内共享代表选择或在日详情按索引 ID 回查校验，确认各入口不会展示同 ID 的不同日期。不要借此改动其他模块的业务去重口径。日期索引成功刷新时替换对应范围，失败来源沿用可信数据并标明不完整。主动删除/归档的事件立即失效，不因旧缓存继续显示。
- 启动时注入现有主库依赖，源读取用私有队列 context，UI 只消费值与 `NSManagedObjectID`。监听项目现有本地保存和远端合并事件，按受影响日期和来源失效。索引刷新版本绑定查询和结果，慢查询禁止覆盖后来成功的数据。读取历史日只抓所需范围，装进当前浏览窗口前先准备好日锚点。

### 5.2 抽取算法

1. 从日期索引筛选小于本地今天且有至少一条可见记录的日子，每个日期等权。首抽有距今天至少 30 个日历日的候选时从那部分随机选。后续在剩余候选中随机，允许抽到更近或更远日期。记录少的日子保留相同机会。
2. 已到达才写入本轮 `Set<DayID>`。本轮状态仅驻留本次长廊会话，离开当前长廊会话后清除。一次关闭漫步再打开仍属于原会话。全部看完后显示「重新漫步」，首个新日尽量与上一个不同。
3. 加载某候选成功但已无可见记录，移除该候选并从剩余集合继续选；加载失败保留失败标记。有效候选耗尽后根据来源完整性显示空态或重试。避免无限循环。抽样器支持注入固定随机序列，方便验证去重和 176 天样例。
4. 查看原记录或手动按日期定位，不消耗漫步轮次。关闭、数据失败、取消请求都不计「已看」。

### 5.3 回看文案与出处

首版在本地生成并附来源，零网络依赖。过场里的「薄荷换盆后，闻起来满手都是薄荷味。」是原文摘句。抵达后的「从买土到换盆，那天留下来的细节是洗完手仍闻得到的薄荷味。」是示例解读，只有样例数据可以使用这句预写文案。

生产规则采用保守的确定性生成，最多一句，证据挂到可打开的同日原记录。

- 优先选该日用户原文中可独立阅读的第一人称句子。若只可做摘录，展示短引文并保留原意；用「你那天写道」引出，避免把摘录冒充分析。若摘句与记录列表重复且没有补充细节，可以省略。引用的原记录优先与过场摘句来源一致。取不到可见正文时仅显示记录。
- 原文没有可用句子但当天有明显、可证实的结构时，可选用事实模板。例如至少四条有可靠时刻的记录且 18:00 后占比达到现有日回放条件，可用「这一天的记录大多留在傍晚以后」，并绑定参与判断的记录。多条依据点「查看这句的来源」打开对应记录列表；单条依据直达原记录详情。已有 `DailyReplayPresentation.narrative` 可参考时间条件，但它目前返回无来源的字符串并带通用解读，不能整体复制为有证据的「回看一句」。
- 单笔账单、普通单次打卡或只有机械状态时直接展示记录。不推断情绪、因果、人格、长期规律或跨领域关系。回看句带 `文本、来源身份与修订、规则版本`，只在记录完整或模板能独立由当前可见记录证明时呈现。编辑、撤销、归档、删除、权限变化后一并重新验证。
- 将来接 AI 属于另一项设计，另走 iOS/后端 Prompt、版本和接口契约验证。本期暖光出发、抵达和回看体验可离线完成。

## 8. 迁移、回退与边界

- **日回放、月历。** 统一到日期主线和日期选择器。历史定位、全部记录、来源和导航通过后，旧档位可以收敛。原记录、附件、历史数据继续走现有源。
- **任务轴。** 在任务日程中验收任务与系统日历同轴、创建、拖拽调时及旧通知落点后再迁。系统日历未授权与拒绝路径要能反馈。此项未通过前保留原能力。
- **个人与 AI。** 个人页承接「我的积累」、里程碑和每周回顾。AI 记忆与确认归记忆中心，「一个发现」和报告归 HoloAI。原「查看新记忆」路由逐条走查，确保改到待确认或对应记录。周回顾通知保持原落点。计划台账里独有的历史计划先核对能否从原对话访问。已采纳事项继续走任务或目标。
- **独立展区和周网格。** 上一轮减法建议退役七天并排、跨模块热力图、每日感知和精选故事专区。选定暖光不改变这些功能本身的评审状态。若实施整套减法，按清单确认失去的用户动作与历史入口；单独交付暖光无需等待这些退役。
- **回退。** 仅暖光有问题时使用现有回放动效开关直接显示同日结果。随机漫步入口有问题时可单独撤回入口及其宿主接线；长廊时间线有问题时优先回退该 UI 切换，保留现有可用入口。业务数据均为读路径，避免引入需要回滚的持久化迁移。
- **本期边界。** 无需修改 CloudKit、Core Data Schema、首页视觉、后端或 Prompt。日用 CloudKit Development 数据只能按项目约定保护；隔离验证用测试或样例库。工作区的其他人改动按现行规则保护。本稿和截图验收的是浏览器参考及实现规格，iOS/Mac 原生、真机性能、多设备同步和生产发布均待执行方分层验证。
