✂️ 这轮的六刀减法（每刀都少几行）

  1. 1外观 3 行 → 1 行：一级只留一行、右侧显示当前值，点开二级页选跟随系统 / 浅色 / 深色（你拍板的）。
  2. 2缓存 2 行 → 收进数据管理：缓存大小 + 清除缓存是低频操作，跟「清空数据、最近删除」是同一类事，归进数据管理页。
  3. 3隐私政策 + 用户协议 → 收进「关于」：政策文档是「了解 Holo」类内容，放关于页是 App Store 审核惯例位置，一级页省 2 行。
  4. 4重看新手引导 + 重看新人笔记 → 收进「关于」：一次性内容、极低频，跟政策文档同属「回看 Holo 是什么」。
  5. 5「外观」「通知」两个单行组 → 收进「通用」：一行还单独挂组标题显得碎；收编后组数 7 → 5。
  6. 6AI 回放 3 开关 → 收成 1 个入口：上一版已做，保留。点开就是原来的三个开关，功能不变。

· 保留没砍的三处，理由：应用锁是安全开关需要直达；小组件显示想法原文是隐私泄露担忧型开关，用户警觉时要一秒找到；反馈给开发者是产品生命线，保留一级。
· 图标在原型里用 emoji 示意，正式实现沿用 App 现有 SF Symbols 砖样式，颜色 / 圆角 / 字号 / 间距与现设置页完全一致。
· 所有二级页（HoloAI 聚合页、通知设置、数据管理等）内容原样复用；外观选择、关于页内政策 / 引导是新增的轻量二级页。纯界面重组，不动业务逻辑，无需后端发版。
