# Holo 全局动效改版：实施与验收

目标：温暖且有惊喜。打开时识别品牌，记录时得到准确回应，回看时看到积累。动效不延迟保存、不参与业务判定、不改变数据结构或导航入口。

## 已实现的体验

| 行为 | 实现 | 真实状态与回退 |
|---|---|---|
| 落下一笔 | 新记账、完成新想法编辑后，列表行展示 400ms 暖色光痕 | 仓库成功后发布，编辑旧记录不庆祝；弹层退出后消费，超时不补播 |
| 完成一件 | 习惯页和 Today 当天首次有效记录展示 600ms 局部暖光；任务确认保存后播放一次 750ms 短回执 | 坏习惯、连续计数不庆祝；撤销取消在途效果；待确认文案与已保存文案分开 |
| 展开一天 | 主动打开一天时，时段内容短促错峰展开，600ms 内结束 | 日日期头保持稳定；刷新、筛选、懒加载重建不补播；照片翻片保留原手势 |
| 日常手感 | 首页、底栏、目标、AI 卡片、新人引导、健康日期与共同业务按钮统一按压 | 不改变按钮动作、布局或热区；关闭开关保留普通按压透明度反馈 |
| 健康与 AI 等待 | 日期、图表支持减少动态效果；运行中局部图标跟随前后台与可见性 | 阶段、数字仍来自真实数据，不增加假进度或后台调用 |
| 首页品牌 | 完整保留球体、轨道、铭文、背景和默认运动参数 | 只改变不可见与后台时的动画生命周期；恢复后沿用原参数 |

任务列表、详情、Today 和 Matter 分步推进共用原有三秒保存窗口。新版 Today 与分步推进补齐了窗口内的可撤回入口，动画不负责确认或取消事务。Matter 步骤完成保持已有轻量文字回执。

## 实现入口与内部契约

- 源码根：`/Users/tangyuxuan/Desktop/Claude/HOLO/Holo/Holo APP/Holo/Holo/`。
- `Models/Motion/HoloMotionEventLedger.swift`：按操作 ID 区分 pending/confirmed/failed/undone，只有 confirmed 可展示。事件过期、重复、撤回均不能误庆祝。习惯每天一次的规则独立于 UI。
- `Components/Motion/HoloMotionFeedback.swift`：局部光效、按压、回放展开和内存展示中心。每个记录有自己的展示代次，无关记录不会中断已播放效果；装饰不命中、不进入无障碍树。
- 参数与开关位于 `Utils/DesignSystem.swift`，主 App 与 Widget 共用定义。没有新增业务持久化字段、Prompt 或后端依赖。习惯当天的展示次数保存在本机 `holo.motion.habitResponseDay`，不改变打卡数据，也不参与云同步。

`holoMotionSurfaceIsActive`：首页常驻页面标记当前可见层；列表在编辑弹层打开时关闭；子层与父状态相与。一个成功事件只允许最先可见的展示消费，不经同步通知制造事件。进入后台、关闭开关或启用减少动态效果时，丢弃尚未播放的回应；只有短时编辑遮挡可以等待返回列表。

## 展示开关与回退

四个 UserDefaults 键默认开启，测试可通过启动参数覆盖：

| 键 | 作用 |
|---|---|
| `holo.motion.interactionEnabled` | 按压缩放与全屏移动转场；关闭后保留普通反馈与淡入淡出 |
| `holo.motion.recordFeedbackEnabled` | 记账与想法新增光痕 |
| `holo.motion.completionFeedbackEnabled` | 习惯暖光与确认完成回执；关闭后任务撤回反馈仍存在 |
| `holo.motion.replayEnabled` | 明确打开一天时的错峰展开 |

系统减少动态效果优先于开关：无局部光晕扩展、无页面位移、无回放错峰、无持续旋转/呼吸；状态文字和撤回入口保留。键盘继续使用系统时序。关闭所有开关不改变存储，回退无需迁移。

## 系统复审修正（2026-10-04）

复审覆盖首页品牌、共享按压/入场/转场、手动记账与自然语言记账、新想法、习惯、任务列表/详情/Today/Matter、日回放，以及所有现存持续动画与逐帧绘制入口。重点核对业务成功来源、可见性、前后台、减少动态效果、关闭开关、重复播放与操作热区；这不是全 App 所有业务的完整回归。

| 发现 | 最终调整 | 用户可见影响 |
|---|---|---|
| KeyframeAnimator 默认循环 | 两个新效果显式 `repeating: false`；移除任务待确认时的第二个完整回执 | 勾选后只保留撤回提示，真实确认后才短暂庆祝；连续操作不会叠两张回执 |
| 完成回执用泛化标题，详情没有限定当前任务 | 确认时快照真实任务名；详情按任务 ID 过滤 | 用户知道刚完成的是哪件事，其他详情任务不会误播 |
| 未挂载的列表行无法自行处理后台切换 | 展示中心在离开前台时清空所有待播事件，保留去重账本 | 返回前台不补播旧记录；新的手动保存仍正常回应 |
| 日回放以分组序号去重，刷新和新懒加载分组可能入场 | 按稳定时段 ID 去重，只接收打开一天后 1 秒内的入场；筛选、遮挡、后台取消请求 | 滚动阅读保持安静，切换日期才形成新的展开请求 |
| 习惯展示去重只在内存 | 本机持久化当天展示次数 | 重启后撤销再勾选也不会重新庆祝 |
| 旧的光标、扫光、纪念日和引导装饰有无限循环遗漏 | 新增 `HoloAmbientMotion.swift`；统一减少动态效果、前后台、页面可见性、交互开关和消失时停播 | 减少动态效果时保留静态状态，不持续旋转或呼吸；减少不可见页面绘制 |
| 新人和纪念日纸屑持续循环 | 改为一次下落，粒子身份由 State 固定；减少动态效果关闭纸屑，保留操作卡片 | 惊喜短暂出现，阅读与操作不被持续打扰 |
| 通用旧入场、金额键盘和饼图逐帧扫描未接统一控制 | 入场总时长不超过 600ms；键盘采用共同缩放；饼图在静态模式直接显示真实结果并暂停 TimelineView | 数字和分类金额始终可读，静态模式仍可输入和选择 |
| 新人“首次记录”监听通用数据刷新 | 只接明确本地保存事件；保留表单和用户当前对话发起的记账路径，幂等命中不再发布 | 云同步、初始化与后台刷新不会被当作刚完成记录 |
| 启动参数 NO 被 Bool 强转误读 | Foundation 实测 `object: NO / cast: nil / bool: false`；共用 `HoloMotionPreferencePolicy`，兼容系统布尔读取 | 关闭页面转场与记录反馈的启动参数真正生效，开关规则一致 |
| 新人关闭入口偏小 | 关闭按钮与次要操作至少 44pt | 更容易点中，避免为了动效牺牲操作 |

首页球体、轨道、弧形文字、背景色与默认运动参数再次通过保护检查。`ChatView.swift` 和 `HoloTaskCompletionCoordinator.swift` 与本轮复审前快照字节一致；没有新增聊天中间容器，没有改变三秒撤回、保存失败或重复任务规则。没有改后端。
