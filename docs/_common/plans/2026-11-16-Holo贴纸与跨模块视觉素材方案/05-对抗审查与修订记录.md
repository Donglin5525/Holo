R1 适合产品讨论，尚不足以无歧义交给另一个 AI 实施。主要缺口是长廊真实接线、深色素材边界、删除的单调性、版本并发、提交幂等、纯图片与旧端、来源投影更新和导入恢复。R2 已修改原三份文档，并补实施入口、长廊/深色规格与可执行输入输出样例。

## 3. 对当前代码的关键证据

主代码根为 `Holo/Holo APP/Holo/Holo/`；路径与符号是交接定位线索，实施前再核对。

- `Views/MemoryGallery/MemoryGalleryView.swift`：顶栏真实入口及 `CalendarRootView` 宿主；不能凭文件开头旧注释恢复两Tab布局。
- `Views/MemoryGallery/RandomWalk/MemoryGalleryFindDateModel.swift`：实际找日期 Sheet、620pt高度和漫步状态。
- `Views/MemoryGallery/Timeline/MemoryGalleryTimelineView.swift`：`MemoryGalleryDayPreview` 现有图片想法优先规则。
- `Models/Calendar/CalendarEvent.swift`：事件 `==` 仅比较 id，附件缩略图还没有source attachment ID。
- `Services/Calendar/CalendarEventProvider.swift`：想法按createdAt、旧附件投影取数，不能误把素材时间当业务日期。
- `Views/MemoryGallery/Calendar/CalendarViewModel.swift`：当前growth通知刷新，不等于未来视觉变更自动生效。
- `Views/Thoughts/ThoughtEditorView.swift`：`persistContent`、`hasContent`、`clearRecoveryRecordAfterCommit` 均需接入视觉草稿，不能只加一个SwiftUI Image。
- `Services/Thoughts/ThoughtEditorRecoveryStore.swift`：暂存图片与恢复日志本机存储，现接口吞写入错误，新增路径必须能让调用者知道失败。
- `Models/CoreDataStoreUpgrade.swift`：已支持纯加表/登记升级、SQLite backup和_SUPPORT复制，也明确拒绝降级。没有执行当前备份的恢复测试，不能声称已满足本需求。

## 4. 未被文档审查证明的事项

1. Vision对用户真实照片的质量、可用硬件范围、冷启动和热运行耗时。
2. 图像柔边/预乘alpha、透明玻璃、细杆、孔洞在不同缩放下是否好看。
3. CloudKit乱序、两设备离线并发、账号切换和删除内容的实际传播。
4. 旧版另一设备编辑新记录是否安全；本地升级后的降级明确不支持。
5. 新像素数据、外置BLOB与现有升级备份的可恢复性。
6. 深色token、月历小屏与已有长廊排版在真机是否协调。

这些都已转为03的验收条件，不以“方案评审通过”替代。没有发现新的设计反例不等于没有实现风险。
