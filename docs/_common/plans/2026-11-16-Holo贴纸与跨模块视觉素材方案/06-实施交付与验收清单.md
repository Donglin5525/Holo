## 2. 已实现能力（对照原型六场景）

1. **制作贴纸**：拍照/相册/文件三入口；贴纸/照片双模式；贴纸与原图对照；纸边三档×厚度两档；
   透明 PNG 不二次抠图；无主体→裁近重试/改照片；等待态如实（不伪造进度）。
2. **我的贴纸**：三分栏、长按七项菜单、导出透明 PNG、彻底删除（墓碑+清像素同事务）、
   空态一句话；命名可跳过。
3. **固定支出**：列表图标位贴纸优先、详情主视觉+编辑外观/恢复分类图标；金额/流水不动。
4. **想法头图**：编辑器菜单「添加/更换头图」（照片模式默认）、编辑页头图区、列表卡头图预览；
   无头图原样折叠。
5. **长廊**：时间线主预览头图优先于旧附件；找日期升级图片月历（图片/日期双模式、
   默认图片；日期/今天/选中在图外；N 条计数）。
6. **深色**：纸边 token（浅 #FAF8F2/深 #D6D1C9）、纯白跨模式、夜间柔光仅预览、导出固定浅色。

## 3. 手机验收清单（装机后过目，全部手机上完成）

> 装机包我构建好后单独给清单。以下是功能验收点：

1. 固定支出：任一项目详情 →「设置外观」→ 拍/选一张图做成贴纸 → 使用 →
   列表图标与详情顶部显示自己的物品；金额/已购天数/日均不变。
2. 同一项目「恢复分类图标」→ 回到原样，素材库里还在。
3. 想法：新建想法 → 菜单「添加/更换头图」→ 选照片 → 保存 → 列表卡出现头图；
   再打开编辑，正文/标签/纸张原样。
4. 长廊：找日期 → 默认图片模式 → 有头图想法的那天出现缩略图和条数；
   切「日期」模式回到原数字月历；时间线上那天主预览带图。
5. 深色模式：做一张浅色物体贴纸 → 深色下纸边变柔和浅灰、物体颜色不变。
6. 我的贴纸：长按 → 重命名/收藏/查看使用位置/导出 PNG/移出/彻底删除逐项可用。

## 6. 数据安全口径（本轮实施守住的红线）

- 纯加表：三实体零动旧表；守门实体数核对通过；升级登记簿无需变更。
- 不重置任何 CloudKit 数据；开发库是你的生产数据，全程只读验证。
- 彻底删除走墓碑：离线旧数据晚到不能复活素材（V 系与素材包测试锁死）。
- 提交原子性：素材+位置+业务变更单事务；失败保留草稿不半成功。
- 财务语义零改动：换图不记账、不改流水；想法文本 AI 链路零触发（纯视觉提交不碰正文 hash）。
