## 用现成数据启动

1. 确认试点记录在 Holo 中就绪；若仍待导入，沿用 Holo 现有正常导入/录入流程。方案不自动写入日用库。
2. 冻结该批数据的范围、账户、口径、版本和问题。没有具体问题时默认回答：“这段时间最值得我了解或调整的一处财务变化是什么？”
3. 从现有财务深度分析入口生成当前版本基线，保留问题、报告与可追溯任务身份。先核数字与语义，再判断深度和文风。
4. 以同一份 Holo 任务快照/证据验证新方法；必要的本地核算与方法消融作为辅助，不要求用户再准备一份表格。
5. 新方法接入后，用同一入口复测报告、依据、追问与纠正。真实批评测先冻结费用上限；本轮没有模型调用或预算消耗。
