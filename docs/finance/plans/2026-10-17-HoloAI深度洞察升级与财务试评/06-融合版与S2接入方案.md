# 06 — 融合版方法与 S2 接入方案

日期：2026-10-18。状态：融合方法已定稿并在真实数据+真实模型上验证（16 次调用共 ≈¥0.021，12 首轮消融 + 3 融合 + 1 修复轮）；生产接入未开始。本文件是 S2 实施的依据，术语服从 02 契约。

## 1. 融合版方法 = 四个条件各自证明的优点

首轮消融（03§4）证明了各条件的收益来源；东林盲评反馈「都挺好、分期最佳」进一步确认：现行方法不是全坏，它的报告成熟度与风险抓取是资产。融合原则：**判断力用新方法（C），表达力保留现行风格（A），个性化用背景但加防线（D 的教训），数字永远来自台账**。

| 融合要素 | 来源条件 | 证据 | P1V2 落点 |
|---|---|---|---|
| 答案先行、抓最大的一件事 | C | A 全文漏报收入降 2.8 万；C 第一句即剪刀差 | 判断方法 §1.1-1.2 |
| 候选解释+改判条件 | C/D | D 用东京旅行背景正确排除误读 | §1.4 |
| 已知风险必须处理 | A(Q3 表现最佳) | A 抓到双记+截止日；东林点名「分期最好」 | 台账【已确认事实与已知风险】段 + §1.5 |
| 标题力度与要点句式 | A/B | 点破式标题有记忆点，claims 每句完整判断 | 表达层 §2.1-2.3 |
| 口语不油腻 | B | B 改写更顺（但救不了判断） | §2.4 |
| 不编动机 | C | A 的「主动消费升级」实锤 | §1.4 |
| 不假设合同条款 | D 教训 | D 编造利率 3-4% | §1.7 + 台账零息特征行 |
| 明确行动可含「不动」 | Q3 各版 | 「无需调整+修复双记」是最佳行动形态 | §1.6 |

P1V2 全文冻结在 `local-only/run_ablation.py`（P1V2 常量）；输出 schema **对齐现行生产 AnswerV1**（title/narrativeSummary/keyInsight/claims/interpretation/recommendation），新增可选字段 `claims[].kind/overturnIf`、`boundaries`——iOS 现有 UI（AgentDeepAnalysisDetailSheet/HoloAgentResultRenderer）直接可渲染，S2 无需重构展示层。

## 2. 台账侧三处根治（比提示词更重要的防线）

1. **【已确认事实与已知风险】段**：程序生成的客观事实（双记风险+截止日、零息特征、口径限制）进台账，模型被要求逐条处理——Q3 的成功本质是「风险由程序发现，模型只负责讲清楚和给动作」。
2. **零息特征行**：`月供×期数≈合同额` 由程序算出——根治 D 编利率；利率信息未提供=不存在。
3. **方向箭头式行文（S2 待实施）**：Q2 首版与现行方法同犯「比较方向说反」（449→346 说成次数增加），修复轮证明方向核对表有效。台账对比行文统一「从去年的X变为今年的Y（增/减N）」，方向不再依赖模型理解。

## 3. 核验增强（进 T05）

- 数值核验从「数字出现过」升级为**数字+方向+分母**三对（metricAssertions 绑定 evidenceID 时含比较方向枚举）。
- 输出污染检测：正文含「等等/让我重新核对/此处需修正」等自我对话痕迹=拒收，走修复协议一次。
- 修复协议纪律沿用 04§5：一次修复、仍败则撤回，不循环。

## 5. 成本与质量基线（本轮实测）

- 16 次调用共 ≈¥0.021（qwen3.7-flash，t=0.2，思考关）；融合版单份 in≈3.0K/out≈0.6K tokens ≈ **¥0.001/份**——远低于方案 10.1 的 ¥0.10 目标，余量可容纳一次修复轮与背景。
- 质量事故账：首轮 2/12 major（A 动机归因、D 编利率）；融合版 3 份+修复 1 份=方向错误 1（已根治于台账行文）、编造 0、动机 0。
- 已知限制：单模型单温度、三题一数据源、样板非留出集——03§4.3 的 20+ 样本扩展与留出集验证在 S2 后执行，本轮结论限于「方法可行且收益来源明确」。
