## 不可更改的核心规则

- 通用快捷指令：账户默认自动识别，项目默认不挂靠。
- 固定账户/项目保存在每条快捷指令中；不读取手工记账页的上次选择。
- 用户固定对象失效时转复核，不静默回退默认值。
- 金额、币种、支付状态、收支方向不确定时不自动写。
- 多笔、疑似重复、退款与项目冲突进入复核。
- 同图连按、重试、回执丢失只能产生一笔交易。
- 账户、分类、项目、AI 来源必须在同一次 Core Data save 中落地。
- 自动成功不保存原图；待复核证据仅本机暂存并按期清理。
- 通知权限不影响主流程；聊天图片入口仍默认确认。
- 自动提交必须同时通过 iOS 本地开关、后端 `automationPolicy.autoCommitAllowed` 和本地确定性安全门禁。
