## Key Questions

1. 如何让默认路径只有一次按键，同时仍允许用户选择账户和财务项目？
2. App Intent 应直接写账还是生成待复核草案？
3. 如何保证后台重试、连按和进程退出不会重复入账？
4. 哪些改动必须发后端，哪些可以纯 iOS 完成？
5. 如何在不新增不必要 CloudKit schema 的前提下记录来源和幂等？

## Decisions Made

| Decision | Rationale |
|---|---|
| 使用独立实施包，不覆盖仓库根已有 task_plan.md | 根计划属于并行的日历任务，覆盖会破坏用户工作 |
| 更新既有正式方案，不另起冲突版本 | 保持单一事实源，GLM 不需要在多份设计中猜优先级 |
| 快捷记账不沿用手工页“上次选择” | 无界面后台运行时该隐含状态不可见，风险不可接受 |
| 参数按每条快捷指令保存 | 多场景可配置与日常一键并不冲突 |
| 首版不新增 CloudKit schema | 待复核与结果使用 App Group 本地文件，避免把设备临时流程扩散为同步数据模型迁移 |
| 增加后端自动提交总闸 | 财务自动写入必须能在不重新发版 iOS 的情况下立刻降级为全部复核 |
