> **代码真源**：`Holo/Holo APP/Holo/Holo/Utils/DesignSystem.swift`。本文是它的结构化说明；token 的最终值以代码为准，改了 token 必须同步改本文。

> **深色模式**：颜色一律走 colorset token 自动适配，**禁止用 `if darkMode` 判断颜色**（见第九节）。

## 一、颜色系统

**统一程度：✅ 强统一。** 全 App 颜色都走 token，几乎没有硬编码 hex。

### 1.1 品牌主色（固定橙，不随深浅模式变）

| Token | 色值 | 用途 |
|---|---|---|
| `Color.holoPrimary` | `#F46D38` | **主强调色**：主按钮、选中态、品牌标识 |
| `Color.holoPrimaryLight` | `#FED7AA` | 主色的浅色变体：徽章底、浅色背景 |
| `Color.holoPrimaryDark` | `#EA580C` | 主色的深色变体：渐变收尾、深色文字 |

> 说明：`holoPrimary` 是固定橙色，**不随深浅模式切换**。`Light/Dark` 后缀是同色系的明暗档位，不是浅色/深色模式。

### 1.2 背景 / 容器色（colorset，自动适配深浅）

这些颜色在 Asset Catalog 里定义了 Light / Dark 两套值，**系统切换深色模式时自动适配，代码里只写 token 名**。

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `Color.holoBackground` | `#FDFCF8` | `#1C1C1E` | 页面主背景（米白 / 近黑） |
| `Color.holoCardBackground` | `#FFFFFF` | `#2C2C2E` | 卡片背景 |
| `Color.holoGlassBackground` | 白 `@0.7` | 黑 `@0.5` | 毛玻璃浮层（底部导航、浮窗） |
| `Color.holoBorder` | `#F0F0F0` | `#3A3A3C` | 边框 |
| `Color.holoDivider` | `#F1F5F9` | `#38383A` | 分隔线（图表网格线也用它的低透明度） |
| `Color`（Shadow） | 黑 `@0.04` | 黑 `@0.20` | 阴影色（Dark 下更明显） |

### 1.3 文字色（colorset，自动适配深浅）

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `Color.holoTextPrimary` | `#333333` | `#F5F5F5` | 主文字 |
| `Color.holoTextSecondary` | `#939393` | `#939393` | 次要文字、轴标签（两模式相同） |
| `Color.holoTextPlaceholder` | `#9CA3AF` | `#6B7280` | 输入框占位符 |

### 1.4 功能 / 状态色（固定，不随深浅变）

| Token | 色值 | 用途 |
|---|---|---|
| `Color.holoSuccess` / `holoSuccessDark` / `holoSuccessLight` | `#22C55E` / `#16A34A` / `#D1FAE5` | 成功、收入、达标 |
| `Color.holoError` / `holoErrorDark` / `holoErrorLight` | `#EF4444` / `#DC2626` / `#FEE2E2` | 错误、支出、超支 |
| `Color.holoInfo` | `#60A5FA` | 信息提示、冷色热力图 |
| `Color.holoPurple` | `#C084FC` | 紫色装饰 |
| `Color.holoAI` | `#7C5CFC` | **AI 功能专属色**，与品牌橙区分，用于智能整理等入口 |

### 1.5 图表配色

12 色调色板（`holoChart1`…`holoChart12`）+ 自动取色函数 `holoChartColors(count:)`。
**详见 [`图表设计规范.md`](图表设计规范.md)**，本文不重复。图表色禁止硬编码，必须走 `holoChart*` 或语义色 token。

### 1.6 热力图色阶

唯一来源：`HoloDesignSystem.holoHeatmapColor(level:palette:colorScheme:)`，支持 `warm`（活跃/品牌橙）和 `cool`（记录数/信息蓝）两套，各 0–5 级，Light/Dark 独立色阶。
**禁止在组件里硬编码热力图 hex**，全 App 热力图色阶只从这里取。

### 1.7 分类色（记账分类）

`holoCategoryDining` / `Transport` / `Shopping` / `Coffee` / `Grocery` / `Utilities` / `Entertain` / `Housing` / `Salary` / `Bonus`，与前端原型对齐，定义在 `DesignSystem.swift`。

### 1.8 Holo Plus 主题色

`enum HoloPlusTheme`：深底渐变（`darkGradient`）、深底文字（`accentText` / `subtleText`）、徽章（`badgeBg` / `badgeText`）、光晕（`glowColor`）、描边（`strokeColor`）、浅底高亮（`plusColumnTint` / `plusValueColor`）。
**Plus 相关页面配色只从这里取，禁止再内联金色/橙色 hex。**

### 🔴 颜色红线

- **禁止硬编码 hex**（`Color(red:green:blue:)` 或 `Color(hex:)` 字面量）。新颜色必须先加到 `DesignSystem.swift` 再用。
- **禁止 `if 深色模式` 判断颜色**，用 colorset 让系统自动适配。
- `Color(hex:)` 解析器在 `Utils/Color+Hex.swift`，仅用于定义 token，不用于业务代码内联。

## 二、字体系统

**统一程度：⚠️ 一半散乱**（设计 token 约 1063 处 vs 原生 `.system(size:)` 约 1109 处，各占一半）。

> 注意：原生 `.system(size:)` 主要是**图标尺寸**（见 §8.4）和少量特殊数字显示，正文/标题应优先用下列 token。

| Token | 对应系统字体 | 用途 |
|---|---|---|
| `.font(.holoAmount)` | `largeTitle` + bold | 金额大数字 |
| `.font(.holoTitle)` | `title` + bold | 大标题 |
| `.font(.holoHeading)` | `title3` + semibold | 页面标题 |
| `.font(.holoBody)` | `body` + medium | 正文（默认） |
| `.font(.holoCaption)` | `subheadline` | 辅助/说明文字 |
| `.font(.holoLabel)` | `caption` + medium | 按钮标签 |
| `.font(.holoTinyLabel)` | `caption2` + medium | 底部导航标签 |

所有 token 跟随系统动态字体缩放（无障碍）。

### 🔴 字体红线

- 正文/标题用 token，**不要裸写 `.font(.system(size: N))` 当正文字号**。
- 图标尺寸允许用 `.font(.system(size:))`（图标不是文字，见 §8.4）。
- 金额显示（空间受限）必须用 `NumberFormatter.compactCurrency()`，禁止 `fixedSize`（见 `CLAUDE.md` 编码约定）。

## 三、间距系统

**统一程度：✅ 强统一**（约 1508 处使用，几乎替代魔法数字）。

| Token | 值 | 典型用途 |
|---|---|---|
| `HoloSpacing.xs` | 4pt | 紧凑元素间隙 |
| `HoloSpacing.sm` | 8pt | 小间隙 |
| `HoloSpacing.md` | 16pt | **标准内边距**（卡片内、列表行、水平页边距） |
| `HoloSpacing.lg` | 24pt | 段落间距、导航外边距 |
| `HoloSpacing.xl` | 32pt | 大段落 |
| `HoloSpacing.xxl` | 48pt | 页面顶部留白 |

> 图表卡片内边距约定：水平 16 / 垂直 14（见图表规范）。

### 🔴 间距红线

- **禁止魔法数字**（`padding(17)`、`spacing: 13` 这类）。用 `HoloSpacing`；确需中间值时优先用现有档位组合，不要开新值。
- 若某个尺寸反复出现且不属于现有档位，**先加到 `HoloSpacing` 再用**，不要散落硬编码。

## 四、圆角系统

**统一程度：⚠️ 较统一**（token 约 516 处，但仍有约 102 处硬编码数字）。

| Token | 值 | 典型用途 |
|---|---|---|
| `HoloRadius.sm` | 8pt | 小元素、标签 |
| `HoloRadius.md` | 12pt | 按钮、胶囊 |
| `HoloRadius.lg` | 16pt | **卡片**、主按钮 |
| `HoloRadius.xl` | 24pt | 弹窗、底部导航浮层 |
| `HoloRadius.full` | 9999 | 圆形（头像、胶囊 `Capsule()`） |

### 🔴 圆角红线

- 用 `HoloRadius`，**禁止硬编码 `cornerRadius: 18` / `10` 这类**。新增圆角值先加到 `HoloRadius`。
- 胶囊形优先用 `Capsule()` 而非 `RoundedRectangle(cornerRadius: 9999)`。

## 五、阴影与卡片

### 5.1 标准卡片（高频，必用）

```swift
VStack { /* 内容 */ }
    .holoCard()   // 卡片底 + 16 圆角 + 0.5pt 描边 + 轻投影
```

`holoCard()` 定义：`holoCardBackground` 底 + `HoloRadius.lg` 圆角 + `holoDivider.opacity(0.4)` 的 0.5pt 描边 + `black.opacity(0.035)` / radius 8 / y 3 的阴影。内容 padding 由调用方控制。

### 5.2 阴影 token

| Token | 用途 |
|---|---|
| `HoloShadow.card` / `.button` | 卡片 / 按钮常规投影（走 Shadow colorset，自动适配深浅） |
| `HoloShadow.primaryGlow()` / `.float` | 品牌橙发光（主按钮、浮动按钮） |

### 🔴 阴影/卡片红线

- 卡片外观用 `.holoCard()`，**不要每张卡手写 background + clipShape + stroke + shadow**。
- 标准卡片之外如需自定义阴影，颜色走 `HoloShadow.*` 或 `Shadow` colorset，不要硬编码阴影参数。

## 六、触觉反馈

**统一程度：✅ 最统一**（全 App 的正面榜样）。单一入口 `HoloHapticManager` / `HapticManager`。

| 方法 | 触觉类型 | 场景 |
|---|---|---|
| `HapticManager.success()` | 通知·成功 | 保存、创建成功 |
| `HapticManager.warning()` | 通知·警告 | 警告提示 |
| `HapticManager.error()` | 通知·错误 | 操作失败 |
| `HapticManager.light()` | 撞击·轻 | 计数、选择切换（最常用） |
| `HapticManager.medium()` | 撞击·中 | 打卡、任务完成、长按 |
| `HapticManager.heavy()` | 撞击·重 | 重操作 |
| `HapticManager.selection()` | 选择 | 拖拽排序、滑动选择 |
| `HapticManager.taskCompletion()` | 音效+中撞击 | 任务完成庆祝 |

### 🔴 触觉红线

- **禁止直接用 `UIImpactFeedbackGenerator` / `UINotificationFeedbackGenerator`**，一律走 `HapticManager`。

## 七、动画

**统一程度：✅ 已建立 token**（`HoloAnimation`，见 `Utils/DesignSystem.swift`）。新增动画的唯一来源；现有页面渐进迁移中，值与原习惯值一致，迁移不改变手感。

### 标准 token

| Token | 值 | 用途 |
|---|---|---|
| `HoloAnimation.quick` | `easeInOut(0.15)` | 微交互——开关、高亮、按压反馈 |
| `HoloAnimation.standard` | `easeInOut(0.2)` | 常规切换——展开/收起、淡入（默认首选） |
| `HoloAnimation.smooth` | `easeInOut(0.25)` | 较慢切换——导航高亮、板块过渡 |
| `HoloAnimation.snappy` | `spring(0.3, 0.7)` | 弹性交互——拖拽、卡片弹入、选中态（最常用） |
| `HoloAnimation.grounded` | `spring(0.45, 0.82)` | 沉稳弹性——滑动返回、大块视图位移 |
| `Animation.holoScreenTransition` | `easeInOut(0.28)` | 全屏模块转场专用（`Utils/HoloScreenDismiss.swift`） |

用法：

```swift
withAnimation(HoloAnimation.snappy) { isExpanded.toggle() }
.animation(HoloAnimation.standard, value: selection)
```

### 🔴 动画红线

- 新增动画**必须用 `HoloAnimation.*`**，禁止裸写 `.easeInOut(duration:)` / `.spring(response:)` 魔法数字。
- 含动画的交互**必须做 `reduceMotion` 兜底**（参考 `Components/BottomNavBar.swift`）。
- 现有裸数字可渐进迁移到 token（值一致，不改变手感）；不要在迁移中引入 0.18 / 0.62 这类孤立数值。

## 八、组件规范

> 现状说明：Holo 的组件层**尚未抽象成标准组件库**。下面记录的是各组件**事实上的约定写法**——改造时照此执行，保证一致性。

### 8.1 主按钮（CTA）— 事实规范

全项目没有 `ButtonStyle` 封装，但保存/确认类主按钮高度一致，**按此执行**：

```swift
Button { /* 动作 */ } label: {
    Text("保存")
        .font(.holoBody).fontWeight(.semibold)
        .foregroundColor(.white)
        .frame(maxWidth: .infinity)
        .frame(height: 56)
        .background(
            isEnabled ? Color.holoPrimary : Color.holoTextSecondary.opacity(0.3),
            in: RoundedRectangle(cornerRadius: HoloRadius.lg)
        )
}
```

| 维度 | 规范 |
|---|---|
| 背景 | `holoPrimary`（启用）/ `holoTextSecondary.opacity(0.3)`（禁用） |
| 圆角 / 高度 | `HoloRadius.lg`(16) / 56pt |
| 字体 / 字色 | `holoBody` + semibold / 白色 |
| 宽度 | `maxWidth: .infinity`（通栏） |

> 参考实现：`Views/AddTransactionView.swift` 的 `SaveButton`。

### 8.2 输入框 — 现状散乱（临时约定）

**没有统一输入框组件**。改造时若新建表单输入，按此约定保持风格：

- 背景：`holoCardBackground`，圆角 `HoloRadius.md`，padding 用 `HoloSpacing`。
- 占位符色：`holoTextPlaceholder`。
- **禁止**沿用裸 `TextField` + 硬编码 `cornerRadius` / `padding`（如 `ChatInputView` 的旧写法不应被复制）。
- 金额输入用现成组件 `Components/AmountInput.swift`。

### 8.3 弹窗 / Sheet — 现状散乱（临时约定）

约 112 个 `.sheet`，`presentationDetents` 和圆角五花八门。改造约定：

- **能确定高度的优先用 `.height(N)`**，N 取整（200 / 320 / 400 / 480…），避免 `.medium` 在不同机型高度不可控。
- **统一显示拖拽指示器** `.presentationDragIndicator(.visible)`（现状多数缺失，新建/改造时补上）。
- 内容区圆角用 `HoloRadius`，不硬编码。
- 聚焦 `UITextView` 时弹 `confirmationDialog` 有失焦竞态（见记忆 [[confirmationdialog-uitextview-race]]），改用 `.sheet(item:)`。

### 8.4 SF Symbol 图标 — 颜色统一，尺寸待收敛

`Image(systemName:)` 约 600 处，密度极高。

- **颜色**：✅ 走 token（`holoPrimary` / `holoTextSecondary` 等），统一。优先用 `.foregroundStyle`，不要用已废弃的 `.foregroundColor`。
- **尺寸**：⚠️ 散落约 18 种 size。约定收敛到以下档位：

| 档位 | size | 典型用途 |
|---|---|---|
| 极小 | 10–11 | 轴标签、角标 |
| 小 | 13–14 | 行内图标、说明 |
| 标准 | 16 | 导航、列表行图标（最常用） |
| 中 | 18–20 | 入口卡片图标 |
| 大 | 24 | 中央功能按钮 |

- 新增图标优先选上表尺寸；**新增/修改 SF Symbol 名称必须先验证存在**（`NSImage(systemSymbolName:) != nil`），无效名称渲染空白（见 `CLAUDE.md`）。

### 8.5 底部导航

参考 `Components/BottomNavBar.swift`：3 项（个人 / 中央 AI / 记忆长廊），浮动毛玻璃 `ultraThinMaterial` + `HoloRadius.xl`；左右文字按钮图标 size 16 + `holoTinyLabel`，选中 `holoPrimary`；中央 AI 按钮凸起 `Circle` 56×56 `holoPrimary` + sparkles 图标 + `offset(y: -24)`。**首页结构禁止改动**（见记忆 [[goal-feature-elevate-to-mainline]]）。

### 8.6 Toast

用 `Views/Components/HoloToast.swift`，不要自建浮层提示（避免全屏透明视图拦截触摸，见踩坑速查表）。

### 🔴 组件红线

- 主 CTA 按 §8.1 写，**不要自创按钮配色/高度/圆角**。
- 新输入框/弹窗按 §8.2 / §8.3 约定，禁止复制旧散乱写法。
- 图标颜色走 token，禁止硬编码；尺寸收敛到 §8.4 档位。

## 九、深色模式

**机制**：颜色全部走 Asset Catalog 的 colorset，**系统切换深浅模式时自动适配**，代码里只写 token 名（如 `Color.holoBackground`）。
用户还可在设置里手动覆盖（跟随系统 / 浅色 / 深色），由 `Utils/DarkModeManager.swift` 通过 `preferredColorScheme` 应用。

### 🔴 深色模式红线

- **禁止 `if colorScheme == .dark` 判断颜色**。需要 light/dark 不同的色，在 colorset 里配两套值。
- 个别确需按模式区分的**非颜色**逻辑（如热力图色阶），用 `HoloDesignSystem` 提供的 `colorScheme` 参数函数，不要自己 switch hex。
- 新增语义色时，**同步在 colorset 配好 Light + Dark 两套**，否则深色模式会穿帮。

## 十、红线汇总（禁止清单）

> 改造前、改造后各过一遍。

1. ❌ 硬编码颜色 hex / RGB —— 必须走 `DesignSystem.swift` token
2. ❌ `if 深色模式` 判断颜色 —— 用 colorset 自动适配
3. ❌ 裸写 `.font(.system(size:))` 当正文字号 —— 用 `holo*` 字体 token
4. ❌ 魔法数字间距 —— 用 `HoloSpacing`
5. ❌ 硬编码圆角 —— 用 `HoloRadius`
6. ❌ 手写卡片外观 —— 用 `.holoCard()`
7. ❌ 直接用 `UI*FeedbackGenerator` —— 用 `HapticManager`
8. ❌ 自创主按钮样式 —— 按 §8.1
9. ❌ 图标尺寸随意开新值 —— 收敛到 §8.4 档位
10. ❌ 复制旧的散乱输入框/弹窗写法 —— 按 §8.2 / §8.3 约定
11. ❌ 未验证就写 SF Symbol 名称 —— 先 `NSImage(systemSymbolName:)` 验证
12. ❌ 裸写动画魔法数字（`.easeInOut(duration:)` / `.spring(...)`）—— 用 `HoloAnimation.*` token
