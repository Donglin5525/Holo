# Holo 图表设计规范 V3

> 2026-10-16，东林确认的全模块图表组件化方案。本文替代旧版关于财务组件路径、固定细柱、双轴叠加、气泡和页面补轴带的规定。

## 唯一实现

所有模块复用 `Holo/Components/Charts`。业务页面只映射数据、单位、语义颜色及查看明细动作，禁止再实现选中公式、估算轴带、私有刻度或自绘柱线。

| 公共件 | 作用 |
|---|---|
| HoloChartFrame | 标题、周期、独立/内嵌容器、加载/空/失败状态 |
| HoloBarChart | 单柱、分组柱、横向排名 |
| HoloLineChart | 线性趋势、稀疏测量、真实时间采样、参考线 |
| HoloDonutChart | 原生 SectorMark、固定中心读数、可选分类列表 |
| HoloHeatmap | 自适应周×星期网格、日期描边、二维滑选 |
| HoloRangeTimeline | 按真实时间比例的分段、阶段读数 |
| HoloProgress / HoloProportionBar | 单值进度、圆环、多项构成比例 |
| HoloChartGeometry | 槽位、实际位置命中、色阶、断线、自然日日期迭代 |

财务旧名称 LineChartView / TrendChartView / PieChartView / CalendarHeatmapGridView 只是适配器，不再拥有画法。旧 ChartBarPairLayout 的估算接口仅保留兼容测试，不允许新界面使用。

## 数据契约

- HoloChartBucket.id 为稳定日期/区间/分类身份，不能使用每次新建的随机 UUID。
- values 的每一项与 series 同位；0 是真实数值，nil 是无记录；isFuture 是未到来的整桶，不可选。同期对比里未来本期通过 futureSeries 标记、去年仍有值时保留历史比较桶。未来的空财务桶不参与绘制；已存在的实际记录不改统计定义。
- 一般按自然桶等距排布；心率等不等距采样提供 position 真实时间坐标。图形、选中与刻度从同一个 ChartProxy 读取实际位置。
- 健康图表使用严格查询；没有样本的日期不补 0。自然日迭代使用 Calendar，不按固定 86400 秒推算。
- 折线遇到 nil 断段，孤点保留；默认线性。金额、计数、测量、比率的统计定义由业务提供；周均必须标为周日均，不冒充周合计。
- 财务金额仅在绘图边界转成 Double；原始统计与对账仍使用 Decimal。
- 拖动不查询数据库或网络，只变更选中身份；业务联动仅在身份改变时调用。

## 交互

- 柱线图：点按、横滑查看，直接纵滑交还父滚动；松手保留；数据范围/指标更换清除。
- 热力图：点按日期；按住 250ms 后二维滑选；未按住的纵滑仍滚动页面。禁止重叠扩大每格的热区，绘制与命中用同一槽位。
- 上方读数区固定显示日期、单位和值；查看明细用独立按钮或既有可点击分类列表；滑选不能触发页面跳转或弹层。
- 装饰层必须 allowsHitTesting(false)。柱线图手势覆盖层严格位于实际绘图区；传入回调的点已经是绘图区局部坐标，不可再次减轴带。
- 热力图计数色阶固定为 0 / 1 / 2–3 / 4–5 / 6–9 / 10+，颜色唯一来源 holoHeatmapColor，数量图默认使用雾蓝 mist，选中用品牌橙描边且保留原填色。0 不可与 1 同色。习惯月历的完成/跳过等业务状态不强制转成计数色阶。

## 外观与可访问性

- 独立卡片使用 HoloChartFrame(independent: true)；已有容器内保持内嵌，避免套卡片。
- 主数值 title2，说明 caption，轴默认 11pt 并随字号缩放；空间不足减少刻度。
- 实际绘图区测得的槽宽决定柱宽，单柱不超过 18pt、分组每根不超过 10pt，密集时继续收窄，不允许伸出日期槽。
- 轴带由公共件预留，业务页不能再增加“刻度溢出补偿间距”。
- 财务收支与余额上下分区，各自数值轴，同一个时间桶；默认线性，不自动隐藏尖峰。
- nil 进度显示未知，0 进度不画圆头假点；超额文字保留真实值，几何进度封顶。动画尊重减少动态效果。
- 使用语义色；单独的图例、日期、数值和 VoiceOver 文案共同表达信息，不能只靠颜色。分类明细按钮至少 44pt。

## 样例与验证

调试构建以 `-HoloChartGallery` 启动可进入原生组件样板，无需造业务数据。包含空值、零值、未来、细小扇区、缺失/零/超额进度。

基础规则运行 `bash scripts/run-chart-geometry-tests.sh`。界面测试为 `HoloChartInteractionUITests`（位于既有 HoloAcceptanceUITests.swift），验证原生点击、横滑、纵滑、热力二维滑选、细小分类入口及切换清除。现有 FinanceChartScaleTests、HabitReviewTrendChartLayoutTests 与报告兼容用例继续运行。

自动测试不替代真机手指、美观度、大字号和 iPad 现场验收；未完成的验收必须明确记录，不能用编译成功替代。
