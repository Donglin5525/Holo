# Holo 图表设计规范 v1

> **基准来源**：财务模块「统计分析 → 明细」Tab 的趋势图（`LineChartView`）
> **适用范围**：全 App 所有数据可视化组件
> **核心理念**：所有图表共享同一套「外壳 / 坐标轴 / 配色 / 交互」规范，只在「图形本体」上各自不同。就像同一套餐具，盘子和碗形状不同，但釉色、花纹、材质是一致的。

---

## 〇、一句话总览

```
┌─────────────────────────────────────────────┐
│  .holoCard()  外壳（统一）                     │  ← 所有图表必须包这层
│  ┌───────────────────────────────────────┐   │
│  │  标题 + 图例（统一排布）                  │   │
│  │  ┌───────────────────────────────┐    │   │
│  │  │                                 │    │   │
│  │  │     图形本体（各自不同）          │    │  ← 折线/柱/饼/环/热力 各显神通
│  │  │                                 │    │   │
│  │  └───────────────────────────────┘    │   │
│  │  坐标轴（统一：右Y轴 / 淡网格 / 10号字）  │   │
│  └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

## 一、分层原则：哪些必须统一，哪些允许各自不同

### ✅ 必须统一（横向规范层）
| 维度 | 规范 | 说明 |
|---|---|---|
| 卡片外壳 | `.holoCard()` | 圆角 16 + 0.5pt 描边 + 轻阴影 |
| 内边距 | 水平 16 / 垂直 14 | `HoloSpacing.md` / 14 |
| Y 轴位置 | 右侧（trailing） | 数值标签靠右，与页面右侧重心一致 |
| 网格线 | `holoDivider.opacity(0.32)` | 淡到几乎看不见，不抢戏 |
| 轴标签字号 | 10pt | `.font(.system(size: 10))` |
| 轴标签颜色 | `holoTextSecondary` | 统一次要文字色 |
| 配色来源 | `holoChart*` / 语义色 token | 禁止硬编码 hex |
| Tooltip | 4 圆角 + 卡片底色 + 轻阴影 | 见 §6 |
| 空状态 | 图标 + 一句话 | 见 §7 |
| 交互（若有） | `DirectionalChartGestureOverlay` | 横滑选点、纵滑让位 |

### 🔶 允许各自不同（图形本体层）
- 折线 / 柱状 / 饼图 / 进度环 / 热力图 / 波形 —— 形态本身不强制统一
- 图表高度（趋势图 142 / 柱状图 160~200 / 进度环按尺寸）
- 单线图的曲线平滑方式（趋势用 catmullRom，余额折线用 linear，有理由即可）

> **判断口诀**：如果你要改的是「图表怎么画」，那是本体层，自由；如果你要改的是「图表四周长什么样」，那是横向规范层，必须对齐趋势图。

## 二、卡片外壳规范（统一）

所有图表必须包裹在标准卡片外壳内：

```swift
VStack(...) {
    // 标题区 + 图表区
}
.padding(.horizontal, HoloSpacing.md)   // 16
.padding(.vertical, 14)
.holoCard()
```

`.holoCard()` 的精确定义（`DesignSystem.swift`，**不要手写替代它**）：

| 属性 | 值 |
|---|---|
| 背景 | `Color.holoCardBackground` |
| 圆角 | `HoloRadius.lg` = **16pt** |
| 描边 | `holoDivider.opacity(0.4)`，`lineWidth: 0.5` |
| 阴影 | `Color.black.opacity(0.035)`，`radius: 8`，`y: 3` |

**禁止行为**：
- ❌ 手写 `.background + clipShape + shadow`（`BudgetSummaryCard`、`CategoryComparisonListView` 当前的做法）
- ❌ 用毛玻璃 `.ultraThinMaterial`（`MonthlySummaryCard` 当前的做法）
- ❌ 自定义圆角值（12 / 20 等不一致值）

**例外**：进度环（健康三环、看板进度 hero）这类「图形本身就是主角、不需要卡片承载」的组件，可不包卡片，但其周围元素的圆角/配色仍遵循本规范。

## 三、坐标轴规范（最关键的统一项）

这是当前各图表**差异最大**的地方，也是统一后观感提升最明显的项。

### 3.1 Y 轴

| 属性 | 规范值 | 现状反面教材 |
|---|---|---|
| **位置** | `.trailing`（右侧） | Health/Habit 现在用 `.leading`（左），要改 |
| 网格线颜色 | `holoDivider.opacity(0.32)` | Health/Habit 现在用 `holoDivider`（不透明），偏重 |
| 刻度数量 | `.automatic(desiredCount: 4)` | — |
| 标签字号 | `.system(size: 10)` | Health/Habit 用 `.holoLabel`（系统字号），偏大 |
| 标签颜色 | `holoTextSecondary` | ✅ 已统一 |
| 标签宽度 | `width: 40, alignment: .trailing` | 让数字右对齐，整齐 |
| 数值格式 | 大数压缩：≥1亿→「X.X亿」、≥1万→「X.X万」、否则整数 | 见 `formatAxisValue` |
| Y 轴域 | 稳定取整（`niceCeil`），避免数据小变导致轴抖动 | 见 §3.3 |

```swift
.chartYAxis {
    AxisMarks(position: .trailing, values: .automatic(desiredCount: 4)) { value in
        AxisGridLine()
            .foregroundStyle(Color.holoDivider.opacity(0.32))
        AxisValueLabel() {
            if let val = value.as(Double.self) {
                Text(formatAxisValue(val))
                    .font(.system(size: 10))
                    .foregroundColor(.holoTextSecondary)
                    .frame(width: 40, alignment: .trailing)
            }
        }
    }
}
```

### 3.2 X 轴

| 属性 | 规范值 |
|---|---|
| 网格线 | 不画（或 `holoDivider.opacity(0.32)`，克制） |
| 标签字号 | `.system(size: 10)` |
| 标签颜色 | `holoTextSecondary` |
| 降采样 | 数据点 > 14 时，自动降到 6 个标签 |
| 绘图区左右留白 | `.plotDimension(startPadding: 12, endPadding: 12)` |

```swift
.chartXAxis {
    AxisMarks(values: axisMarkDates) { value in       // axisMarkDates 见 §3.4
        AxisValueLabel {
            if let date = value.as(Date.self) {
                Text(labelFor(date))
                    .font(.system(size: 10))
                    .foregroundStyle(Color.holoTextSecondary)
            }
        }
    }
}
.chartXScale(range: .plotDimension(startPadding: 12, endPadding: 12))
.chartYScale(range: .plotDimension(startPadding: 9, endPadding: 12))
```

### 3.3 Y 轴域稳定算法（防抖）

Y 轴最大值取「好看整数」，避免数据微小变动导致坐标轴上下跳：

```swift
/// 向上取整到整齐刻度：10 / 20 / 50 / 100 / 200 / 500 / 1000 ...
private func niceCeil(_ value: Double) -> Double {
    guard value > 0 else { return 1 }
    let magnitude = pow(10, floor(log10(value)))
    let fraction = value / magnitude
    let niceFraction: Double
    switch fraction {
    case ...1: niceFraction = 1
    case ...2: niceFraction = 2
    case ...5: niceFraction = 5
    default: niceFraction = 10
    }
    return niceFraction * magnitude
}
// 用法：.chartYScale(domain: 0...niceCeil(maxValue))
```

> **例外**：余额折线等「正负都有」的数据，不强制从 0 开始，但域范围仍需稳定（参见 `BalanceChartScale`）。

### 3.4 X 轴标签降采样

```swift
/// 数据点多于 14 个时，均匀取 6 个标签；否则全部显示
private var axisMarkValues: [...] {
    guard dataPoints.count > 14 else { return dataPoints.map(\.date) }
    let desiredCount = 6
    let lastIndex = dataPoints.count - 1
    let step = max(Double(lastIndex) / Double(desiredCount - 1), 1)
    return (0..<desiredCount).compactMap { index in
        let dataIndex = min(Int((Double(index) * step).rounded()), lastIndex)
        return dataPoints[dataIndex].date
    }
}
```

### 3.5 大数格式化

```swift
private func formatAxisValue(_ value: Double) -> String {
    let absValue = abs(value)
    if absValue >= 100_000_000 {
        return String(format: "%.1f亿", value / 100_000_000)
    } else if absValue >= 10_000 {
        return String(format: "%.1f万", value / 10_000)
    } else if absValue >= 1 {
        return String(format: "%.0f", value)
    } else {
        return ""
    }
}
```

## 四、配色规范

### 4.1 颜色优先级（从高到低）

| 场景 | 用什么色 | 示例 |
|---|---|---|
| 有明确语义 | 语义色 token | 支出 `.holoError` / 收入 `.holoSuccess` / 余额 `.holoInfo` |
| 多分类无语义 | 调色板 `holoChartColors(count:)` | 饼图分类、多系列对比 |
| 单系列强调 | `.holoPrimary`（品牌橙） | 习惯折线、健康趋势 |
| 品牌专属 | 固定 token | AI 相关 `.holoAI`（紫） |

### 4.2 语义色（来自 `DesignSystem.swift`）

| Token | Hex | 用途 |
|---|---|---|
| `holoPrimary` | #F46D38 | 品牌主色，强调 |
| `holoError` | #EF4444 | 支出 / 警告 / 超支 |
| `holoSuccess` | #22C55E | 收入 / 达成 / 正向 |
| `holoInfo` | #60A5FA | 余额 / 中性信息 |
| `holoAI` | #7C5CFC | AI 功能专属 |

### 4.3 多分类调色板

```swift
// 12 色，自动按最大色相差排列；超出 12 色用黄金角度补色
let colors = Color.holoChartColors(count: categories.count)
```

### 4.4 渐变与透明度（面积图）

```swift
LinearGradient(
    colors: [lineColor.opacity(0.14), lineColor.opacity(0.005)],
    startPoint: .top,
    endPoint: .bottom
)
```
- 面积顶部透明度 **0.14**，底部接近透明 **0.005**（不是 0，留一丝痕迹）
- 柱状图半透明叠加：收入 `holoSuccess.opacity(0.45)` / 支出 `holoError.opacity(0.88)`（支出更实，因为是主角）

### 4.5 ❌ 必须消灭的硬编码色

当前有两处热力图用了独立硬编码色阶，**必须迁移到 token**：
1. `CalendarHeatmap.swift` — 冷蓝色阶 `#F6F8FB→#345D7C`
2. `MemoryHeatmapView.swift` — 暖橙色阶 `#F5F2ED→#FF8C66`

> 迁移方案：在 `DesignSystem.swift` 新增 `holoHeatmapCool(count:)` / `holoHeatmapWarm(count:)` 工厂方法，内部基于 token 色生成色阶，消除硬编码。

## 五、交互规范

### 5.1 是否需要交互？

| 图表类型 | 交互 | 说明 |
|---|---|---|
| 趋势图 / 柱状图 / 饼图 | ✅ 需要 | 用户要「点某天看明细」 |
| 健康/习惯趋势 | 🔶 可选 | 当前无交互，建议后续加 |
| 进度环 / 进度条 | ❌ 不需要 | 纯展示 |
| 热力图 | ✅ 点击选中 | 当前已有 |

### 5.2 拖动选点 + 实时 Tooltip（标准交互模式）

所有「需要交互」的图表，统一用 `DirectionalChartGestureOverlay`：

```
手指横向滑动 → 图表独占手势，光标「吸」到最近数据点，实时弹 Tooltip
手指纵向滑动 → 图表手势让位，页面 ScrollView 立即接管滚动（不卡顿）
抬起手指     → 触发 onSelectDate，定位到该数据点
```

**为什么用它而不是系统的 `.chartGesture`**：系统的手势和父级 ScrollView 会打架，横滑时页面跟着滚、竖滑时图表抢手势，体验割裂。`DirectionalChartGestureOverlay` 在手势识别**开始前**就判定方向，从根上解决冲突。

### 5.3 选中态视觉

| 元素 | 样式 |
|---|---|
| 竖直指示线（折线图） | `RuleMark`，`lineColor.opacity(0.35)`，虚线 `dash: [3,3]`，`lineWidth: 1` |
| 竖直指示线（柱状图） | `Capsule`，`holoPrimary.opacity(0.12)`，宽 2 |
| 选中点（折线） | 双层 PointMark：外层 halo（卡片底色，symbolSize 66）+ 内层 dot（线色，symbolSize 30） |
| 选中扇区（饼图） | 沿角平分线凸出 8pt + 白色描边，未选中扇区降透明度 |

## 六、Tooltip 规范

```swift
HStack(spacing: 4) {
    Text("金额")                        // 内容
        .font(.system(size: 10, weight: .bold))
        .foregroundColor(valueColor)     // 用语义色，不用纯黑
}
.padding(.horizontal, 6)
.padding(.vertical, 4)
.background(
    RoundedRectangle(cornerRadius: 4)           // 圆角 4
        .fill(Color.holoCardBackground)         // 卡片底色
        .shadow(color: .black.opacity(0.1), radius: 2, y: 1)   // 轻阴影
)
.fixedSize()
.position(x: clampedX, y: clampedY)             // 带 clamp 防溢出
```

| 属性 | 规范值 |
|---|---|
| 圆角 | **4pt**（比卡片的 16 小，视觉层级更低） |
| 底色 | `holoCardBackground` |
| 阴影 | `black.opacity(0.1)`，`radius: 2`，`y: 1` |
| 字号 | 10pt，`bold` |
| 位置 | 跟随触摸点，但 clamp 在图表范围内防溢出（左右各留 60pt 余量） |
| 多值时 | 纵向堆叠，每项用各自语义色（支出红/收入绿/余额蓝） |

## 七、空状态规范

```swift
private var emptyChartView: some View {
    VStack(spacing: HoloSpacing.md) {                    // 16
        Image(systemName: "chart.line.uptrend.xyaxis")   // 对应图表类型的图标
            .font(.system(size: 40, weight: .light))
            .foregroundColor(.holoTextSecondary.opacity(0.5))

        Text("暂无数据，这就开始记一笔吧！")              // 引导行动的文案
            .font(.holoCaption)
            .foregroundColor(.holoTextSecondary)
    }
    .frame(height: <同图表高度>)                          // 占住位置，避免空状态塌陷
    .frame(maxWidth: .infinity)
}
```

| 属性 | 规范值 |
|---|---|
| 图标 | SF Symbol，对应图表类型（`chart.line.uptrend.xyaxis` / `chart.bar` / `chart.pie`） |
| 图标字号 | `.system(size: 40, weight: .light)` |
| 图标颜色 | `holoTextSecondary.opacity(0.5)` |
| 文案字号 | `.holoCaption` |
| 文案颜色 | `holoTextSecondary` |
| 文案语气 | 引导行动（「这就开始记一笔吧！」），不是冷冰冰的「暂无数据」 |
| 占位高度 | 与图表同高（空状态不塌陷） |

> 当前 `HabitLineChartView` 的空状态图标用 28pt、文案用「暂无数据」，需对齐到 40pt + 引导文案。

## 八、标题与图例排布

```
┌──────────────────────────────────────────┐
│ 收支趋势                  [支出][收入]    │  ← 标题左，切换器/图例右
│ 横向滑动，明细实时定位                      │  ← 副标题（可选）
├──────────────────────────────────────────┤
│                                          │
│              图表本体                      │
│                                          │
└──────────────────────────────────────────┘
```

| 元素 | 规范 |
|---|---|
| 标题字号 | `.holoLabel`（caption weight medium）+ `.fontWeight(.semibold)` |
| 标题颜色 | `holoTextPrimary` |
| 副标题字号 | `.system(size: 10)` |
| 副标题颜色 | `holoTextSecondary` |
| 图例项 | `LegendItem`：8×8 圆点 + caption 文字（定义在 `BarChartView.swift`，可复用） |
| 类型切换 | `Picker(.segmented)`，宽 136，`.labelsHidden()` |
| 标题与图表间距 | `spacing: 10` |

## 九、图表高度参考

| 图表 | 高度 | 说明 |
|---|---|---|
| 单折线趋势图 | 142pt | 趋势图基准 |
| 柱状图（单 Y 轴） | 160pt | |

## 十、迁移清单（现状 → 目标）

按「改动量从小到大」排序，建议按此顺序逐个收敛：

| # | 组件 | 现状问题 | 改动 | 难度 |
|---|---|---|---|---|
| 1 | `HabitLineChartView` | Y轴在左、网格重、空状态小、无 Y 域稳定 | Y轴改右 + 网格淡化 + 轴字号10 + 加 `niceCeil` + 空状态对齐 | 低 |
| 2 | `HabitBarChartView` | 同上 | 同上 | 低 |
| 3 | `HealthTrendChart` | Y轴在左、无外壳卡片、网格重、轴字偏大 | 加 `.holoCard()` + Y轴改右 + 网格淡化 + 轴字号10 | 低 |
| 4 | `MonthlySummaryCard` | 毛玻璃外壳 | 改 `.holoCard()` | 低 |
| 5 | `BudgetSummaryCard` | 手写外壳 | 改 `.holoCard()` | 低 |
| 6 | `CategoryComparisonListView` | 手写外壳 | 改 `.holoCard()` | 低 |
| 6 | `CalendarHeatmap` 色阶 | 硬编码冷蓝 | 迁移到 token 工厂 | 中 |
| 7 | `MemoryHeatmapView` 色阶 | 硬编码暖橙 | 迁移到 token 工厂 | 中 |
| 8 | `PieChartView` | 本体复杂但外壳/配色 OK | 仅校对外壳和配色一致性 | 低 |
| 9 | `CategoryBarLineChartView` | 死代码（未被引用） | **直接删除** | 低 |
| 10 | `KanbanProgressHero` | 品牌橙渐变底（特例） | 评估是否保留特例，或统一 | 需讨论 |

> 进度环（`HealthRingView` / `TripleHealthRingView`）、波形（`RecordingWaveformView`）属于「形态自由」组件，**不在本轮统一范围内**，仅保证配色走 token 即可。
