## 🚨 同一个 Bug 连续修不好时

**停下，先读 [`开发守则与事故预防措施.md`](开发守则与事故预防措施.md) 的「踩坑速查表」**（第四节）。

按症状查表，确认不是已经踩过并记录的坑，再动手改代码。已记录的坑包括：
- 保存后界面无响应 → 全屏透明视图拦截触摸
- **键盘弹出输入框被顶起** → iOS 17 hosting view 平移，用 `disableKeyboardAvoidance()`
- 主线程卡死 → 同步锁 / Core Data save 阻塞
- sheet 关闭后界面异常 → presentation 状态未复位
- Core Data 崩溃 → 跨上下文使用托管对象
- SwiftUI 状态不同步 → `@StateObject` 包单例
