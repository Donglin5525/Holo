## 场景2：订阅内购 HoloPlus 合规 🔄

### P0 必拒项（不修一定被拒）

1. **付费墙缺隐私政策链接** ❌
   - `HoloPlusPaywallView.swift:228-251` 的 `legalLinks` 只有"管理订阅"+"订阅条款"两个按钮，**没有隐私政策链接**。Apple 3.1.2 要求订阅页必须有两个可点击跳转链接：EULA + Privacy Policy。

2. **付费墙缺自动续费说明文案** ❌
   - 全局扫描无"自动续费/续订/扣费/如何取消"等标准披露文字（3.1.2c 最常见拒因）。必须补：标题、周期、价格、自动续费、扣费时间、如何取消/管理、隐私政策与协议链接。

### P1 高风险

3. **无公网隐私政策/用户协议 URL** ❌（跨场景硬前提）
   - App 内隐私政策/用户协议全是本地内嵌 HTML（`LegalDocumentSheet.swift`），**没有任何可公网访问的 https URL**。`holoapp.cn` 下未见 `/privacy`、`/terms` 页面。
   - 影响：App Store Connect 元数据必须有公网隐私政策 URL；Sign in with Apple 要求；付费墙链接也指向这里。**需东林在 holoapp.cn 部署页面。**

4. **价格与周期展示弱化** ⚠️
   - `HoloPlusPaywallView.swift:200` 真实账单价用 `.holoCaption`（最小灰字），周期仅隐含在商品名里。账单金额应最醒目，周期应显式标注"/月""/年"。

### P2 次要

5. 会员中心未展示到期/续费日（数据已就绪 `HoloEntitlementState.swift:18`，`HoloMembershipCenterView.swift` 没用）
6. **买断版未实现** ⚠️：`.storekit` 中 `nonRenewingSubscriptions` 为空，代码无买断商品。memory 记录的 ¥38/¥68 买断版未落地——**需东林决策 v1.0 是否含买断版**。

### 已合规 ✅
恢复购买按钮 + `AppStore.sync()`；StoreKit transaction 监听 + 后端校验 + 功能降级；product id 客户端与 .storekit 一致；无外部支付引导；EULA 用 Apple 标准 EULA；权益说明清晰。

## 场景3：AI 应用合规 🔄
