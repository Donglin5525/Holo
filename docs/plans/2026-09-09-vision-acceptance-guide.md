## 三、真机验收动线（建议 10 分钟）

1. Xcode 选真机 Run（开发证书包装到手机，走 CloudKit Development 环境不影响本功能——本功能不依赖 CloudKit）。
2. 进「对话」页 → 输入栏左侧新增的 **图片按钮** → 「拍照」或「从相册选择」。
3. **场景 A 正常记账**：拍一张真实小票/支付截图（可先在输入框打附言再选图）→ 出现「正在看图…」→ 出确认卡 → 核对金额/分类/日期 → 确认 → 去财务页看交易落账。
4. **场景 B 微信/支付宝识别**：用一张微信支付截图 → 确认后看这笔钱记没记到名字带「微信」的账户（没有该账户则落默认账户）。
5. **场景 C 转账拦截**：发一张微信转账截图 → 应收到拒识说明，不出确认卡。
6. **场景 D 防重**：同一张小票发两次 → 第二次应在确认前提示「可能已记过」。
7. 顺手看：聊天历史里自己发的图有缩略图；识别中点停止按钮能取消。

## 五、已知边界（按拍板执行，非遗漏）

- 外币拒识（拍板 7）；转账/还款/理财拦截（防虚增支出）；清单截图暂不支持转任务（二期）。
- 识别置信度低（<0.45）不出卡，引导重拍或手填——宁可问不瞎猜。
- 同一笔小票重复发送是「提示」不是「阻断」（拍板 9）。
- 聊天图片缩略图只存本机（换设备看图不跟随同步，属预期）；CloudKit 字段化留待 1.0.3 schema 增量一起做。
