# 深度分析报告：详情页展示提问 + 报告分享 · 规划

日期：2026-09-14　|　提出：东林　|　状态：待拍板（原型见文末链接）

## 一、背景与痛点

1. **看报告忘了问题**：深度分析报告是长文（数千字、多章节），看到中后段容易忘记「我当时问的是什么」。报告标题是 AI 起的（比如「熬夜变多的这一个月…」），不等于用户原话，起不到锚定作用。
2. **报告无法分享**：报告只能自己看，没有分享出口。

## 二、现状调研结论（2026-09-14 摸底）

- 报告详情页 = `Views/Chat/Analysis/AgentDeepAnalysisDetailSheet.swift`，自上而下：导航栏（返回＋「深度分析」＋scope）→ 血统条（仅追问报告显示）→ Header（✦深度分析＋「结论已核对」印章）→ 开场段（大标题＋keyInsight 强调条）→ 优先建议 → 观察章节 → 数据语境 → 证据折叠区 → 收尾卡 → 追问 dock。
- **用户的原始提问已经落库**：每份报告（一条 ChatMessage 的 `agentResultJSON`）里存有 `question`（本次提问）和 `rootUserQuestion`（追问链根问题）。云端轨道在 `finalizeCloudResult` 时由客户端回填（`HoloCloudAnalysisService.swift:427,442`）。**报告列表卡已经在显示提问，唯独详情页没显示。**
- 旧报告兼容：早期报告 `question` 可能为 nil（optional，向后兼容，做空态不显示即可）。
- 分享先例：`ThoughtShareCard.swift`（想法分享卡）已完整验证「SwiftUI 卡 → ImageRenderer 长图 → ShareLink 分享 / 存相册」全链路，含三件套：超 8000px 自动降 scale 重渲（防全透明空图）、预览图降采样到 3500px（防 GPU 纹理超限）、品牌尾注开关。纪念日分享卡是第二例。
- 报告正文是结构化 JSON（title / keyInsight / sections[] / recommendations[] / evidenceReferences[]），不是整篇 markdown，分享卡可以按层挑选内容。
- 视觉：主色 `#F46D38`，详情页卡片圆角 20–28，暖纸手账分享卡色板 ink `#3D3229` / holo `#F46D38`（固定不随深浅模式变）。

## 三、功能一：详情页展示「你的提问」

**数据**：`result.question`（缺省时退让 `rootUserQuestion`，再缺省则整个区块不渲染）——纯 UI 改动，零迁移。

**设计**：
- 位置：导航栏下方、报告 Header（✦深度分析）之前，作为整份报告的「缘起」。追问报告保持现有血统条在前、提问卡随后（血统条说明链路背景，提问卡是本报告的直接起因）。
- 样式：引文卡——「你的提问」小标签（主橙）＋ 引号装饰 ＋ 用户原话，下沿一行小字（提问日期）。风格与详情页现有卡片一致（浅底、圆角、细描边）。
- 长问题：默认最多 3 行，超出折叠＋「展开」；点展开/收起。
- 读法锚点（二期可选）：报告很长，往下滚之后提问又看不到了。可选做「滚动过 Opening 后，导航栏下方出现一条可点的小胶囊『回看提问 ⇡』，点击滚回顶部」。**先不做，看实际体感。**

**改动面**：仅 `AgentDeepAnalysisDetailSheet.swift`（+ 新文案三语）。

## 四、功能二：报告分享

**入口**：详情页导航栏右上角分享按钮（square.and.arrow.up 图标，与项目「动作在右」惯例一致）。

**交互**：点按钮 → 弹出分享预览页（沿用想法分享卡的「深色舞台」形态）：中间滚动预览长图，底部操作条（主按钮「分享」＝系统分享面板 ShareLink、次按钮「存相册」）、品牌尾注开关（独立于想法卡的开关，默认开）、一行隐私提示小字「分享图包含你的个人数据分析，请确认后再发送」。

**分享卡内容（自上而下）**：
1. 品牌头：HOLO 标识 ＋「深度分析」章 ＋ scope 与日期（如「近30天 · 2026年9月」）；
2. **提问引文块**（呼应功能一：看分享图的人先知道这份分析回答了什么问题）；
3. 报告大标题（衬线）；
4. 核心结论（keyInsight，橙色强调）；
5. 优先建议（序号圆）；
6. 观察章节。
7. 品牌尾注（金线侧脸 ＋「HOLO · 人生数据库」，可开关）。

**内容范围双档**（预览页顶部切换，需拍板）：
- **完整报告**：提问＋标题＋结论＋全部建议＋全部观察章节；跳过证据明细、数据语境、追问记录这些「App 内交互性内容」。长图高度随内容生长，沿用 8000px 降 scale 策略，数千字报告预计 1–2 万 px，降 scale 后仍可读。
- **核心摘要**：提问＋标题＋结论＋优先建议，一屏短卡，适合快速转发。

**不做**（明确排除）：分享图数据遮蔽/脱敏（过度设计）；PDF/文本导出（先只做图片）；报告列表页长按分享（详情页一个入口够）。

**工程**：新建 `ReportShareCard.swift` ＋ `ReportShareSheet.swift`，整套复用 `ThoughtShareCard` 骨架（340pt 宽、3x、降 scale、预览降采样、ShareLink、存相册）。风格沿用暖纸手账（固定色板，不随深浅模式），与想法分享卡形成统一的「HOLO 出品」识别。

## 五、工程影响评估

- **纯 iOS，无需后端发版**（提问数据本地已有；分享是本地生图）。
- **无 CloudKit schema 变更**。
- 旧报告（question 为 nil）：提问区块不显示，分享卡提问块同样缺省跳过。
- 测试：详情页提问展示/折叠 XCUITest；分享卡渲染冒烟（长报告触发降 scale 路径）。
- 多语言：新增文案同步 zh-Hans / zh-Hant / en 三语。

## 六、需要东林拍板的点
