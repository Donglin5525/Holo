新用户激活一期 · 设计稿

2026-09-14 · 配套方案：docs/plans/2026-09-14-new-user-activation-p0-plan.md
目标：新用户落地后，整个首页只保留一个行动指令——「对 Holo 说第一句话」；完成前一直在，完成后自动消失。
手机画面为浅色模式还原（品牌橙 #F46D38 / 背景 #FDFCF8 / 球 192pt / 五角形半径 155pt），与真机观感对齐。

① 现状对照：新用户首屏「十个入口、零个动作」

这是用户反馈的问题现场：中央球、五个功能钮、底栏三个入口全部是「去某个地方」，没有一个指令告诉他「现在做这件事」。点进任何模块都是空的，空态只有一句陈述。

现状 · 新用户首页
问题清单
✗ 10 个可点目标全是导航，零个动作指令
✗ AI 一句话记录是核心能力，但只能靠导览一句话传达，跳过引导的人完全不知道
✗ 各模块空态是陈述句（「暂无交易记录」），没有「从这里开始」的按钮
✗ 第一次记录成功，系统毫无反馈

② 首页「第一步行动卡」——三个位置方案（拍板点 1）

约束：不能破坏已定稿的光球+三环视觉。三个方案都做到：点卡片 → 跳 AI 对话并预填「午饭花了 35 元」（只预填不自动发送）；出现第一笔记录后自动消失；可 × 手动关闭。

方案 A · 问候下横条推荐
一条轻横条，挂在问候语正下方——视线落点第一站
✓ 位置最高，新用户进来第一眼就看到，不遮挡球和五角形
✓ 形态轻（像系统通知条），对定稿视觉侵入最小
✓ 老用户升级后即使误现也易关闭
✗ 信息量少，只能放一句标题+一句示例，没有大按钮
方案 B · 五角形下行动卡备选
一张完整任务卡，落在球区和底栏之间的留白里
✓ 指令感最强：标题+示例句+橙色大按钮，最像「该做这件事」
✓ 有空间放完整引导文案，转化路径最短
✗ 占用球下方空间，需把球区压矮一点，对定稿构图有扰动
✗ 视觉最重，新用户看完若不操作，卡片一直在首页压场
方案 C · AI 按钮气泡备选
不加卡，在中央 AI 按钮上浮一个指向气泡+虚线光圈
✓ 最轻，页面零改动，直接把人引到正确的入口上
✓ 「入口」和「指令」合一，看到气泡就知道往哪按
✗ 信息量最少，讲不清「为什么/能干什么」
✗ 底部是视觉边角，容易被忽略；点空白处消失后就再无触达

③ 空态升级：从「陈述句」到「起点」（拍板点 2）

原则：空态不再只是描述「这里是空的」，而是给出一个可以直接按的按钮，一键直达新建表单/编辑器。按钮样式统一用品牌橙实底、圆角 12，与看板主行动按钮同语言。

④ 「记录今天」语义修正（拍板点 3）

现状：看板底部「记录今天」按钮打开的是想法编辑器，字面像「记录今天的一切」，新手容易误解。两个改法二选一：

改法一 · 只改文案（改动最小）按钮文案改为「记想法」，图标不变。语义准确，零行为变化。
改法二 · 改指向（与本期方向一致）按钮改为「对 Holo 说」→ 跳 AI 对话并预填。让看板的唯一行动出口与行动卡同方向；但看板底部与「＋开始一件事」功能重复，需接受。 推荐

⑤ 首次记录成功庆祝（拍板点 4）

触发条件：保存人生第一笔记录时（保存前全库计数为 0）。只在「记一笔」主路径触发（含 AI 记账落库），一次即落盘永不重现，老用户永远不触发。点「去长廊看看」→ 关浮层并跳记忆长廊。

首次记账成功 · 庆祝浮层
设计说明
✓ 轻浮层而非全屏庆祝页——庆祝完仍留在原处，不打断
✓ 一句话点出产品叙事「人生数据库开始运转」
✓ 唯一按钮指向记忆长廊：让用户亲眼看到自己的记录长出了第一条
✓ 无按钮路径：点浮层外任意处关闭，「以后再说」
✓ 触发一次即落盘，重启/再次记账都不再出现
