# 新用户激活一期（轻量版）：第一步行动卡 + 空态 CTA + 首次庆祝（2026-09-14）

> 背景：用户反馈「首次进来界面太复杂，不知道该干什么」。
> 引导 V2（9dece11f，聚光灯导览+欢迎条）已解决「入口在哪」，但没解决「落地后做哪件事」——
> 该档案第五节第 1 条当时已预判「V1 行动式结尾是激活率最大抓手」，本次启动就是回应这个预判的轻量先行版。

## 一、诊断（四个结构性缺陷）

| # | 缺陷 | 事实依据 |
|---|---|---|
| 1 | 引导教「地图」不教「目的地」 | 4 页引导+三步导览全部在讲入口位置，讲完用户仍无行动指令 |
| 2 | 新用户首屏「十个入口、零个动作」 | 首屏 10 个可点目标（中央球+五角形5+底栏3+设置）全是导航，没有一个是直接动作 |
| 3 | 无第一次成功体验 | 全 App 无新手任务/首次庆祝机制，价值闭环全靠用户自己撞 |
| 4 | 跳过即失联 | 跳过引导后无二次触达；「AI 一句话记录」核心能力只靠导览一句话传达 |

复杂感的真正来源不是入口数量，而是「每个都想让你看，没有一个让你做」。

## 二、已拍板决策（东林，2026-09-14）

1. **首次核心动作 = AI 一句话记录**（押注「人生数据库」心智，与导览第 3 步口径一致）。
2. **一期范围 = 轻量版**：首页行动卡 + 空态 CTA + 首次庆祝。V1 行动式结尾、通知权限时机、新手里程碑留二期。

## 三、一期方案

### 3.1 首页「第一步行动卡」（核心件）

- 新组件 `Components/FirstStepActionCard.swift`，挂载 `HomeView.swift`。
- **显示条件（与门）**：
  1. `LightweightOnboardingSettings.isCompleted == true`（走完或跳过引导）；
  2. 未手动关闭（`OnboardingProgressStore` 新 key）；
  3. **全库无记录**：交易 / 任务 / 想法 / 习惯（含打卡）计数全为 0。
     口径：任一存在即视为「已激活」，永不再显示。评估时机：首页 onAppear + 记录变更通知。
- **交互**：点卡片 → 跳转 AI 对话并预填示例句「午饭花了 35 元」到输入框（**只预填不自动发送**，沿用 `handleCapabilityTap` 的 .todayState「确认权在用户」原则；通道复用 `ChatViewModel.inputText` 直接赋值 / DeepLink `.chat(prefill)`）。
- **消失**：产生任一记录自动消失；× 手动关闭落盘不再出现。
- 视觉约束：不破坏已定稿的「光球+三环+球内弧形铭文」视觉；位置/形态以设计稿拍板为准（三候选：问候下横条 / 五角形下行动卡 / AI 按钮气泡）。

### 3.2 空态 CTA 化

| 模块 | 现状 | 改法 |
|---|---|---|
| 财务 | EmptyStateView 纯文字「点击 + 按钮记录第一笔交易」（FinanceComponents.swift:362） | 组件加 CTA 按钮参数，账本/账户空态传「记一笔」直达新增表单（Form 内 Button 必须 plain 的坑在档） |
| 任务 | 「点击右下角 + 创建第一个任务」纯文字（TaskListView.swift:1435） | 加「创建第一个任务」按钮直达新建 |
| 想法 | 「点右下角 + 记录第一条想法」纯文字（ThoughtListView.swift:1332） | 加「记录第一条想法」直达编辑器 |
| 看板主卡 | calm 态「今天没有必须立刻处理的事」无按钮（TodayPrimaryFocusCard.swift:135） | 补行动出口指向 AI 一句话（与行动卡同方向） |
| 「记录今天」语义 | 打开的是想法编辑器，语义易混（TodayOverviewSection.swift:53） | 文案或指向微调，以设计稿拍板为准 |

### 3.3 首次记录成功庆祝

- 触发：保存**人生第一笔**记录时（保存前全库计数为 0），一期收敛在「记一笔」主路径（含 AI 记账落库）。
- 形态：轻量庆祝浮层（微动画 + 「第一条记录完成，你的人生数据库开始运转了」+ 去长廊入口）；触发一次即落盘，永不再现。
- 老用户永远不触发（有存量数据）。
