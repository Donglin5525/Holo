# 睡眠「整晚时间轴」重设计方案

日期：2026-09-14
状态：已实施（2026-09-14 东林拍板"可以，开工"）；编译绿、三睡眠测试套件 9+5+8 全绿、模拟器走查全过；**待东林真机验收后提交**
范围：纯 iOS，**无需后端发版**
配套视觉稿：`docs/plans/2026-09-14-sleep-timeline-redesign-mockup.html`

---

## 一、问题：用户看到了什么

东林 9 月 14 日真机截图（当天白天有过一次午睡，晚上正常睡）：

- 时间轴横轴从 **12:00 画到 08:30**，真正的夜间睡眠只占右半边；
- 统计行写着 **「入睡 12:00」**——中午十二点入睡，荒谬；
- 条带左侧一截粉色块之后是长达约 8 小时的空白底色，看起来像"躺着没睡"；

- 条带上密密麻麻的细条纹，分不清哪段是什么；

- 条带上方飘着 **03:18、07:31、07:42** 三个红字，没有任何说明是什么意思；
- 统计行「深睡集中 —」，但下面解读文案却说"深睡分布偏后半夜"——**同一个数据两处说法自相矛盾**（一个显示无数据，一个下了结论）。

结论：这张卡不是"丑"，是**信息错误 + 坐标系错误 + 口径自相矛盾**三件事叠加，任何人看不懂是必然的。

## 二、诊断：五个根因（已逐行核对代码）

### 根因 1｜"一晚"的定义吞掉了白天小睡（数据层，最上游）

`HealthRepository.swift:532-535`：归晚窗口 = **前一天中午 12:00 → 当天中午 12:00**，窗口内所有睡眠样本一律算作"这一晚"。

后果：13 日午后的午睡被并入 13 日晚的"一晚"，于是：

- "夜晚"从 12:00 开始，轴被拉成 20.5 小时，真正的夜间睡眠被压到右半边；
- 「入睡」取窗口内最早样本起点（`HealthRepository.swift:652`）→ 显示 12:00。

### 根因 2｜条带渲染"空隙不留白"，两套坐标系打架（渲染层）

`HealthSleepTimelineCard`（`SleepTimelineCard.swift:73-82`）：所有分段用 HStack **首尾相接顺铺**，每段宽度 = 时长比例。但注释声称"段间空隙由渲染层留白"——**实际实现没有做**。

同时，夜醒红字标注用的是**真实时间比例定位**（`SleepTimelineCard.swift:107`）。

后果：小睡和夜睡眠中间约 8 小时没有样本，条带却把它们**拼在一起画**；红字却按真实位置飘。条带和红字各说各话，整个图完全失去"时间"含义。夜间内部的手表摘下空档同样会错位。

### 根因 3｜细条纹灾难（渲染层）

`SleepTimelineCard.swift:77`：`max(2, 实际宽度)` ——几秒的微小样本也被强制画成 2pt 宽的条，比例失真且制造大量假条纹；Apple Watch 的分期样本天然碎片化（分钟级 core/REM 交替），同阶段相邻样本之间若有一秒级缝隙，归并函数（`merged()` 只合并重叠/相接）就断开，形成细碎条纹；相邻矩形接缝还有抗锯齿白线。

### 根因 4｜「深睡集中 —」与"偏后半夜"自相矛盾（口径层）

"深睡集中"按**前半夜深睡占比**计算。因为小睡把"夜晚中点"推到了 22:15（`SleepStructureAnalyzer.swift:66-69`），深睡全部落在"前半夜窗口"之外 → 占比算出 0% → 统计行有 `ratio > 0` 门槛显示"—"（`SleepTimelineCard.swift:198`），而解读文案没有这个门槛照样说"偏后半夜"（`SleepTimelineCard.swift:221-223`）。**同一个 0%，一处当"无数据"、一处当"结论"**。本质还是根因 1 的下游，但口径不统一要单独修。

### 根因 5｜标注语义不明（设计层）

红字 = 夜醒时刻（≥2 分钟的清醒段，`SleepTimelineCard.swift:129-133`），但页面上没有任何图例或文字解释；07:31 与 07:42 是清晨"醒了赖床"的两段，也被当"夜醒"标出来；轴中间的 22:15 是"夜晚中点时刻"（`SleepTimelineCard.swift:147-149`），对用户是无上下文的噪音。

## 三、设计原则（第一性原理）

这张卡要回答的唯一问题：**「昨晚我睡得怎么样？」**

由此推出三条铁律：

1. **只画"这一晚的主睡眠"**。白天小睡不是"这一晚"，必须请出去（但不消失，单独一行带过）。
2. **一个图只有一套坐标系**。条带、刻度、标注全部按真实时间比例定位，空隙就留白。
3. **每个数字要么有明确定义，要么不显示**。同一个数据在卡内不允许两种说法。

## 四、方案

### 4.1 数据层：给"一晚睡眠"下定义（根治根因 1、4）

新增纯函数模块 `HealthSleepSessionSplitter`（新文件，不改动现有 Builder/Analyzer）：

- 输入：归晚窗口内的全部样本（现有查询结果，原样）；
- 聚类规则：睡着类样本（深/核心/REM/未分期）之间**时间间隔 < 3 小时**归为同一"睡眠会话"；每个会话向外吸收与边缘**间隔 < 60 分钟**的在床/清醒样本作为"上床/赖床"尾巴，吸收后边缘外扩、可级联延伸到真实上床/离床点为止（间隔 ≥ 60 分钟视为起床后的行为，不并入，避免上午间歇躺床把轴拉长）；
- **睡着总时长最长的会话 = 主睡眠（夜间）**，其余 = 小睡；
- 输出：主睡眠样本集 + 小睡列表（次数、总时长）。

下游全部改吃主睡眠样本集：

| 指标 | 现状口径 | 新口径 |
|---|---|---|
| 入睡 | 窗口内最早样本起点（含在床/小睡）→ "12:00" | 主睡眠首个睡着样本起点 |
| 起床 | 窗口内最晚样本终点 | 主睡眠最后一段（含赖床尾巴）终点 |
| 夜醒次数 | 清醒≥2分钟段数（含清晨赖床） | 主睡眠**内**清醒≥2分钟段数，**末段清醒（终醒）不计** |
| REM 段数 / 深睡集中 / 入睡耗时 | 全窗口 | 仅主睡眠；"夜晚中点"= 主睡眠中点 |
| 时间轴窗口 | 12:00→08:30（20.5h） | 主睡眠窗口（典型 8–10h） |

- 顶部「睡眠阶段」总量卡**维持当日总量口径（含小睡）**，与苹果健康一致，不动；
- 小睡在时间轴卡内以一行灰字带过：「白天另有小睡 1 次 · 约 1 小时 20 分，未计入上图」。

> 该设计的好处：`HealthSleepTimelineBuilder` 与 `SleepStructureAnalyzer` 两个既有模块**零改动**，既有 13 个测试零迁移；会话切分是它们上游的一个独立纯函数，可单测全覆盖。

### 4.2 渲染层：重写条带（根治根因 2、3、5）

`SleepTimelineCard` 重写，结构从上到下：

1. **时刻锚点行**：左「入睡 23:47」右「起床 07:42」，正文色、带文字标签（取代裸红字；红色弃用）。
2. **条带**：ZStack 按 `(start − 窗口起点) / 窗口跨度` **真实比例定位**（弃用 HStack 顺铺）；
   - 空隙 = 留白（胶囊底色），不再冒充"躺着"；
   - 删除 `max(2, …)` 最小宽度；< 40 秒的微小清醒段并入底色不单独画；
   - 同阶段相邻样本**缝隙 < 2 分钟自动缝合**（消灭细碎条纹的主要手段）；相邻段绘制重叠 0.5pt 消抗锯齿白缝；
   - 在床但未睡（上床/赖床）= 浅米灰，与"清醒"灰区分；**色值需比卡片底色深至少一档**（视觉验收已发现过浅会导致用户看不出条带尾部的"赖床"段）。
3. **刻度行**：按整点每 2 小时标刻度（00:00、02:00…），**删掉"夜晚中点时刻"**。
4. **图例行**：● 深睡 ● 核心 ● REM ● 清醒 四色小图例（颜色与顶部阶段卡完全一致）。
5. **统计行 4 项**：夜醒 / REM / 入睡耗时 / 深睡集中（入睡、起床已上移到锚点行，不再重复；「入睡耗时」是新换入的既有指标）。
6. **小睡行**（仅当日有小睡时出现）：灰字带过。
7. **解读文案**：输入改为主睡眠特征后沿用现有生成逻辑；删除统计行 `ratio > 0` 门槛，0% 是合法值（显示"后半夜"），与文案口径统一；只有真正的 nil 才显示"—"。
8. 夜醒**不再逐个标时刻**（次数在统计行）；条上的清醒灰段本身就是位置信息。

### 4.3 边界情形

| 情形 | 行为 |
|---|---|
| 正常一晚（绝大多数，无小睡） | 与现状几乎一致，仅渲染更干净 |
| 当日有小睡（东林 9-13） | 主图只画夜睡眠；小睡一行带过 |
| 夜里起 2 小时又睡回 | 间隔 < 3h，仍算一个主睡眠 |
| 真劈成两段睡（间隔≥3h） | 取长者为主睡眠，短者按小睡带过 |
| 无手表（只有未分期睡眠） | 现有引导态不变 |
| 手表中途摘下（夜间空档） | 真实留白，刻度仍可读 |

## 五、实施清单

- **批 1（数据层）**：新建 `HealthSleepSessionSplitter.swift` + 单测（单会话/小睡分离/多小睡/3h 阈值/尾巴吸收/无睡着段）；`HealthRepository` 两处睡眠查询（时间轴+明细）接入主睡眠过滤；`HealthSleepDetail` 增加小睡摘要字段。
- **批 2（渲染层）**：重写 `SleepTimelineCard`（真实比例定位、刻度计算纯函数+单测、图例、锚点行、统计行 4 项、小睡行）；文案入 `Localizable.xcstrings` 三语。
- **批 3（验收）**：模拟器 mock 双状态走查 + 东林真机验收。
- 回归保障：既有 Builder/Analyzer 13 个测试不动且必须全绿；详情页现有 XCUITest 不动。

## 六、拍板点（需要东林定）

1. **统计行第 3、4 项**：推荐「入睡耗时 + 深睡集中」；备选：维持原 5 项（与锚点行重复，不推荐）或只留「夜醒 / REM」两项。
2. **「深睡集中」这个指标留不留**：推荐保留（解读文案依赖它）；若你觉得"前半夜/后半夜/均匀"太术语，可换成「深睡时长」（顶部卡已有，略重复）。
3. **小睡的呈现**：推荐时间轴卡内一行灰字；备选：完全不说（信息丢失）。
4. **夜醒时刻标注**：推荐完全去点（最干净）；备选：只标最长一次夜醒的时刻。
