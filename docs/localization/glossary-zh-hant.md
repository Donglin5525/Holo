## 三、简繁一对多陷阱字（逐字核对清单）

这些简体字对应多个繁体字，转换错了整句都露馅，转换后重点搜检：

| 简体 | 应为 | 错成 | 场景 |
|------|------|------|------|
| 签 | 簽（补签/签到/签名） | 籤 | ⚠️「补签」是打卡语境，OpenCC 按字面转成「補籤」（抽签义）是错的；但「標籤」的籤是对的——只修「補籤」词组，已加进 fill-zh-hant.sh |
| 项目 | 項目 | 專案 | ⚠️ App 内「项目」均为列表条目义（支出项目/周期性项目），保留「項目」；台湾「專案」指工程/计划义，语义会漂。已在 fill-zh-hant.sh 加「專案→項目」修正 |
| 账 | 帳 | 賬 | 账本/账户/记账，全 App 统一「帳」。⚠️ OpenCC s2twp 实测输出「賬」（香港写法），已在 fill-zh-hant.sh 加「賬→帳」后处理修正，机器转换后仍需搜检 |
| 里 | 裡 / 里 | 全「裡」 | 「这里→這裡」表方位用裡；「公里」长度单位保留「里」 |
| 后 | 後 / 后 | 全「後」 | 「之后→之後」；「皇后」保留（App 内基本无） |
| 发 | 發 / 髮 | | 「发送→發送」；「头发→頭髮」（App 内基本无） |

## 四、定名原则

1. **产品词从简**：能同形就同形（回放不用重播、看板不用儀表板），保持简繁用户的界面心智一致
2. **两岸惯用词该换就换**：用户日常读得到的动作词（匯入、設定、資料）跟随台湾习惯，s2twp 自动处理为主
3. **品牌词零翻译**：Holo、Plus、AI 保持原样
4. **机器转换 + 人工兜底**：一切以本表为终审，机器与人工冲突时以表为准，表没覆盖的新词先查 s2twp 结果再入表
