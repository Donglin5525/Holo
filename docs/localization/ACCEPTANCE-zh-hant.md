## 六、配套工具（后续维护用）

| 工具 | 用途 |
|---|---|
| `docs/localization/scan-pending.py <目录>` | 扫描待本地化中文行 |
| `fill-from-stringsdata.py <derivedData> <主表> [小组件表]` | 构建后把提取词条写回词表（含双表分流） |
| `fill-zh-hant.sh [词表] [--force]` | OpenCC 繁体填充（含 3 条修正规则，不覆盖人工校对） |
| `glossary-zh-hant.md` | 术语表（新增文案请对照维护） |
| `string-refactor-guide.md` | 改造规范（新功能文案照此写） |

**新功能流程**：正常开发 → 构建一次 → 跑 fill-from-stringsdata → 跑 fill-zh-hant → 提交时带上 xcstrings。三步脚本，中文文案会自动进表自动转繁。
