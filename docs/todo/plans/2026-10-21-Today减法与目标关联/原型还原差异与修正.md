# 原型还原差异与修正

2026-10-21。对照基准是最后确认的 `holo-today-goals-integrated.html`，不是早期愿望星图或长卷探索稿。

## 上一轮为什么看起来不一样

上一轮完成了数据、保存、来源和目标要求的联动，但把原型的叙事长卷做成了指标清单。功能测试证明操作链可用，不能证明视觉还原合格。此前“按方案实施完成”的表述没有充分区分这两件事。

| 原型要求 | 上一轮原生偏差 | 本轮修正 |
|---|---|---|
| 今天：暖色卡片、独立当前事实、目标说明、全宽实心入口 | 描边白卡、金额和目标混在一行、只用文字链接 | 按原型恢复卡片结构与实心入口 |
| 今天：其他安排、日常入口、底部记账/对Holo说 | 圆角任务组、日常入口收进折叠、大块帮理入口 | 恢复连续行和显性日常入口，低频安排仍可展开 |
| 详情先是长卷和目标标题 | 旧概览、期望结果、截止信息抢在长卷前 | 详情开头恢复长卷层级，完整元信息移入设置 |
| 叙事段落中的数字可点 | 一列金额、次数和分钟 | 恢复25点叙事、行内数字来源链接与左侧章节线 |
| 想达成什么 / 为此做的安排 | 只在每行小字写角色，列表平铺 | 明确分区，避免重复绘制旧限制绑定 |
| 对折、调整、回顾、关注各有层次 | 小块对照文字、窄按钮，分析卡直接占正文 | 两列对照、全宽调整入口、回顾与历史入口、设置省略号 |
| 目标列表连续行 | 图标卡片和粗标题 | 连续行、细分隔、状态在右侧 |
| 统一轻字重、22点页面边距、暖色局部容器 | 默认通用组件拼接 | 局部样式契约与两组局部颜色资产，未改全局品牌色 |

## 还原用到的具体数值

页面边距22；标题30；叙事25且行距10；重点标题22；当前事实31；行标题16、右值17、注释12；来源行至少68高；主按钮至少48高、14圆角；重点卡片21内边距、20圆角。颜色遵循原型的局部深橙 `#C54A08` / `#FF8A5C` 与暖色容器 `#F7F1EA` / `#252322`。数字、原始记录、保存和判断规则继续使用上一轮同一事实源。

这些是原型结构和样式数值的对齐；没有声称系统导航、系统表单和网页控件已逐像素相同。没有改模型、CloudKit、Prompt或后端。

## 功能保留

- 单账户储蓄、多习惯与多模块要求不变；来源数值可纠错、确认与未知仍区分。
- 目标设置保留授权、提醒、原关联、手动记录和生命周期操作；从省略号与页尾入口进入。
- 分析、历史和修正仍使用原报告链，收在“查看回顾与历史”，保留服务端开关。
- 手动编排的今天计划继续用原计划分组与冲突处理；普通安排改连续行，完整任务模块、习惯模块与财务仍为原入口。

## 二级动线的补齐（2026-10-21 晚）

继续对照同一份已确认原型，补齐“今天 → 长卷 → 原记录 → 调整约定”的后半段：

- 来源明细恢复原型的范围、独立汇总、连续原记录和下划线切换；每行明确提示编辑，保留左滑/长按删除、记录与补录。每日确认使用同一排版，未知与明确未发生分开。
- 来源页增加反向目标关联，显示同一习惯在不同目标中的实际要求，并能打开对应目标。反向查找只读当前计划，不给其他目标新建版本；与约定编辑共用要求说明。
- 约定编辑改为连续页面：成功条件、折叠的来源要求、资金安排、采用前变化预览、独立确认及全宽保存。当前/新要求显示在同一预览中，继续走原版本冲突检查、幂等提交和未保存离开保护。
- 补上数字键盘的“完成输入”；最大辅助字号下，明细切换和关联入口改为纵向排列；禁用主按钮有明确弱化状态。
- 今天连续任务行接入既有完成协调器的待确认状态，提供同一3秒窗口内的就地撤回。

本轮未改变结果计算、原始记录保存服务、数据模型、CloudKit或后端。原模块的记录编辑/补录、账户、任务详情仍复用既有页面，不声称系统控件与网页逐像素相同。
