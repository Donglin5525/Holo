> 2026-10-21 后续反馈：本稿中Today内新增、记录与重排的方向已被东林否决，保留为历史。后续边界以同目录 `Today只读概览与原模块边界.md` 为准，不再按本稿实施。

2026-10-21。对应东林真机反馈：无目标时页面断裂，记账/对Holo说缺少上下文，底部“更多安排与日常状态”使用户难以继续行动。本文件是待评审的新提案，不覆盖此前已确认的原生实施契约。本轮不改原生、真实数据、后端或云端。

## 产品结论

此前主要完成了目标长卷与来源操作的一致性，却没有统一 Today 的阅读逻辑。当前 `DailyKanbanView.todaySections` 有目标时走 `TodayGoalFocusSection`，无目标时走旧 `TodayPrimaryFocusCard`，之后无条件拼接 `GoalJourneyTodayLinks`，再把事项、习惯、财务/健康和帮理入口一起折叠。后果是主行动、原模块入口和记录摘要处在同一层，却没有说明用户为什么要跳过去。

新的 Today 只回答：现在从哪里开始，之后还有什么，刚做过/记过什么。目标是行动的来处及进展背景，不决定是否能使用这个页面，也不替换主行动。

## 一条主线

打开今天 → 当前一步 → 原任务/原习惯操作 → 回到同一份安排 → 当前一步/后续安排更新 → 回看刚发生的记录。

- 当前一步和后续安排连接在同一条连续清单中；时间固定的日程明确显示时间，不伪装成可勾选任务。
- 无目标时直接使用真实任务、习惯、日程；不出现空目标卡或创建目标的门槛。
- 有目标时沿用同一页面。关联任务里显示目标与当前事实，关联习惯显示其独立窗口/单位，点击看既有长卷。完成准备事项不增加专款，记录阅读不变更要求。
- 完成一件事后由今天原已选择的下一项接上，不再自动塞入另一批积压任务。只选了某个既有步骤时，做完该步即可结束今天的选择，根任务继续未完成。
- 今天没有安排时只邀请添一件事；真正没有习惯时不虚构既有习惯和历史记录。完成场景保留实际日程、原记录与已明确放下的安排，不伪造“所有事情都已解决”。

## 两个明确的分支

### 安排变了：调整今天

“调整今天”放在今天安排的标题旁。表达情况/自己选择 → 预览保留、只推进某一步、今天先放下及固定日程 → 对已过截止的放下单独确认 → 采用 → 回到更新后的同一页。采用前不写事实或计划；采用后可撤销本次选择。撤销不撤销已经真实完成的步骤或新增原记录。

这是现有 TodayRelief 的清晰入口，不是泛化 HoloAI 聊天入口。原型中的自动预览是本地演示规则，不调用模型。

### 刚发生一件事：新增

右上角“＋”统一新增一件事、习惯记录、一笔收支、一个想法。任务明确选择是否也加入今天；记账/想法保存后回到原安排，并在“今天留下的记录”看到结果。记录支出不会改掉当前重点或自动生出新的待办。

从目标或来源明细编辑阅读后，返回相同来源位置；不会不分来路一律扔回今天。取消不保存，离开有输入的表单先提供继续编辑/放弃。

## 旧功能的去向

| 原内容 | 新的位置与职责 |
|---|---|
| 任务与习惯 | 当天真正要做的进入连续安排；所有任务/习惯仍在原模块 |
| 记账 | “＋ → 一笔收支”；实际支出在当天记录和原财务回看 |
| 对Holo说/帮我理一理 | Today 内以“调整今天”表达目的；全局聊天入口仍由原导航提供 |
| 目标摘要/完整长卷 | 放在相关行动的背景中，点开仍是原目标；所有目标由管理入口进入 |
| 事项/Matter | 当前可执行行动进入今天；整件事与讨论保留原事项入口 |
| 健康/预算/财务状态 | 有来源的事实在当天记录/原模块核对；正常状态不强占主行动。确需处理的确定性异常须给出明确核对动作，不能藏进模糊折叠区 |
| 其他全部内容 | 右上角“管理全部内容”进入明确命名的原模块；不再在页尾搭一组通用模块摘要 |
| 已完成/今天放下 | 属于今天安排的状态，有明确来源与恢复动作；不是装杂项的“更多”抽屉 |

原页面的关闭、主导航、任务多视图、习惯设置/回顾、目标生命周期、账户/预算、报告入口继续保留。原型只聚焦上述动线，未重画全部旧模块功能。

## 实施前必须守住的边界

1. Today 是同一事实源的行动投影，不新建影子任务/习惯/账单；原对象ID、规则和真实保存回执不变。
2. 排序仍需尊重即将开始的真实日程及用户已确认安排；普通逾期事实可见，但不靠大面积警报长期压住页面。
3. 当前原生显式日计划主要承载任务选择；将习惯与步骤在同一清单呈现时，应做类型化行动投影和日范围注意力状态，不把习惯打卡伪装成 TodoTask，也不改其全局频次。
4. 预算/健康异常、未来时段、来源不可用、同步分叉不能被“今天轻一点”掩盖；原有错误/恢复处理需要接入统一清单或对应原模块。
5. 采用/撤销只改当天注意力选择，不改截止、日历时段、目标要求或已发生事实；记录保存走原模块，多个目标读同一个值。
