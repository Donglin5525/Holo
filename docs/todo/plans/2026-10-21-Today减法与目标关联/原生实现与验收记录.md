# 今天摘要、目标长卷与统一来源明细：原生实现记录

2026-10-21。承接《整体方案与操作一致性契约》。本文件记录原生实施事实；前一份契约中的“尚未修改原生”为当时评审阶段状态。当前工作区有其他会话在途改动，本轮未暂存、提交、推送、部署或安装真机。

## 用户可见变化

- 今天展示一个重点目标、当前可推进动作、最多三条默认安排；同一任务在当前可见安排中出现后，不再在重点行动中重复。其他安排、习惯和今日概况在“更多安排与日常状态”展开。无活跃目标保留原来的日常焦点。
- 今天摘要和目标列表使用相同目标事实构建器。详情新增“进展长卷”，可拨动最初约定、已保存回顾、当前进展，并对照最初约定与现在。历史只展示实际保存的计划和报告，未生成的历史数值不补画。
- 金额、活动次数、累计数值、有记录天数、最新测量分别展示；不合成跨单位的目标总百分比。最新测量的上限判断与整段期间的行为上限分别处理。
- 点来源进入原模块明细，点一条原记录修改或删除，新增事实也复用原习惯输入器。来源保留目标读取的时间范围和计数方式；活动次数不混为里程累计。保存成功才关闭，失败保留输入。
- 原有个人→目标、生命周期、手动记录、关联对象、提醒、AI授权、任务多视图保留。目标详情低频项收在“目标设置与全部关联”。

## 数据和判断规则

1. `GoalPlanPayloadV2` 增量到 schema 3，v2 继续读取。每个习惯/任务绑定可保存本目标的要求。修改本目标要求追加计划版本，不修改共享习惯的默认频次、数值目标、单位或父目标引用。
2. 手动约定编辑和 AI 修正均验证基础版本。成功条件变化需要单独确认；重复操作 ID 不重复升版；旧报告身份沿用，不重写正文。旧限制在编辑草稿中转成一项要求，避免出现两套冲突上限。
3. 习惯新增 `HabitDailyConfirmationMO`：记录齐全、确认未发生、截至现在已核对、明确做到/没做到，以及撤回。确认不创建伪数量记录。当前日未结束，不提前判整日未发生或未做到。
4. 当前“截至现在为零”是有范围的事实，周期仍在进行；没有记录或确认仍未知。数量、完成状态或结算边界改变会让原确认失效，备注改变不使数量确认失效。
5. 习惯按自己的凌晨结算时间读取；本目标阶段生效前的记录不计入新阶段。日确认校验原记录摘要、时区和结算点。
6. 编辑/删除原记录及每日确认通过隔离保存合并回主界面；明确合并父对象关系更新。保存失败不全局回滚主上下文，也不提前显示成功。数值新增和打卡失败恢复本次变动。
7. 单账户储蓄读实际账户余额；全账本净结余保留明确旧口径。减少奶茶不自动增加专款。旧量化入口也读取已确认单账户口径，测量无记录不伪用基线当实测。
8. 每日确认属于习惯：删习惯级联删除其确认，软删期间不参与事实读取；去重服务的通用子关系合并能保留该挂子关系。
