## 2. 模拟器走查结论（改造前表现）

### 动线一：首页 → Today（01/04/08 系列截图）
- 首页：问候语+洞察轮换条；中央橙球带**同心圆环动画**+弧形文字「7 件事需要关注」；环绕五模块卡（任务/想法/财务/健康/习惯）。
- Today 顶部焦点卡现状：红色警示样式（「需要马上处理」+大标题+橙按钮），无进度环；下方依次为进行中的事（空态）、今天的安排、保持状态折叠胶囊（习惯 1/3·睡眠·步数）、今日概况（支出/预算/AI 入口）。

### 动线二：任务列表 / 详情 / 完成与撤回（09-24/30 系列）
- 列表：顶部进度卡「1/2·50% 圆环+横条」；筛选 chips；按 已过期/今天/明天/未安排 分组；卡内子任务**平铺**（3 条全显）+「0/3」迷你进度条；完成后**保留在列表**（绿勾+「已完成 HH:MM」徽章归「最近已完成」）。
- 列表完成（勾满 3 子任务）：父任务自动完成 → 底部白底横幅「任务已完成+撤回文字钮」，约 3 秒自动消失落库；点横幅主体是**打开详情**而非撤回。
- 详情完成：圆圈立即变绿勾+标题划线，随即弹「实际用了多久？」时长记录面板；**无 banner、无撤回**。与列表表现完全不同。
- 撤回后子任务勾选是否恢复：**未验到**（自动化点击未在 3 秒窗口内命中撤回钮，见缺口）。

### 动线三：Today → Matter（06/08/21）
- Today「进行中的事」为空态（「最近有什么想让 Holo 一起推进？」+虚线「开始一件事」按钮）；无 Matter 数据，事件文案现状待有数据环境补录。
- 附带现网行为：「开始一件事」拉起 HoloAI 预填草稿；AI 建任务确认卡即使显示「今天」也落「未安排」分组。

### Today 页完成表现（14）
- 任务行点击进详情，完成后任务**从「今天的安排」直接消失**，无撤回——与任务列表「保留+徽章」不一致，正是 G1 要统一的对象。

## 3. 基线缺口（G1 前需补）

1. **撤回后子任务勾选恢复**未实测到（代码事实已确认不恢复，待真机人工顺手验证一次）。
2. **Matter 详情事件列表现状**无数据可录（空态已录）；G4 前需在有 Matter 的环境补录一次。
3. **首页模块卡/球体点击**：模拟器坐标点击通道间歇失灵（AX 坐标 1.3 倍错配），未验证首页主入口点击，待东林真机顺手确认（动效改造会动首页，这是前置）。
