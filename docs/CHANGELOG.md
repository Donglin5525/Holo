## [Unreleased]

### Features
- **iOS**: 目标系统 v2 主线化——手动创建编辑 + 贯穿看板 + AI 可感可改
  - 目标从「AI 生成后锁死」升级为主线功能：支持手动创建/编辑（同一表单复用），详情页新增期望结果/动机/截止倒计时展示
  - 看板任务行、习惯行、任务卡显示目标归属胶囊（按领域配色），看板 Hero 区新增「N 件事在为目标添砖加瓦」
  - AI 侧：对话自动注入 3 个活跃目标（进度/期望结果/动机）；新增「改目标字段 / 关联任务到目标 / 不让 AI 参考某目标」三类写操作意图
  - 主动提醒：注入按目标级开关标注——关闭的目标 AI 绝不主动提起（仅被问到时参考），开启的目标遵循克制建议规则（每条回复最多一个、语气平实、不感兴趣就停）
  - 已知尾巴：多目标歧义只有文本反问（结构化选择卡未做）；任务/习惯关联目标只有 AI 入口（手动 UI 未做）
- **iOS**: 账单周期与信用卡类型——统计口径对齐真实账单
  - 全局记账周期支持自定义每月起始日（1-31 号），起始日 = 1 时等价自然月、老数据不受影响；解决「Holo 说花了 8000、银行 App 显示 6000」对不上的痛点
  - 「银行卡/信用卡」混用的旧类型拆出独立信用卡，支持账单日/还款日/额度；账户详情新增本期账单、可用额度、距还款日倒计时卡片
  - 旧「信用卡」账户一次性幂等迁移；财务设置页新增记账周期入口
- **iOS**: 财务 CSV 导入流式化——大文件不闪退 + 24 小时批次撤回
  - 64KB 分块流式读取，5 万行账单不再整体进内存被系统杀进程；导入前 20 条逐条实时反馈进度
  - 导入完成弹结果统计，24 小时内可按批次撤回（设置页与快速导入结果页均有入口）
  - 5 万条模拟器验收通过（UTF-8 边界误判 P1 已修复回归）
- **iOS**: AI 内容举报 + 未授权首屏引导（App Store 合规）
  - 每条 AI 消息长按可举报，提交后端 `/v1/reports`（Guideline 1.2）；AI 消息增加「AI」角标
  - 未开启 AI 数据处理授权时，聊天首屏不再误报「服务不可用」，改为说明原因 +「开启授权」入口
- **iOS**: 记忆长廊周视图重做——3 日滑动日历
  - 一周 7 列改为「昨天/今天/明天」3 列，今天恒在中列，左右翻页切换；预载 ±60 天 + 接近边缘续载避免边滑边查库卡顿
  - 日期格行钉在顶部不随滚动，横向单一 ScrollView 杜绝双滚动错位
- **Web**: 官网新增 /privacy /terms /support 承接页
  - App Store 要求法律页直接可达：独立静态法律页（带暗色模式）、支持页（数据删除指引/HealthKit 说明/支持邮箱）
- **iOS**: HoloAI 聊天滑动体验优化——根治卡顿 + 滚动进度条 + 返回按钮防误触
  - **卡顿根治**：每条消息滑进屏幕原本要临时解码 JSON、重建分析卡片、重算金额格式；改为消息创建时一次性预算并缓存，滑动时只读取结果、零计算。手写相等判断排除派生缓存字段加速 diff；ForEach 去掉每次复制整个消息数组的写法，时间戳分隔标志改为进列表前预计算
  - **滚动进度条**：滑动时右侧出现细条、停手约 1 秒淡出。用完全独立的 UIKit 组件自己监听滚动、不经过聊天页重绘通道，绝不拖累流畅度
  - **返回最下方按钮防误触**：按钮点击区严格限定在胶囊形状本身；按钮出现时底部最后一张卡片自动上移避让，消除与功能卡片（确认/取消/查看全部）的重叠误触
- **iOS**: 想法转任务全面改造——确认环节 + 选中转化 + AI 提炼 + ✅ 标记
  - 转任务不再一键直转，弹出底部确认面板，可逐条编辑标题、勾选后再创建
  - 支持**选中文字转化**：在正文选中一段文字，系统编辑菜单 / 键盘工具栏 ✅ 按钮均可触发，只转选中的那一段
  - 支持 **AI 智能识别**：点确认面板顶部「AI 智能识别」，AI 从想法/选中文字里自动提炼多条待办
  - 选中文字转任务后，正文里被转的文字末尾出现轻量「清单图标 + 任务」关系标记，点击可查看任务或取消标记；原文保持用户输入样式
  - 编辑器键盘工具栏按 iOS 原生编辑器思路收敛为 6 个单行入口：标签、引用、图片、格式、列表、转任务；加粗和有序/无序列表收进系统菜单
  - 转任务完成时对来源文字短暂高亮、关系标记轻微呼吸，深浅色模式下自动适配，不再使用大胶囊或横向滚动图标墙
  - 接入已有的休眠代码（`ThoughtTaskExtractionSheet` + `ThoughtTaskExtractor` + 后端 `thought_task_extraction` purpose），后端无需发版
- **iOS**: 想法编辑器体验升级——自动保存 + 工具栏重做 + 补全富文本格式
  - 自动保存：移除「保存」按钮、「取消」改「完成」，纯自动落库（对齐备忘录），写一半退出不丢
  - 空内容占位引导「写点什么吧…」
  - 键盘工具栏重做为精炼布局（6 按钮 + 玻璃底 + 精致高亮），视觉质感全面升级
  - 补全富文本格式：斜体 / 下划线 / 文字颜色此前底层支持但无入口，现接入；颜色走轻量浮层（8 预设色 + 重置，锚定工具栏上方）
  - 编辑器内 AI 归类标签从只读升级为可确认/拒绝（与详情页统一）
  - 语音与智能总结按钮拉开间距避免误触
  - 清理死代码（旧 SwiftUI 版工具栏 / 未接入的颜色选择器 / 快速记录工具栏）

### Bug Fixes
- **iOS**: 修复想法编辑器 @引用/#标签/任务标记点按弹不出操作菜单——confirmationDialog 呈现导致 UITextView 失焦，selectedToken 被同步清空的竞态；改用 `.sheet(item:)` 自绘菜单。顺带修复引用正文以 @ 开头时出现 @@ 双前缀
- **iOS**: 修复 HoloAI 弱网下点「停止」是「表面取消」、退出再进来仍提示「还在请求中」的问题。**表面取消**：流式请求（普通聊天/分析/记忆洞察生成）的内部 Task 未接取消信号，点停止只断了"接收结果"的管道，真正持有连接的 `urlSession.bytes` 仍在后台挂起并自动重试（最长 ~120s）；三层流式统一注册 `onTermination` 把取消信号传导到内部 Task，并让 `URLError.cancelled` 不再被当作可重试网络错误。**还在请求中**：Agent 深度分析路径的取消是 fire-and-forget，与"重新进页面的状态同步"存在竞态——job 尚未落盘 `.cancelled` 时，消息会被重新点亮为 streaming；新增 `ChatMessageType.userCancelled` 持久标记，停止时写入，状态同步见此标记一律跳过，从根上切断竞态；已取消消息统一渲染为纯文本「已停止生成」。纯客户端改动，无需后端发版
- **iOS**: 修复全局键盘避让导致输入框被挤压/遮挡的体验问题。想法首页搜索框键盘弹出时不再被压缩；今日看板习惯数值输入弹窗（手写 overlay 系统避让管不到）改为跟随键盘高度上移；调整余额备注框改为可滚动避免被遮；习惯打卡（卡片入口/快捷打卡）、周期项目编辑、一次性购买编辑的数字键盘统一补「完成」收键盘按钮
- **iOS**: 修复确认面板预勾选失效——传入内容被提前去掉列表标记（`-`/`1.`），导致列表型想法进入面板后一条都没勾；改为传原始 markdown 内容
- **iOS**: 修复选中文字转任务首次打开识别为整篇的问题——`.sheet(isPresented:)` 内容闭包在状态变量更新前被预创建，读到中间态（nil）；改用 `.sheet(item:)` 一次性构建完整参数
- **iOS**: 修复首页底部导航高亮残留——进入「记忆长廊」再退回首页，底部导航的「记忆长廊」一直保持选中态不消失。「个人」走 sheet 在 `onDismiss` 兜底复位，而「记忆长廊」走常驻导航栈，退回时无清理逻辑；改为在 `onChange(of: activeScreen)` 统一入口里「回到首页（activeScreen == nil）即复位 selectedTab」，覆盖所有常驻模块，不只是记忆长廊

### Improvements
- **iOS**: App Store 上架合规包：隐私清单补全（健康/音频/购买记录/FileTimestamp API 声明）与健康写入用途文案；隐私政策/用户协议同步 2026-08-13 版（新增健康 AI 条款、扩充 AI 供应商清单）；付费墙自动续费披露 + 计费周期标签（3.1.2）；账号删除前撤销 Apple 登录凭证（5.1.1v）；桌面 Widget 付费墙拦截后购买成功自动续跳；商店截图 6 张定稿 + 审核提交材料
- **iOS**: 杂项打磨：移除「即将上线」类占位（财务/健康占位 Tab、智能提醒、月历 AI 洞察）；健康洞察页加「AI 生成仅供参考，不构成医疗建议」；模拟器一律禁用 CloudKit 同步防崩溃；记忆详情三页横向溢出修复；文案中文化
- **backend**: 升级 hono 4.13 / @hono/node-server 2.x（框架版本，无业务改动）
- **docs**: 规范文档归类重组——创建 `docs/standards/` 规范中心，集中 6 个开发/Prompt/图表/Agent 规范文档，新增 `INDEX.md` 按场景索引；清理根目录临时过程文件（findings/progress/task_plan/memory）
- **docs**: 键盘避让事故复盘沉淀进开发守则（三轮误判错误模式、`KeyboardAvoidanceDisabler` 修复方案）；速查表加「键盘弹出输入框被顶起」条目；自检清单加键盘检查项

### Notes
- **后端发版**: 客户端账号删除已调用 `POST /v1/auth/apple/revoke`（删除前撤销 Sign in with Apple 凭证），后端接口需配套上线并随下次后端发版生效；AI 内容举报依赖的 `/v1/reports` 同步确认线上可用
- **schema**: `Account` 新增账单日/还款日/额度字段、`Goal` 新增 `proactiveNudge` 字段；若这些实体在 CloudKit 同步范围内，上线前需做一次 schema 部署（Development → Production）确认
- **CloudKit**: `TodoTask` 新增可选字段 `sourceTextSnippet`（记录选中转化时的来源文字快照），需一次 CloudKit schema 部署（Development → Production）
