## [Unreleased]

### Features
- **AI 思考过程透明化**：AI 回复期间不再只显示跳动的圆点或「正在分析中…」，而是如实告诉用户此刻在查阅哪些数据，让用户切实感受到 AI 在认真翻阅「我的」数据来回答
  - **深度分析**：把内部已有的工具调用记录（调了账单/记忆/任务/想法等）翻译成用户可见文案，从泛化的「正在读取本地数据」升级为具体的「正在翻阅账单、回顾记忆」；点击卡片可展开查看完整调用日志时间线
  - **普通聊天**：两段黑盒等待期（意图识别 + 记忆查询）现在分别显示「正在理解你的问题」「正在回顾你的记忆（N 条）」，收到第一个字后切回正常流式
  - **普通分析**：硬编码的「AI 正在分析中…」替换为「正在查阅数据、回顾你的记忆（N 条）」
  - 诚实边界：普通聊天只查记忆、不查账单，提示如实呈现；记忆为空时显示中性「正在思考回复」，不假装在回顾
  - 纯 App 端改动，不涉及后端发版（查阅的是手机本地数据库）

### Bug Fixes
- **iOS**: 修复全局键盘避让导致输入框被挤压/遮挡的体验问题。想法首页搜索框键盘弹出时不再被压缩；今日看板习惯数值输入弹窗（手写 overlay 系统避让管不到）改为跟随键盘高度上移；调整余额备注框改为可滚动避免被遮；习惯打卡（卡片入口/快捷打卡）、周期项目编辑、一次性购买编辑的数字键盘统一补「完成」收键盘按钮

### Improvements
- **docs**: 规范文档归类重组——创建 `docs/standards/` 规范中心，集中 6 个开发/Prompt/图表/Agent 规范文档，新增 `INDEX.md` 按场景索引；清理根目录临时过程文件（findings/progress/task_plan/memory）
- **docs**: 键盘避让事故复盘沉淀进开发守则（三轮误判错误模式、`KeyboardAvoidanceDisabler` 修复方案）；速查表加「键盘弹出输入框被顶起」条目；自检清单加键盘检查项
