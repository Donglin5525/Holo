- **iOS**: 任务列表排序——四个维度升降序，排序方案自带分组策略
  - 排序方式：截止时间（默认，即原顺序）/ 优先级 / 创建时间 / 完成时间（「已完成」页专用并为其默认）；每种带方向切换，文案说人话（「早→晚」「高→低」「最近在前」），不暴露「升序/降序」术语，各维度有符合直觉的默认方向
  - 排序方案自带分组策略：按截止时间排=保持时间分组（现状）；按优先级排=切换「紧急/高/中/低」四分组且组序随方向翻转（满足「一眼看最紧急」）；按创建时间排=平铺；已完成页保持按周分组、只调组内顺序
  - 边界规则：无截止日期的任务无论方向恒沉底（不随降序翻到顶部）；排序值并列时按创建时间兜底，列表顺序稳定；同优先级组内按截止时间细排
  - 入口固定筛选条右端（不随过滤胶囊滚动、始终可见），改过排序后胶囊橙色高亮显示当前排法，让排序状态可见可改；弹层与记账弹层同款视觉（居中标题/细分隔线/规范字体），即点即生效、换维度自动重置为该维度默认方向、支持一键恢复默认

- **iOS**: 财务账单智能导入——微信/支付宝/银行账单一键导入 + AI 科目匹配（一期）
  - 三类账单开箱即用：微信/支付宝账单自动识别（封面说明行跳过、固定列映射、免 AI 免流量）；银行账单支持 CSV/TXT/Excel(xlsx)，格式由 AI 指认列位（表头 + 脱敏样本发送，金额/卡号打码后才上云）

  - 账户映射：微信/支付宝按「支付方式」列逐行映射（零钱/零钱通/各银行卡，含模糊匹配初值可改），银行账单整份默认单账户；预览页可改选

### Bug Fixes
- **iOS**: 修复卡片式页面不支持下拉关闭——任务详情/记账/新建习惯/新建纪念日四张卡片，此前为防误触丢内容用 `interactiveDismissDisabled` 一刀切拦掉系统下拉手势，连「没改动想下拉关掉」都做不到。新增可复用守卫组件 `SheetDismissGuard`（UIKit presentationController 桥接，捕获「用户下拉被拦」的瞬间回调页面分流）：三个表单卡改为「无改动时直接下拉关、有改动时拦下弹『放弃修改？』确认」，对齐 iOS 系统行为；任务详情编辑模式下拉与返回按钮/右滑完全一致（先保存再关闭），三条关闭路径同构。纯客户端改动，无需后端发版
- **iOS**: 根治「删除数据闪退」反复复发的问题——根因是统一模式而非局部 bug：仓库层 `context.delete + save` 后被删对象即刻作废，调用方此后访问其任何属性（`removeAll` 闭包里的 `.id`、表单关闭动画期间 body 重读字段）都触发 "could not fulfill a fault" 闪退。本次修复 4 处：子任务页与编辑任务页删除子任务（先把对象移出界面数组再删库，失败分支 reload 恢复）；交易编辑页删除交易（成功后不再把 isDeleting 翻回，避免表单重读已删交易字段）；编辑任务页删除清单（清单级联删除会连带删掉其下任务，正在编辑的任务属于该清单时删除后立即关闭表单）。全盘清点其余删除场景：任务软删/习惯/纪念日/看板路径模式正确无需改；想法删标签、AI 对话删交易后不刷新、导入撤回后台删除三处列为观察名单。纯客户端改动，无需后端发版
- **iOS**: 修复想法编辑器 @引用/#标签/任务标记点按弹不出操作菜单——confirmationDialog 呈现导致 UITextView 失焦，selectedToken 被同步清空的竞态；改用 `.sheet(item:)` 自绘菜单。顺带修复引用正文以 @ 开头时出现 @@ 双前缀
- **iOS**: 修复 HoloAI 弱网下点「停止」是「表面取消」、退出再进来仍提示「还在请求中」的问题。**表面取消**：流式请求（普通聊天/分析/记忆洞察生成）的内部 Task 未接取消信号，点停止只断了"接收结果"的管道，真正持有连接的 `urlSession.bytes` 仍在后台挂起并自动重试（最长 ~120s）；三层流式统一注册 `onTermination` 把取消信号传导到内部 Task，并让 `URLError.cancelled` 不再被当作可重试网络错误。**还在请求中**：Agent 深度分析路径的取消是 fire-and-forget，与"重新进页面的状态同步"存在竞态——job 尚未落盘 `.cancelled` 时，消息会被重新点亮为 streaming；新增 `ChatMessageType.userCancelled` 持久标记，停止时写入，状态同步见此标记一律跳过，从根上切断竞态；已取消消息统一渲染为纯文本「已停止生成」。纯客户端改动，无需后端发版
- **iOS**: 修复全局键盘避让导致输入框被挤压/遮挡的体验问题。想法首页搜索框键盘弹出时不再被压缩；今日看板习惯数值输入弹窗（手写 overlay 系统避让管不到）改为跟随键盘高度上移；调整余额备注框改为可滚动避免被遮；习惯打卡（卡片入口/快捷打卡）、周期项目编辑、一次性购买编辑的数字键盘统一补「完成」收键盘按钮
- **iOS**: 修复确认面板预勾选失效——传入内容被提前去掉列表标记（`-`/`1.`），导致列表型想法进入面板后一条都没勾；改为传原始 markdown 内容
- **iOS**: 修复选中文字转任务首次打开识别为整篇的问题——`.sheet(isPresented:)` 内容闭包在状态变量更新前被预创建，读到中间态（nil）；改用 `.sheet(item:)` 一次性构建完整参数
- **iOS**: 修复首页底部导航高亮残留——进入「记忆长廊」再退回首页，底部导航的「记忆长廊」一直保持选中态不消失。「个人」走 sheet 在 `onDismiss` 兜底复位，而「记忆长廊」走常驻导航栈，退回时无清理逻辑；改为在 `onChange(of: activeScreen)` 统一入口里「回到首页（activeScreen == nil）即复位 selectedTab」，覆盖所有常驻模块，不只是记忆长廊
