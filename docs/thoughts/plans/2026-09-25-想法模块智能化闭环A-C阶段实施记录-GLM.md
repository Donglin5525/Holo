# 想法模块智能化闭环 A-C 阶段实施记录（GLM）

实施日期：2026-09-25。依据方案：[2026-09-24-想法模块智能化闭环体检与落地方案-GLM.md](2026-09-24-想法模块智能化闭环体检与落地方案-GLM.md)。本记录按方案 §10 模板撰写；D 阶段（发布放量）未执行，见「发布决策」。

## 1. 产品效果：东林能在 App 里看到什么

**侧边栏导航（A1，Debug 开发包立即可见）**：
- 想法模块只剩一条主内容流，「想法|主题」分段切换与主题卡墙主模式已移除（`ThoughtSidebarRollout.isEnabled`，Debug 默认开 / Release 默认关，可显式覆盖回滚）。
- 左上「侧栏」按钮或左缘右滑（跟手）展开抽屉侧栏：全部想法 / 置顶 / 主题（组尾管理主题）/ 我的 #标签（斜杠路径树+折叠）/ 其他（已归档、数据清理）。
- 内容层整体右移、左缘大圆角、侧栏与内容两层视觉（类 flomo 截图层级）；点侧栏节点收起并切换范围，标题/列表/搜索范围同步。
- 右上独立「返回 Holo」；退出模块不再占用左缘滑动（手势所有权归侧栏）。

**相关旧想法（B，编辑器内）**：正文已落库且本机索引有命中时，编辑器底部出现「你之前也写过」1-3 条可回原文的旧想法（`resurfacingEnabled`，Debug 默认开）；无命中安静留空；「不相关」反馈后同版本不再推荐。

**帮我想想（B，编辑器内）**：正文 ≥10 字出现入口，请求只带当前笔记脱敏正文，回答分「你写过的」（引用原文）与「AI 的思考（推测）」两区，可选 nextStep。**需后端发版**才可用；未发版时显示「暂不可用（服务未开放）」，保存不受影响。

**主题建议行（C，侧栏）**：候选簇达门槛（≥3 条相近、有名字）时侧栏主题组出现轻量建议行（建立/忽略）；discovery flag 关闭时不出现。

**混合搜索（C）**：搜索词两字以上时，关键词命中之后追加语义近义命中（防抖 600ms，需网络与本机索引）；离线/未索引自动回落纯关键词。

**设置页（A）**：「设备智能索引」页如实区分未授权/未开启/已暂停/整理中/完成/失败可重试；提供开启、暂停/继续、重试失败、重新核对、删除操作；隐私文案按已核实事实收敛。

## 3. 数据契约与迁移

- **ThoughtTopicLink**：新增写入方 source=ai/v3（枚举既有），visibility=weakVisible；同 pair 裁决 rank 不变（user active > rejected 墓碑 > ai/v3 > legacy）。无 CloudKit schema 变更（ThoughtTopicLink 已在既有模型内）。
- **semantic_job**：幂等加列 finished_at（ALTER，旧库自动补列，NULL=未完成）。
- **related_feedback**（新表，本机 SQLite）：PK(thought_id, related_id)，basis_hash 留版本依据；随「删除设备智能索引」整体销毁；不进 iCloud。
- **导航偏好**：thoughts.sidebar.pinned / thoughts.sidebar.expandedTagPaths（UserDefaults，本机，首版不跨设备）。
- **回滚矩阵**：侧栏 flag 关=完整回旧导航（分段+卡墙，数据零迁移零丢失）；V2 停算=设置页显式开；relation=on 退回 shadow 只需切 flag（committed_ 记录留痕，已写 link 由裁决层继续压制/共存）。

## 6. 发布决策

**当前不可给真实用户放量。** 条件与顺序：
1. 后端发版（thoughts/insight 三件套）后，容器内验证路由+闸门（mock→真实供应商须显式 `HOLO_THOUGHT_INSIGHT_PRIVACY_VERIFIED=true` 才放行）。
2. 东林真机走查侧栏手感（动画参数按 §5.8 真机校准）+ 边缘手势 + VoiceOver。
3. 灰度开关矩阵：`thoughts_sidebar_v1`（Release 默认关→放量改默认）、`resurfacing`（同）、V2 停算（随 uiEnabled 联动）、relation 正式提交（需先出正式 `ThoughtSemanticCalibration.json` 并过 §8.C 门槛——精确率 ≥95% 且严重误归零才放量）。
4. 一键回退动作已备：关对应 flag 即回退，无数据迁移。

**遗留到下一步**（非本轮范围）：侧栏滚动位置跨 scope 锚点恢复（当前切 scope 回顶）；「在全部想法中搜索」显式扩展按钮；评测集冻结与 precision/recall 报告（需真实模型）；D 阶段标签建议实验（无证据不做）。
