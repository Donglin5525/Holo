## 4. 内容与导出契约

1. **输入来源**：`ThoughtShareSheet` 从 `RichContentSerializer.nodes(richJSON:fallbackPlainText:)` 取富文本节点；图片用 `thought.sortedAttachments` 的原有顺序，优先原图，缺失时用缩略图；标签来自 `recognizedTagNames` 经 `ThoughtTagNormalizer.lastSegment`；心情来自 `thought.moodType?.displayName`；时间取 `createdAt`。只本地排版，不请求 AI 或后端。
2. **正文保真**：`HoloContentNode` 的普通文字、行内 Markdown、标签、引用和转任务标记均须可读；不重写、不截断、不擅自生成标题。空心情/空标签不留假内容。标签超过三个时沿用 `+N` 规则。用户正文内的 Emoji 不清除。
3. **图片与尾注**：单图、多图都保留顺序；不同模板可改变相框样式，不得漏图。`showsBrandFooter` 同时作用于四版；关闭后不显示 Holo 尾注。静态导出图不得出现按钮、选择勾或「点击」字样。
4. **尺寸与设备**：卡宽 340pt，高度随正文生长。延用 `ImageRenderer` 3x 导出与最大约 8000px 的回退策略；预览图降到最大约 3500px，但分享和存相册使用同一张完整导出图。导出色板固定，不因系统深浅模式变色。
5. **选择状态**：`thoughtShareCard.style` 本机持久化；无记录或未知值回退暖纸手账。切换模板或尾注时重渲当前想法，生成中不可把旧模板的图分享出去。连续快速切换后，以最后选中的模板为准。

## 6. 验收矩阵

| 场景 | 通过标准 |
|---|---|
| 首次打开、再次打开 | 首次为暖纸手账；切换后再次进入沿用上次选择；旧手账输出无意外变化。 |
| 两个入口 | 列表和编辑器打开同一分享面板，当前想法一致。 |
| 四版图形 | 三枚 PNG 各在指定模板中清楚可见且无白底/黑边/裁断；档案版日期章正确；无系统 Emoji 装饰。 |
| 无心情、无标签 | 不出现空白 Emoji 位、假标签、错误日期。 |
| 富文本与用户 Emoji | 粗体等行内格式、标签/引用/任务标记、原文 Emoji 保真；没有文字被截断。 |
| 图片 | 0、1、2、3 张及横/竖图均按顺序显示；无拉伸、漏图或遮挡正文。 |
| 超长笔记 | 导出不是透明空图；预览可滚动；原文完整，画质退让边界可接受。 |
| 快速切换与尾注 | 最终预览、分享图、相册图均是最后选择的模板和尾注状态，没有旧图混用。 |
| 小屏、大字、深色系统 | 控件可达、文字可读；导出图本身保持模板固定色板。 |
| 分享与保存 | 系统分享得到可打开的图片；相册里实际存在对应图片，再记录完成。 |

验收报告分开写：代码/资源核对、编译、模拟器真实旅程、真机、相册与系统分享。`BUILD SUCCEEDED` 和 HTML 对比稿不能当成用户旅程通过。
