## 2. P0 任务（批准范围）
- **A 读源统一**：`TopicRepository.fetchThoughts(byTopic:)/searchWithinTopic/thoughtCount` 改投影裁决（谓词粗筛+`effectiveTopics` 精筛）；旁路四点（`TopicService`、`ThoughtUIHelpers`、`CalendarEventProvider:182`、`MemorySignalDataAdapter:113`）同步；`fetchThoughtClassificationTopicId` 保持旧源（V2 专属口径）；旧关系双写保留为回滚镜像。
- **B verifier 堵漏**：提交前重验 isGranted+发起时代数+hash（照抄 embed `revalidateBeforeCommit`）；save 显式错误处理；落库存 quote 原文片段（脱敏坐标不用于原文高亮，映射不可靠降级整条回源，展示层归 P1）。
- **C relate 任务化**：`semantic_job` kind="relate"；embed 完成改为入队；Pipeline 心跳并列消费；存量补跑（有 active 向量+无 active link+flag/授权门控）；AI 写 link 不递增 topicCatalogRevision 防 loop。
- **D 标签解耦**：拆除 `rename/merge/deleteClassificationTopic` 的 `renameTagPathPrefix` 连带改写；存量「主题/子标签」路径出只读迁移报告，不批量改。
- **E 单选收窄**：`assign`/`setClassificationEnabled` 仅 classification 主题互斥（V2 兼容）；普通主题 0–N 共存。
- **F 测试（完成门）**：①link有/旧关系无→四处一致；②拒绝不复活（含 relate 迟到+授权已撤）；③补跑入队生效；④撤回授权零新外发；⑤软删/归档不计入活跃计数；⑥改名不碰标签；⑦`shadowDifference` 对账归零。既有投影/仓库/手势测试全绿。
