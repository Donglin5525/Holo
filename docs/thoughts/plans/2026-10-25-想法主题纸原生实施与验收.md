# 想法主题纸：原生实施与验收

## 用户可见行为

按东林确认的克制版原型，提供「原样」与八套主题纸：远行邮笺、晴日观察、生活票根、一日一页、对折手记、光影胶片、页边书签、点阵便笺。

- 编辑页正常输入，模板只改变纸面、字体和照片构图；不生成标题、不改写原文、不插入虚构日期、天气或地点。
- 选择面板使用当前文字、富文本与图片做完整预览；底部九个缩略图可切换。取消不写入，明确使用后才应用本条。
- 列表保留原导航、搜索、卡片、标签、状态和菜单，带出模板的字体和局部纸张特征。
- 胶片把照片放在正文前；其他模板保留文后图片，并分别采用纸框、宽幅、偏右或小方图。原图与附件顺序仍由原附件链路保存。
- 分享默认沿用本条，临时换模板不改原记录；显式「设为这条想法的样式」才同步。成图固定浅色，App 内纸面自动适配明暗。
- 下一条仍默认原样；只选模板、没有文字和图片的会话不生成空记录。

原型：`holo-calm-stationery-expanded.html`（本聊天的预览目录），原生实现不依赖网页或示例照片资源。

## 数据与兼容

复用可空 `appearanceRaw` 字符串与原来的编辑提交、恢复草稿、分享同步链路。本轮未增加模型字段。

旧值只在读取时映射：`journal` / `midnight` → `post`，`book` → `bookmark`，`archive` → `field`。不批量重写历史记录；未知值与空值读作原样。

字体与纸墨仅是显示属性，不写成正文颜色或 Markdown 标记。保留用户选色、加粗、斜体、Token、标签、引用与任务标记。模板改变后，列表的富文本测量缓存也区分模板，防止使用旧字体行数造成截断误判。

图片视图接收快照，上传、失败重试、删除与恢复草稿仍交给编辑器既有动作；不另建一套图片持久化。

## 字体

八套模板共用三类：系统体（原样/票根/胶片/点阵）、宋体类（日历/书签）、手写感（邮笺/观察/对折）。导航、按钮和其他模块继续使用系统字体。

随包字体基于 Noto Serif SC 与 LXGW WenKai Lite，按 SIL OFL 1.1 保留许可并将修改后的子集重命名为 `HoloNoteSerif` / `HoloNoteHand`。每类附常规与加粗字重，源文件、哈希和覆盖说明见 `Holo/Resources/ThoughtFonts/SOURCES.json`；重建脚本为 `scripts/prepare-thought-fonts.py`。

保留 GB2312、Big5 常用字一级区、拉丁字与常用标点；其他字符由系统逐字形回退，不限制用户输入。四个 TTF 原始资源合计 19,493,980 字节；这不是 App Store 下载增量测量。

## 验收记录

- 独立数据验证：50 项断言通过，覆盖真实旧 SQLite 模型迁移、原文/富文本/关系/对象身份、旧样式映射、三类字体分组与九种样式保存重载。
- 字体资源验证：真实 TTF 通过 CoreText 进程内注册、PostScript 名称、常用简繁字形、英文数字、加粗与许可检查；App 构建产物的 UIAppFonts 四项与真实随包文件一致。
- 颜色：八套纸张、两种明暗、正文与辅助文字共 32 组对比度通过，最低 4.74:1。
- 主 App / Widgets Debug Simulator 构建通过。新增界面拆为独立叶子组件，View Weight Guard 通过。
- 原生 iPhone：旧 `book` 原值保留、打开显示「页边书签」；九种候选均可切换，预览与取消不写库，明确应用与完成才保存。中文正文逐字一致，富文本 JSON 在分享同步前后保持一致。
- 实际图片：通过系统照片选择器添加照片，编辑器、列表、预览与导出均显示真实附件；查看与移除图片是独立按钮。切回原样后存储为空值，正文与照片保留；只选模板后退出不生成空记录。
- 分享：默认沿用本条，临时切换不写库，明确同步才改变样式；已实际保存到系统相册并读回成图，全文、照片、日期与页脚完整。多图极限、特别长正文导出未做专项走查。
- 明暗与大字号：已检查 iPhone 深色列表/编辑、固定浅色分享成图，以及最大辅助字号选择器可滚动、文字只缩放一次。已修正候选区挤压预览、日期头挤压与 UIKit 字号转 SwiftUI 重复放大的问题。
- iPad：11 英寸 iPad Pro 模拟器竖屏九种候选可切换，长正文预览可滚动且不写库；横屏分栏中可打开编辑器、切换九种候选、应用日历模板并保存。横竖屏分别验收，旋转时现有编辑容器会重建并关闭候选面板，本轮未改变导航容器。

模拟器测试只在本任务隔离设备进行；没有读取或清理日用 CloudKit 开发库。

本聊天预览目录保留实际原生截图 `holo-native-editor-post.png`、`holo-native-editor-calendar-dark.png` 与相册读回的 `holo-native-export-calendar.jpg`。构建、测试过程日志保存在本机 `/private/tmp/holo-stationery-*`，不作为产品资源入库。

## 细节复核（2026-10-25，东林修订）

使用 `ui-ux-pro-max` 视觉技能按真实输入复核，完成以下调整：

- 记录样式收进右上角「…」，移除正文上方独立样式行；列表提示缩为小图标。
- 纸面只保留真实日期与几何装饰，去掉「寄给自己」「日常观察」「留住片刻」「随手记」「光影片刻」等预设标题。模板名称只用于选择器。
- 根因：`UITextView.textContainerInset` 过去只在首次创建时设置，切换模板后仍用旧缩进。现在同步真实输入区与占位提示的约束，不重建正文或改光标；折线在 24pt，正文从 44pt 开始，票根右侧留 32pt。
- 页眉、正文、照片、标签与页脚共用左右安全区；去掉邮笺编辑图片额外的右缩进。观察刻度收进页边，点阵减淡；装饰止于纸面，不穿过编辑工具栏。
- 输入区预算改为读取实际页眉、页脚和当前视口，兼顾键盘与底部安全区，避免按固定屏幕高度估算。

本轮实测：八套模板分别在原生编辑器中输入不同中文内容，保存后逐字核对，并重开检查；补充编号列表、已有正文切换样式、真实照片的五种不同构图，以及含中英文长链接的长文滚动与真实相册导出。所有测试记录仅存在本任务隔离模拟器。最新构建补验长文工具栏在底部安全区与键盘上方完整可见，并复核 iPad 竖屏与横屏分栏中的长正文折线边界。

原生复核图：本聊天预览目录 `holo-stationery-native-refined-review.html`，内含八套真实输入截图、图文补充与相册读回成图；页面内的测试正文由本次操作输入，模板不自动添加这些文字。
