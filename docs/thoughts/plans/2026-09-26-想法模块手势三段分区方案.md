# 想法模块·手势三段分区方案（标签树拉出 + 右滑直达首页）

日期：2026-09-26
状态：**已实施，模拟器门禁 13 过 / 1 条件跳过 / 0 败（干净模拟器现场种子数据），待真机验收**。
拍板：东林 2026-09-26——①三段式=手势三段分区（左缘右滑=返回首页 / 屏幕中部右滑=拉出标签树 / 侧栏内左滑=收起）；②标签树全开时左缘右滑**一步直达首页**，侧栏随模块整体退场，不需要先手动收起。

与《2026-09-26-想法标签与AI主题归类显著生效整改方案-GLM.md》的关系：本方案是其**前置手势批次（G 批次）**，纯 iOS 无后端发版；标签/主题的信息架构（P1）不变，本批次只解决「标签树怎么拉出来、怎么退回去」。

## 1. 手势分区总表（现状 → 目标）

| 起手区 | 手势 | 行为 | 改造前 | 改造后 |
|---|---|---|---|---|
| 左缘窄带（~20pt，实际排除带 28pt） | 右滑 | 一步直达首页 | 侧栏开着时被整体禁用（`isEnabled: !isSidebarOpen`），只能先左滑收侧栏 | **恒可用**，侧栏随模块整体滑走，退场后重置侧栏 |
| 屏幕中部（排除带以外） | 右滑 | 拉出标签树（跟手+松手停靠/弹回） | 无行为，只能点顶部按钮 | **新增** `SidebarOpenPanModifier` |
| 侧栏开启态 | 左滑 | 收起侧栏 | 已有 | 保留，阈值不变（过 38% 或快甩） |
| 卡片行 | 左滑 | 归档/删除按钮 | 已有 + 侧栏拖动中门控 | 保留不动 |
| 横向滚动容器（筛选 chips 等） | 右滑 | 容器自己滚 | — | **让位规则①**：拉侧栏手势不接收（纵向列表不在此列，右滑照常拉出） |
| 卡片按钮展开态 | 右滑 | 只收按钮 | — | **让位规则②**：拉侧栏手势让位（防双动） |
| 编辑器/弹层打开 | 任意 | 全部静默 | 已有闸门 | **让位规则③**：新增手势走同一 `HoloWindowGestureGate` 闸门 |

## 2. 实现要点

### 2.1 SidebarOpenPanModifier（`ThoughtSidebarSupport.swift` 新增）
完全复用关闭 pan 的成熟地基：window 级 `UIPanGestureRecognizer`（含 5 次×50ms 重试挂载）、`HorizontalGestureLock` 轴向锁（只认右向）、`shouldRecognizeSimultaneouslyWith → true`、`HoloWindowGestureGate.isOverlayPresented` 弹层闸门。

`shouldReceive` 三条判定（按序）：
1. `isEnabled` 且弹层闸门放行；
2. 起手点 x ≥ 28pt（左缘排除带，`UIScreenEdgePanGestureRecognizer` 实际响应带约 20pt，留缓冲）；
3. 起手点不在可横向滚动的 `UIScrollView` 内——沿 `touch.view` 响应链查 superview，判 `contentSize.width - bounds.width > 1`；纯纵向列表不满足此判据，右滑照常拉出。

停靠判定与关闭对称：松手 `translation > 0.25 × sidebarWidth` 或 `velocity > 500` → 停靠开（`HoloAnimation.snappy`）；否则弹回（`grounded`）。参数真机校准。

### 2.2 侧栏状态模型重构（`ThoughtsView.swift`）
旧模型 `isSidebarOpen: Bool + sidebarDragOffset: CGFloat` 合成进度，Bool 不可插值导致停靠/关闭瞬间瞬跳。新模型：
- `@State sidebarOffset: CGFloat`（0=收起 … sidebarWidth=停靠开）——唯一事实源，全部路径（拖出/收起/按钮/遮罩/选标签）都改写它，动画天然可插值；
- `sidebarProgress = clamp(sidebarOffset / sidebarWidth, 0, 1)`；`isSidebarDocked = sidebarOffset ≥ sidebarWidth - 0.5`（停靠态=交互态）。

侧栏可见性从二态改为随进度渐显：
```swift
.opacity(min(1, sidebarProgress * 2))   // 拉到一半即全显
.allowsHitTesting(isSidebarDocked)      // 交互仍按停靠态
.accessibilityHidden(!isSidebarDocked)  // AX 与停靠态同步
.zIndex(sidebarProgress > 0.01 ? 1 : 0) // 拖拽中提到内容层之上
```
关闭态（progress=0）opacity/触摸/AX 三通道全关——2026-09-26 修复规则不回退。

### 2.3 右滑返回恒可用 + 退场重置（G2）
`.swipeBackToDismiss(isEnabled: true, isResidentScreenRoot: true)`；回调 `close()` 后无动画重置 `sidebarOffset = 0`——回首页再进想法模块，看到的是干净的想法流（拍板可调：若要保留侧栏开态，删掉重置行即可）。

已知接受的取舍：左缘 20pt 是全 App 统一的返回手势带，恒开后侧栏左缘 20pt 内的点按让位给返回手势（与其它模块左缘行为一致）。

### 2.4 卡片展开态让位（防双动）
`SwipeActionView` 展开态的右滑收按钮是它自己处理的（`h > 0 && isRevealed` 分支）。`ThoughtListView` 新增 `onRevealedCardChange: ((Bool) -> Void)?`，挂 `onChange(of: revealedThoughtId)` 上报（覆盖删除/切范围等所有置空路径）；`ThoughtsView` 持有 `hasRevealedCard`，拉出 pan 的 `isEnabled = !isSidebarDocked && !hasRevealedCard && !isWideLayout`（宽屏不启用拖出，保持按钮入口）。

## 3. 隔离规则（不触碰现有手势，逐条落码）
1. 不新增手势体系，只复用 window pan + 方向锁 + 弹层闸门三件套；
2. 并行识别委托恒 true（0926 R1-G4 教训：缺失会被 ScrollView 判死）；
3. 关闭态三通道全关（opacity/触摸/AX）规则保持；
4. `swipeGesturesEnabled = sidebarProgress < 0.01` 卡片手势门控链保持不动；
5. AX 可见性与视觉同步（iOS 26 幽灵按钮教训）；
6. 弹层打开时三段手势全部静默（同一闸门）。

## 4. 门禁测试（`ThoughtGestureGateUITests` 扩 G9–G13）
- G9 中部右滑 → 侧栏拉出并停靠（G4 继续断言模块不退，两 complementary）；
- G10 侧栏停靠开 + 左缘右滑 → 一步直达首页（不得只收侧栏），再进模块侧栏已重置；
- G11 筛选 chips 行右滑 → chips 自己滚、侧栏不动（让位①）。**现状：侧栏形态下顶部 chips 条不渲染（`filterBarView` 随 rollout 退场），想法页暂无横向滚动容器，本条留位跳过（XCTSkip 注明启用条件）；让位规则①保留在代码里，是横滚与拉出同向冲突的结构性防线，顶部横滚元素回归时去掉 skip 即生效；
- G12 列表纵向滚动 → 不拉侧栏（轴向锁）；
- G13 卡片按钮展开态中部右滑 → 只收按钮不拉侧栏（让位②）。
G6（编辑器内右滑不退模块）兼任让位③的回归门禁。
纪律不变：手势门禁必须真机跑才算数，模拟器绿只证明链路通。

## 5. 30 秒真机验收清单（东林）
1. 想法页屏幕中部往右拖 → 标签树跟手出来，松手停靠；
2. 标签树上往左拖 → 收起；
3. 标签树开着，从屏幕最左缘往右滑 → **直接回到首页**（不是先收侧栏）；
4. 再进想法页 → 是干净的想法流（侧栏已重置）；
5. 卡片左滑出「归档/删除」后右滑 → 只收按钮，侧栏不出来；
6. 筛选胶囊行上右滑 → 胶囊滚，侧栏不出来；
7. 回归：卡片左滑、编辑器内右滑、纵向滚列表，行为与改造前一致。

## 6. 风险与真机验证点
- 左缘返回手势与标签树左缘区域纵向滚动的并行表现；
- `swipeBackToDismiss` 恒开后，侧栏拖拽进行中从左缘起手的极端手势归谁（预期左缘优先归返回）；
- 打开/关闭两 pan 在停靠瞬间切换 isEnabled 的衔接（防半开卡死）；
- iPhone 全系列屏宽下 28pt 排除带与边缘返回带的手感（参数可调）。
