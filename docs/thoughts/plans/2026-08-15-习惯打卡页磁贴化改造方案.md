# 习惯打卡页磁贴化改造方案

> 日期：2026-08-15
> 状态：方案定稿（东林已拍板），待实施
> 交互原型：`docs/design-mockups/habit-checkin-redesign.html`（第 4、5 台为视觉基准；进度条以第 4 台橙色版式为准）

## 一、背景

习惯 Tab 打卡页现为竖向平铺白卡片列表：无视觉主角、完成与未完成差异微弱、页面不呈现「今天做得怎么样」。经三路线对比（HTML 可交互原型），东林选定**路线三：彩色磁贴网格**，并完成进阶细节拍板。

## 二、已拍板决策（2026-08-15，东林）

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 布局 | 两列磁贴网格（LazyVGrid），替换现有卡片列表 |
| 2 | 图标 | 沿用现有 SF Symbols 单色染色体系，不引入彩色图标库 |
| 3 | 磁贴常态 | 全彩淡底：习惯色 8% 混白（深色模式另定），未完成也有色感 |
| 4 | 完成态 | 习惯色实底 + 图标/文字反白 + 右上角勾徽章 |
| 5 | 今日进度 | **橙色单色进度条**（F46D38→EA580C 渐变细条）+ 标题「今日进度 x/y」+ 副标题「还有 n 项待点亮」；不做分段色带 |
| 6 | 点亮动效 | 颜色从点击点圆形扩散铺满磁贴 + 勾徽章弹出 + 成功触觉 |
| 7 | 全部完成 | 标题变「今天全部点亮 ✨」+ 磁贴从左到右波浪跳 + 进度条满格 |
| 8 | 排序 | **位置固定**：按 `sortOrder`（现有字段）升序，完成只变色不移动；手动拖拽排 v2 |
| 9 | 数值类操作 | 磁贴内直接操作：计数类底部两行——上行迷你进度条+数值、下行「−」「＋」并排（「−」仅今日有记录时出现，手滑多记直接回退，对齐原卡片 -1）；测量类当前值旁「撤销」小按钮（保留原有确认弹窗）+「记录」弹数字键盘；**长按磁贴弹快捷菜单**：撤销今日最近一笔（数值型）、查看详情、编辑 |
| 10 | 快捷打卡页 | `HabitQuickCheckInView`（Holo One 入口）同步磁贴化，进度区用同款橙色条 |
| 11 | 空状态 | 示例磁贴引导：显示 3 块虚线示例（散步/阅读/早睡），点击打开新建页并预填 |
| 12 | 深色模式 | 淡底/实底两套色值一并定义 |

**v2 候选（本期不做）**：手动拖拽排序、连续天数里程碑角标（7/21/100 天）、磁贴原地展开操作条、首页看板习惯区迷你磁贴化。

## 三、页面结构

```
导航栏（不变：返回 / 「习惯」 / ＋）
├─ 进度区：标题行 + 橙色渐变进度条
└─ 磁贴墙：LazyVGrid 2 列，纵向滚动
底部 Tab（不变：统计 / 习惯 / 设置）
```

- 进度区：`今日进度 5/9`（完成数为橙色大数字）+ 副标题「还有 4 项待点亮」（全部完成时主标题变「今天全部点亮 ✨」、副标题「完美的一天」）；下方 6~7pt 高圆角进度条，宽度 0.5s 缓动跟随打卡实时增长。
- 磁贴墙：左右边距 20pt，列间距 12pt，行间距 12pt；单块宽度 =（屏宽 − 52）/ 2，最小高度约 118pt。

## 四、磁贴组件规格（新 HabitTileView）

**内容自上而下**：
1. 图标：SF Symbol / 自定义 template 图标，28pt，常态习惯色、点亮后白色
2. 名称：14pt semibold；连续天数以「🔥n」小字跟在名称后（点亮后白色系）
3. 副标题：10pt 次要色，显示频率；每日习惯省略不显示（信息只在偏离默认时出现）
4. 底部区：按类型分化（见下）

**底部区三种类型**：
- **打卡型**：本周 7 点阵——过去且完成=习惯色实心、过去未完成=习惯色 16% 淡色、今天=描边高亮圈（完成变实心）、未来=最淡。数据一次批量预取本周记录，不做每磁贴单独查询。
- **计数类**：迷你进度条（当前/目标）+ `5/8 杯` 数值 + 26pt「＋」圆钮；坏习惯显示 `3/5 支`，超上限时数字与进度条转 `holoError` 红。
- **测量类**：当前值（今日值优先，无则历史最新值）+「记录」胶囊钮 → 弹现有数字键盘 sheet。

**两态配色**（含深色模式）：
| 状态 | 浅色 | 深色 |
|------|------|------|
| 未完成 | 习惯色 8% 混白底 / 习惯色 16% 边框 | 习惯色 16% 混卡底 |
| 完成 | 习惯色实底 + 白字 | 同左，亮度略降防刺眼 |

色值计算封装进 DesignSystem（提供 habit 色的淡底/边框 helper），不散落 magic number。

## 五、交互与动效清单

| 场景 | 行为 |
|------|------|
| 点磁贴主体 | **仅打卡型响应**（勾选/取消，对称操作误触无害）；**数值类主体不响应**——加减/记录只走「−」「＋」「记录」按钮。验收教训：计数类主体若映射 +1，按「−」回退时手滑碰主体会误加，出现「减到一半反弹上涨」 |
| 点亮（打卡 toggle 完成 / 计数首次 +1 / 测量保存） | 颜色自点击点圆形扩散铺满 → 勾徽章 pop + `HapticManager.success()`。实现：overlay 习惯色层 + 从点击点扩大的 Circle mask（scale 动画 ~0.5s），动画结束切正式背景色并移除 overlay |
| 计数 +1（已点亮后再加） | 数字就地更新 + 迷你进度条增长 + 轻触觉 |
| 计数 −（手滑回退） | 「−」钮删今日最近一笔（无确认，与原卡片 -1 一致）；减到 0 时磁贴回到未点亮，「−」钮收起 |
| 坏习惯超标（计数 +1 / 测量保存后触发） | 数值与单位变红、进度条变红、「＋」钮变红，并显示提示文案「已经超过当日限额，请注意控制」（3 秒自动消失）——全部复刻原卡片行为，判定三分支（打卡型 isCompleted 且 target≤1 / 计数型 value>target / 测量型 今日值或历史值>target） |
| 取消打卡 | 再点已完成磁贴 → 颜色 0.4s 渐变回淡底 |
| 长按磁贴 | SwiftUI `contextMenu` 统一：「查看详情」「编辑」（AddHabitSheet(editingHabit:)）；数值型额外首项「撤销今日最近一笔」（现有 `removeLatestTodayRecord`） |
| 全部完成 | 进度条满格 + 标题切换 + 磁贴按位置依次波浪跳（间隔 ~45ms，仅触发一次；记录上一次进度避免重复播放） |
| 入场 | 磁贴瀑布式淡入上移（间隔 ~40ms），仅首次进入播放 |
| 本周点阵周起始 | 用 `Calendar.current.firstWeekday`（跟随系统区域，中国区=周一），不自造规则 |

## 六、数据与状态

- 列表：`repository.activeHabits`（`sortOrder` 升序）→ 天然满足「固定位置」；新建习惯 sortOrder 追加至末尾（现有逻辑不变）。
- **完成判定**：打卡型 `isTodayCompleted`；数值型=今日有记录。与 `getTodayCheckInProgress()` 语义完全一致，进度条数字与磁贴点亮状态永远同步。（注：demo 中「喝水满 8 杯才算完成」为演示简化，实装以本语义为准。）
- 状态刷新：沿用 `.habitDataDidChange` 通知机制，粒度细化到磁贴（通知携带 habitId，现有卡片已如此）。
- 本周点阵：进入页面时一次批量 fetch 本周记录，按 habit 分组预缓存，避免 N 次查询（遵循聊天页渲染预缓存的既有原则）。
