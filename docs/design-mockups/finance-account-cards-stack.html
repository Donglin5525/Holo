多层卡面光效柔光提亮右上角、晕影压暗左下、斜向光带划过——同一套材质模板，五个账户只换色板

材质色板（材质统一 · 只换色相）

  • 现金=祖母绿 · 微信=深海蓝 · 支付宝=深湖青 · 招行=深靛蓝 · 浦发信用卡=金卡（金色天然携带「信用卡」心智，与净资产卡的金线呼应）。
  • 每个账户四个变量：深色起点 / 主色 / 亮色终点 / 高光色。落 Swift 时同一套材质函数，账户只传色板——工程上可维护，视觉上成体系。
  • 全部卡面为深色材质，浅色/深色模式同一张卡，零适配成本。

交互（与上稿一致，动效升级）

  • 点卡头翻卡置顶；上下滑动翻下一张/上一张；点当前卡进账户详情。
  • 翻卡时后方的卡轻微缩小+降透明（景深对焦感）；动态区切换带轻微模糊过渡。
  • 卡堆下方动态区随卡联动：信用卡=账单/还款倒计时/额度三件套+分期流水；普通账户=本月收支三格+近期交易。
  • 账户超过 8 张自动回退平铺或折叠「+N」；归档账户收进卡片视图列表；记住上次选中卡。

原型内为示例数据，「距还款日」为静态演示值。落 Swift 时：材质=多层渐变 overlay + 噪点纹理叠加，翻卡=ScrollView/手势 + matchedGeometryEffect，环境光=跟随选中卡的径向渐变头图。此稿为视觉终稿方向，动效参数（0.5s · 弹性曲线）与 iOS 春簧动画手感对齐。
