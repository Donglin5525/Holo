2026-08-22 · 承接「能力不可见」的根治：上一轮让用户知道「有报告档案」，这一轮让用户在发起前就知道 「都能分析什么」。核心动作：报告 Tab 上半部升级为场景目录（能力陈列馆），下半部保持档案。 → 第一台手机的场景卡可以点，点了看「将预填的问句」。
现状能力藏在一句空话里
「深度分析」四个字不告诉用户能分析什么；财务、睡眠、习惯这些场景在发起前完全不可感知。
教训空泛按钮已被否决
报告 Tab 的「发起新分析」按钮因「空泛无用 + 点击即发」被撤。场景目录不是它的回魂：每张卡是具体能力，点击是预填不发送。
方案场景目录 = 能力的家
6 个场景卡（含周期回放）+ 数据来源徽标 + 额度同池如实标注；点卡 → 切对话预填；档案长出场景徽标与筛选。零后端改动。
报告 Tab · 场景目录主形态 可交互
上半部=「你可以让 Holo 分析什么」场景卡（点卡片试试，下方出现将预填的问句）；下半部=档案照旧。

一条完整的场景动线（确认权全程在用户）
报告 Tab · 点场景卡（财务健康）→ 切回对话 · 问句已预填（可改）→ 用户按发送→ 生成（可切走聊天，完成亮红点）→ 档案落卡（带财务场景徽标）
发起永远以「预填到对话输入框」收口——场景卡、空态、未来任何入口都走同一模式，不再出现「点击即发送」。
D1 · 场景清单第一版收哪些？
推荐 6 个：财务健康 / 习惯坚持 / 睡眠与健康 / 跨域洞察（王牌置顶推荐）/ 任务效率 / 周期回放。任务效率数据在链路里但深度未验证，第一版可保守先上 5 个；想法/情绪场景待核查想法数据读取深度后再议。
D2 · 生成类胶囊是否退役？
推荐退役：「深度分析」「周期回放」从胶囊行撤下（职能由场景目录接管），胶囊行留「今日状态 + 规划目标」。代价：老用户发起多一步；备选：保留两颗胶囊但同改预填模式。
D3 · 场景归类怎么做？
P0 问句关键词本地归类（预填问句由我们生成、词表封闭，归得准）；旧报告按已有问句回溯打标。后续可让意图识别返回场景字段，届时零迁移成本。
D4 · 额度怎么呈现？
推荐目录区统一一句（「共用每月深度洞察额度 · 免费 2 次」），不逐卡标——克制、不贩卖焦虑；点卡预填时不拦（发送前额度预检照旧兜底）。
可行性与边界
  • 零后端改动：场景 = 预填问句走既有深度分析链路（时间语义/额度预检/档案归档全部复用）。
  • 场景卡的「读 XX 数据」徽标与记忆透明化（Holo 看了什么）同一方向，只列链路里真实读取的域，不虚标。
  • 跨域洞察是差异化王牌，置顶+皇冠标识；其问句明确点名三个域，引导模型做交叉分析。
  • 空态与常驻态用同一套场景卡组件，只换标题文案，降低维护成本。
  • 档案场景筛选第一版单选即可（跨域报告在多个筛选下出现的「多选」语义推后）。
