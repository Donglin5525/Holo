底色同源

每张卡从 Holo 暖深褐（净资产卡同源）出发渐变到「暖化后」的账户色；高光统一换成 Holo 暖金光——五张卡色相各异、血缘一致。

品牌橙点亮

冷色全部加黄相压饱和：冷祖母绿→暖祖母绿、深海蓝→暖靛、招行改用 Holo AI 紫系——色板本身就在说 Holo 的话。

品牌橙金卡 ★

品牌橙的三个落点（克制使用）

  • 信用卡卡面：烧橙 → 焦糖 → 品牌橙（#EA580C → #F46D38 延伸），品牌色最重的舞台，与净资产卡、Plus 主题的暖金一脉相承。
  • 选中态点亮：当前卡一圈淡橙描边 + 橙色把手条发光，未选中的卡完全不带橙——「品牌光照在哪张卡上」成为页面的视觉叙事。
  • 功能强调：动态区还款日/查看全部用品牌深橙；净资产比例条的负债段直接用品牌橙渐变——同一颗橙，在系统层反复回响。

本轮补齐的功能缺口（可直接操作）

  • 长按任意卡片 → 操作菜单：编辑账户 / 调整余额 / 设为默认 / 归档——高频管理操作不再必须进详情页（手机画布内按住一张卡 0.5 秒体验）。
  • 卡片视图切换：点净资产卡右上「› 卡片视图」展开全部账户管理列表——含归档账户组与「解归档」操作，点任意行回到卡堆并选中该账户。卡堆负责「看与翻」，列表负责「管理与找」。
  • 「＋ 添加账户」虚线卡头：常驻卡堆最底部，和导航栏 + 号双入口。
  • 归档语义：归档账户不进卡堆、不计入净资产，只在卡片视图可见——冻结但找得到。

为什么不是全部橙色

  • 账户靠颜色互相区分是功能需求，全橙会失去「一眼认出哪张卡」的能力。
  • 品牌的高级感来自「分寸」：净资产卡与信用卡承接品牌暖金，其余账户色回归但同源——像同一间屋子里的五件家具，木料一致、漆色各异。
  • 高光、描边、噪点、比例条这些「材质层」全部统一 Holo 暖调，哪怕色相不同，基因相同。

本稿交互与上一版完全一致（点卡头/滑动翻卡/动态区联动/入场落卡），仅做品牌融合：色板、高光、选中态、比例条。用户自定义账户色时按同一材质函数映射为「暖深褐 → 暖化主色 → 亮色」三段。落 Swift 时材质层（光效/噪点/描边）做成统一修饰符，账户只传一个主色。
