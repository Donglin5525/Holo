报告收藏 + 收藏夹内直接追问（交互原型）

需求：报告管理页右滑收藏/删除；收藏夹（新）；收藏的报告可直接追问，追问产生的报告能在原报告里看到。 本稿共 6 屏：右滑操作 → 收藏夹 → 空态 → 报告详情（内嵌追问 + 追问记录）→ 追问生成中 → 子报告（链式追问）。 屏1、屏4 有可点击演示。
现状已有的地基
删除：长按报告卡 → 确认弹窗，已上线（本方案把入口前移到右滑，弹窗保留）。
追问：详情页有「继续追问」按钮，但会弹回对话页输入，追问完的新报告平铺在档案里，和原报告没有视觉关联。
血统：每份追问报告的数据里已带「父报告/根问题」标记（lineage），只是从未在界面上透出。
方案三件事
① 右滑操作：列表右滑露出「收藏 / 删除」，收藏即时生效，删除走既有确认弹窗；
② 收藏夹：报告页顶部入口条 → 收藏夹页（按收藏时间倒序，可右滑取消收藏）；
③ 报告内追问：详情页底部常驻追问输入条，发送→生成→新报告直接挂进本报告的「追问记录」区块，不弹回对话页。追问记录按血统关联，子报告可继续追问（链式）。
边界提前想清楚的
· 追问消耗「深度洞察」额度，发送前预检（沿用现有文案体系）；
· 周期回放可收藏、不支持追问（没有血统锚点，不硬做）；
· 删除报告 = 收藏与追问链一并消失（收藏是报告的属性，不是副本）；
· 取消收藏不动报告本体；生成中的报告不可收藏（完成才进档案）。
① 报告页 · 右滑操作 核心交互
点击第二张卡片演示右滑：露出「收藏」（橙）与「删除」（红）。删除仍弹确认框（防误删，删的是报告+对应对话）；收藏即时生效并弹轻提示。已收藏的卡右上角星标常亮。

④ 生成中取消
生成中点「取消」：立即停止，不消耗额度，追问记录里的进行中卡随之消失——与聊天流取消语义完全一致。
交互规则速查
  • 收藏/取消收藏：即时生效，无弹窗。收藏成功弹轻提示「已收藏，可在我的收藏找到」；卡上星标常亮。取消收藏同样即时，无提示（可逆操作不打断）。
  • 删除：右滑或长按都进同一个确认弹窗（删除报告 + 对应对话，不可撤销）。删除 = 收藏和追问链一并消失，收藏不是报告的副本。
  • 追问：消耗深度洞察额度（走 analysis 池），发送前预检、失败不扣额；生成中可取消；完成后新报告插进本报告「追问记录」顶部，不弹回对话页、不跳转。
  • 追问记录：只列「直接追问本报告」的子报告（parentResultID = 本报告），子报告页里再看它自己的追问——链式钻取，不平铺整链。
  • 周期回放：可收藏、可删除；无追问输入条（无血统锚点）。
  • 聊天页里的追问链：不受影响。在聊天页发起的追问仍走现有「继续追问」锚点流；无论从哪发起，追问报告都会挂进原报告的追问记录——同一份血统数据，两个入口。
实现路径提示（给开发）
  • 存储：ChatMessage 实体加一个 favoritedAt: Date?（nil=未收藏，非 nil 即收藏时间，排序兼得），代码定义实体 + 轻量迁移，纯客户端、无需后端发版。
  • 右滑：报告列表从 ScrollView+LazyVStack 迁到 List（月份分组→Section header，触底加载哨兵不变），swipeActions 项目内已有 3 处先例（分类管理/纪念日等）。卡片视觉不变。
  • 追问：完全复用既有 continuation 锚点机制（parentJobID/parentResultID/lineage），只是把「跳回对话页输入」改为「详情页内输入条」；生成中状态与聊天卡同源（HoloAgentChatStatusPresenter）。
  • 追问记录：按 lineage.parentResultID 查子报告，列表 DTO 加 relation/shortLabel 透出。
开放决策点（默认按上述做，东林可推翻）
  • 档案列表（全部报告）里，追问报告保持平铺、只加「追问」小徽标区分（屏①第二张卡）；收藏夹与详情页内才做链式聚合。若想档案也聚合成「报告树」可以二期再看。
  • 收藏第一份报告之前，报告页顶部不显示「我的收藏」入口条（避免空入口）；收藏后常驻。
