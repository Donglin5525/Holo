Holo 审美方向 · 三方向原型

每一行是同一个画面，从左到右依次是「现状示意 → A 个人年鉴 → B 精密器物 → C 安静的数据艺术」。三个方向都保留首页结构（问候 → 日程 → 进行中的事 → 光球 + 五个入口 → 底部三项导航），也都保留品牌橙 #F46D38，只是改成「一页只用一处」。示例数据统一为 2026-11-21 周六，习惯和长廊里刻意放了最稀疏的状态（新建 2 天的习惯、没有记录的一天）。

怎么看先横向看一整行，凭第一眼选出「最想用的那台手机」，再往下看方向说明。
现状列的红点标的是「AI 感」来源：①Tailwind 默认色 ②紫色+星星 AI 符号 ③处处胶囊/阴影/光晕 ④字号层级太平。
字体方向 A 加载的是 App 已随包的思源宋体 / 霞鹜文楷文件，所见即真机字形；B/C 用系统字体近似。

05 三个方向的底层规则 选定后会把这些写进《Holo 审美宣言》和 DesignSystem token

A · 个人年鉴 推荐

  • 一句话：你的人生，被郑重地印成一本书。
  • 色：纸色 + 墨色 + 一处橙。功能色降到最少，支出不染红。
  • 字：思源宋体做标题，老式数字做大数字，霞鹜文楷专门给 Holo 的话。全部是现成字体。
  • 形：细线、虚线引导、刊头、页边日期；几乎不用卡片和阴影。
  • AI：页边批注，不用紫色，不用星星。
  • 代价：中等。和想法纸、长廊的气质一致，迁移阻力最小；需要注意宋体小字号在深色模式下的可读性。

B · 精密器物

  • 一句话：一台为人生做的精密记录仪。
  • 色：暖灰金属 + 黑 + 一处橙（像机器上唯一的橙色开关）。
  • 字：系统字体 + 等宽数字，大写英文小标签。
  • 形：刻度、编号、按键、液晶条、拨动开关。
  • 代价：中等偏高。按键、旋钮、开关都要重做；和想法纸、长廊温暖的方向有冲突。

C · 安静的数据艺术

  • 一句话：你的生活本身就是一件作品。
  • 色：近黑底 + 米白 + 一处橙，用明度做全部层级。
  • 字：粗体无衬线大数字，配极小的标签。
  • 形：年环、点阵、织物——每个模块一张标志性的图。
  • 代价：高。每张标志图都要单独设计并实现；默认深色会改变整个 App 的气质，录入型页面也不适合。
需要你拍板
  1. 选哪个方向？我推荐 A 做主调，把 C 的「标志性数据图」嫁接进来（年鉴里的 365 点阵、习惯织线、长廊月度点阵），日常温暖、可读，分享时又足够惊艳。
  2. 首页光球能不能改？三个方向都改了光球的画法（A 线描三环、B 旋钮、C 年环），结构和位置没动。它是首页门面，规范里目前受保护，需要你明确放行。
  3. 先从哪里落地？建议顺序：① 色板与字体 token（全局一起见效）→ ② AI 表达（去掉紫色和星星，改为批注）→ ③ 首页 + 长廊 → ④ 各模块与分享图。
