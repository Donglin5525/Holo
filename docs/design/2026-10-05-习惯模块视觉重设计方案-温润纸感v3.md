# Holo 习惯模块视觉重设计方案（v3 · 温润纸感）

> 2026-10-05 · 设计专员产出 · 待东林拍板三个确认点后交 ios-dev 实施
> 范围：纯展示层。只动 `HabitsView`（头部/摘要/空态）、`HabitTileView`（磁贴主体）、`DesignSystem`（新增 token）；不动数据层、业务逻辑、统计页、各 sheet 内部。
> 硬约束沿用：SwiftUI、深色模式、动态字体（ScaledMetric）、44pt 热区、状态不只靠颜色、习惯色是用户数据、Reduce Motion 全降级。

---

## 1. 设计立意与诊断

**这个页面应该给人的感觉**：一张摊开的打卡手账。早上打开，看到今天要做的几件小事安安静静排在暖白纸面上；每完成一件，「啪」地盖一个章，纸面亮起一块颜色；晚上全部点亮时，进度条变成一排橙色小灯。关键词：**生活感（纸与手账）、成就感（盖章与点亮）、温度（品牌暖橙只出现在页面层，卡片颜色留给用户自己的习惯色）**。

**当前版丑在哪（逐条诊断，代码依据）**：

| # | 问题 | 具体表现 |
|---|------|---------------------|
| 1 | 两套色彩语言打架 | 页面壳是中性灰白 `holoTool*`，磁贴却是「习惯色 8% 淡底 + 16% 彩描边」——浅色模式下 8% tint 几乎不可感知，只剩一圈若有若无的彩线 |
| 2 | 完成态色彩失控 | 完成卡直接铺 12 色图表原色（高饱和数据色），多卡完成整面墙像调色盘，与暖橙品牌、暖白底全面冲突 |
| 3 | 可读性隐患 | 黄 #EAB308、黄绿 #84CC16 实底 + 白字，对比度不足 3:1 |
| 4 | 字号碎片化 | 一张卡上 9/10/11/12/13pt 五种裸字号，火焰徽章仅 9pt——「连续 12 天」小到看不清，且全不走 ScaledMetric |
| 5 | 隐形热区撑爆排版 | 补签/备注按钮 44pt 隐形热区包 13pt 小字，卡片下半是一块看不见的空白，看起来排版塌了 |
| 6 | 没有品牌温度 | 标题 20pt 居中埋在导航条里，进度摘要是一行 15pt 小字 + 6pt 细条——高频激励型页面长得像设置页 |
| 7 | 模块气质割裂 | 任务模块已有成熟暖纸语言（`HoloTaskPaperTheme`），习惯模块完全没用上 |

**上一轮「中性化改版」失败的根因**：把页面壳的中性化当成了目标，但只做了一半——壳变灰了，卡的淡彩底和彩描边还在，「灰底 + 淡彩卡 + 彩线」两头不靠。新方案的做法是明确**三层色彩分工**：页面层 = 品牌暖橙氛围；卡片层 = 用户习惯色（未完成安静、完成点亮）；功能层 = 语义色（红=超标）。各层不越界。

## 2. 整页布局结构

技术形态不变：`VStack(头部) + ScrollView(LazyVStack)`，网格沿用现有 `tileColumns` 自适应（手机 2 列，宽屏 2–4 列，列宽 ≥240pt）。只重绘各区块内部。

```
VStack(spacing: 0)
├─ 头部区（背景 = holoToolBackground，无分割线）
│   ├─ 操作行高 44：返回 44×44（左）｜＋按钮 36 视觉/44 热区（右）
│   └─ 标题组（左对齐，水平边距 20）
│       ├─ 大标题「习惯」 28pt semibold
│       └─ 日期行「10月5日 · 周一」 13pt 次要色
├─ ScrollView
│   └─ LazyVStack(spacing: 24)
│       ├─ ① 今日摘要区
│       ├─ ② 磁贴墙 LazyVGrid(spacing: 16)
│       └─ ③ 已暂停折叠区（基本不动，chip 对齐新语言）
│       padding: 水平 20 / 上 20 / 下 100
└─ 底部 Tab 栏（不动）
```

**① 摘要区（成就感主阵地）**：
- 第一行：`今日` 15pt 次要色 ＋ **`3` 24pt rounded bold 品牌橙** ＋ `/ 5` 15pt 次要色；右侧状态文案（「还有 2 项待点亮」13pt / 全完成时「完美的一天 ✨」13pt 橙 semibold）。
- 第二行：**分段进度条**——每段对应今天应打卡的一个习惯：段高 8pt、capsule、段间距 3pt；完成段填品牌橙，未完成段填 `holoToolInset`；全部完成时整条切 `holoPrimary → holoPrimaryDark` 渐变。比连续细条更有「一格一格点亮」的计数感。

**＋按钮**：视觉 36pt 圆、44pt 热区，底 = `holoPrimary → holoPrimaryDark` 垂直渐变、白 `plus` 16pt semibold，阴影橙 30% r8 y3。

**空态**：三张示例磁贴改「虚线纸卡」：纸白底、习惯色 40% 虚线描边、左上 36pt 图标 chip、名字 17pt、下方「点击创建」13pt。

## 3. 磁贴卡片设计

### 3.1 卡片容器（两态统一骨架）

| 属性 | 未完成（安静纸卡） | 完成（点亮卡） |
|---|---|---|
| 底色 | `holoCardBackground`（纸白，**去掉 8% 习惯色 tint**） | 习惯色经「暖化钳制」后的实底 |
| 圆角 | 20pt continuous（新增 `HoloRadius.tile = 20`） | 同左 |
| 描边 | 1pt `holoToolBorder`（**去掉彩色描边**） | 深色模式补 1pt 习惯色 30% 描边 |
| 阴影 | black 3.5% r8 y2 | 习惯色 18% r10 y4（浅色；深色关阴影用描边） |
| 内边距 | 16（原 14） | 同左 |
| 最小高度 | 132（原 118） | 同左 |

两态切换 = 背景/文字色 crossfade（`recordSettle` 0.4s easeOut）。

### 3.2 卡内层级

```
行1  图标 chip 36×36 圆角10 ──────────── 右上角状态位
行2  名字 17 medium ＋ 连续/累计徽章（ViewThatFits 降级链沿用）
行3  副标题（仅频率非每日/坏习惯上限）13pt
     ↕ 弹性留白（Spacer，最小 8）
行4  类型分化操作区，与上方间距 ≥12
```

- **图标 chip**：36×36 圆角 10；未完成 = 习惯色 12% 底 + 习惯色图标 20pt；完成 = 白 28% 底 + 白图标；emoji 完成态白 28% 圆片托底。行高钉死 36。
- **右上状态位**：未完成 = 空心圆环 22pt、描边 1.5pt `holoToolBorder`（「待办」暗示）；完成 = **白圆勾章 24pt + 习惯色 checkmark 12pt bold**（「盖章」）。形状差异满足「状态不只靠颜色」。
- **徽章**：从裸文字升级小胶囊——高 20、水平 padding 8、capsule；flame.fill 10pt + 数字 11pt semibold（动态字体）；未完成 = 橙 12% 底 + 橙字；完成 = 白 20% 底 + 白字。累计徽章同构、底色习惯色 12%。

### 3.3 三种类型的底部操作区

通用规则：**可见控件与热区解耦**——可见尺寸按表，热区一律 44×44（44×44 透明 frame 承接点击 + 可见 chip 居中 overlay）。

| 类型 | 可见设计 | 数值 |
|---|---|---|
| **打卡型** | ① 本周点阵 7 点：点 8pt、间距 6；过去完成=习惯色实点，漏卡日=虚线空心点+微型加号，今天=习惯色描边 1.5pt，未来=最淡。② 操作 chips 行（右对齐）：「补签」「备注」chip 高 28、字 13pt；未完成=习惯色 30% 描边+习惯色字，完成=白 85% 描边+白字 | 点阵行高 8，chips 行高 28 |
| **计数型** | ① 进度行：条 6pt capsule，轨道 `holoToolInset`、填充习惯色（超标=`holoError`）；数字「3/8」15pt rounded semibold monospacedDigit。② 按钮行（右对齐）：＋ 视觉 40pt 圆、习惯色实底白＋（超标红底）；− 视觉 32pt 圆、习惯色描边，仅今日有记录时出现 | 热区均 44 |

## 4. 色彩与字体规范

### 4.1 习惯色 × 暖底共处策略（三层分工 + 钳制）

**分工**：品牌橙只出现在页面层（标题区、摘要数字、分段条、＋按钮、全完成庆祝态）；卡片层完全让给用户习惯色；红只表超标。两层永不混用。

**策略一：新选色板（治本）**——习惯选色器换成预钳制的「暖化 12 色」，每个色都保证白字对比 ≥3:1，色相顺序对齐现有图表色板：

| 色槽 | 蓝 | 橙 | 绿 | 红 | 紫 | 青 | 粉 | 金 | 靛 | 黄绿 | 玫红 | 天蓝 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| hex | #3B76C9 | #D9662C | #2FA360 | #D64545 | #8063CE | #1F9E9E | #C94F86 | #A87B0F | #5A67C7 | #6E8F26 | #CE4A6B | #2E8FB8 |

**策略二：存量色渲染层钳制（治已入库旧色）**——纯函数 `Color.holoHabitSurface(_ scheme:)`：浅色 saturation≤0.75、brightness≤0.82；深色 saturation≤0.70、brightness∈[0.60, 0.88]；**色相一律不动**（用户的绿色不能变橙——色彩语义是数据）。

**策略三：未完成态去 tint**——纸白卡 + 暖灰描边，习惯色只以图标 chip + 操作元素点状出现。整面墙未完成时是安静暖白纸墙，完成一张亮一块，对比即成就感。

### 4.2 字体层级（全部走 `holoText`/ScaledMetric，卡内无裸字号）

| 用途 | 规格 |
|---|---|
| 页面大标题 | 28pt semibold（pageTitle） |
| 日期行/副标题/chips/撤销 | 13pt（metadata） |
| 摘要数字 | 24pt rounded bold 橙（新 role `habitScore`） |
| 卡名 | 17pt medium（body） |
| 徽章/单位 | 11pt semibold（caption2） |
| 计数数字/测量值 | 15pt rounded semibold monospacedDigit（新 role `habitValue`） |

## 5. 关键交互与微动效

所有动效经 `HoloAnimation` token，reduceMotion 时全部退化直接切换。

| 场景 | 表现与参数 |
|---|---|
| **打卡瞬间** | ① 卡底色 crossfade `recordSettle`(0.4s easeOut)；② 勾章「盖章」scale 1.4→1 + opacity 0→1 `snappy`(spring 0.3/0.7)；③ 触觉 success 保留 |
| 取消打卡 | 背景 crossfade 回退；勾章淡出（无 scale） |
| 计数 +1 | 数字 `contentTransition(.numericText())` + `standard`(0.2s)；进度条宽度 `standard`；＋按钮按压回弹 |
| 超标瞬间 | 进度条/＋色 crossfade；警告行 opacity+上移 4pt `enter`(0.2s)，3 秒淡出 |
| 连续徽章里程碑 | streak 达 7/30/100/365 当日首次渲染：`symbolEffect(.bounce)` 单次 + 徽章底色脉冲 `completionGlow`(0.6s)；日常变化无动画 |
| 补签完成 | 漏卡点 虚线→实点 scale 0.5→1 `snappy` |
| 摘要分段条 | 对应段 crossfade 填橙 easeOut 0.5s；全完成整条切暖金渐变+「完美的一天 ✨」，无撒花 |
| 磁贴入场 | 淡入+上移 6pt `enter`(0.2s)，延迟 index×0.03s（上限 10 张） |

## 6. 风格方向 A/B 与推荐

**A · 温润纸感（本方案，推荐）**：纸白卡、暖灰细线、盖章完成、分段点亮。
优点：与任务模块暖纸语言同源，全 App 气质统一；实现全落在普通 SwiftUI 形状/颜色，无材质成本；「盖章」语义直白成就感强。
缺点：风格偏软，高级感不如玻璃炫；需纪律维持克制，做浓了显旧。

**B · 清透玻璃感**：iOS 26 液态玻璃材质，完成卡变彩色玻璃薄片。
优点：更系统原生、炫。
缺点：大面积彩色 blur 叠暖白底易发灰发脏；玻璃上保证文字对比需逐色调材质，深色工作量翻倍；滚动性能成本；与纸感任务模块割裂——上一轮失败的教训正是语言不统一。

**推荐 A**：这个页面的目标是每天给你「盖完章」的踏实感，纸感语言的服务对象是用户的生活记录，不是炫技。
