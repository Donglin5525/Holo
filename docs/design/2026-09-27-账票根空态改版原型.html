账票根 · 空态改版三方案

改版背景：现版本空态 = 一条深色出票横条 + 一枚虚线胶囊，黑条孤立在暖白背景上、区域信息量过低。以下三方案删除黑条、重排空态； 有票后的堆叠、吐出动画、撕掉交互三案一致保留（方案 A / C 的出票口改为深暖灰细缝而非黑条）。

玩法：点入口/添加按钮 贴一张票根（可连点到 3 张） · 鼠标悬停票根点 ✕ 或右键票根 = 长按撕掉 · 贴满 3 张入口变禁用提示

方案 A

票根空位卡

推荐

空态 = 一张预留好的「相框空位」：虚线框内幽灵票根剪影 + 添加按钮，一眼看懂这里能贴照片；贴票后幽灵退场，票从卡片顶边细缝吐出。隐喻从「收银机」转为「相册空位」，与 Holo 卡片语言同构。
