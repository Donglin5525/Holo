识图记账复核页 · 重设计原型

2026-11-11 · 针对「信息乱、一屏装不下、多笔利用率低」三连问题 · 方案出自 ios-design，原型即契约（拍板后 1:1 落地）
一句话思路：把「看」和「改」分开。扫一眼就能确认的，用紧凑摘要全部摆在一屏里；要细改的，点开哪笔改哪笔。重复的话只说一遍——对方名只在名称栏出现一次，票面金额只在跟你改过的数字对不上时才冒出来。

1三个问题分别怎么解决的

  • 一屏装不下：科目/账户/项目/日期从四个整行（约 176pt）压成 2×2 小格（96pt）；日期从常驻控件改成小格点开弹层（复核场景日期基本不用改）；原图从 68pt 双行缩略条压成 44×44 卡角小图。单笔合计约 469pt，屏幕可用 719pt，最坏情况（转账+笔级警示+票面不符）555pt 也稳稳一屏。
  • 信息碎、重复：对方名原来出现两次（转账行+名称栏）→ 只留名称栏；金额出现两次（大金额+票面原文行）→ 票面值与输入一致时不显示、不一致时显示一行小字「票面原文 ¥xx」；「第 N 笔」标题砍掉（多笔靠金额+名称区分，行序即笔序）。
  • 多笔利用率低：原来一笔一张全尺寸大卡（约 500pt），3 笔滚 3 屏。现在每笔是两行制摘要行（约 64pt：上行=名称完整+金额右对齐，下行=方向胶囊+科目·账户小字），列表卡头部是汇总条（笔数 + 合计大字），4 笔全收起一屏放得下还能再展开一笔细改（717pt）；8 笔以内不滚动。两行制是 11-12 东林反馈「名称被挤成一个字」后的定稿——单行塞六种信息是死结，修哪个挤哪个，账单式两行（微信/支付宝同款）让名称从此完整。

3多笔交互（画板②可以点着试）

  • 点行：展开这笔的编辑块（手风琴，一次只展开一笔），再点收起；
  • 点圆圈：剔除/恢复这笔，行变淡，底部按钮的笔数和合计实时变；全剔光时按钮变灰显示「先勾选要记的账」；
  • 点「查看原图核对」：弹层看大图，看完关掉，页面位置不动（原来是在页面里撑开一大块）；
  • 方向切换：科目自动重新匹配、转账行「转出↔收到」实时跟着变（逻辑与现状完全一致，只挪了位置）。

4东林已拍板（11-11 原型标注，随契约落地）

  • 转账笔的页面级警示「请核对方向和对方。」去掉——转账行的「转出/收到」方向胶囊已经把方向说清楚了，这句是废话；
  • 多笔提示压成一句：「勾掉不想记的，一次入账。」（旧文案 28 字太啰嗦）；
  • 「N 笔待确认 · 合计 ¥xx」从 meta 小灰字升级为列表卡头部汇总条：笔数 13pt 次级色、合计 24pt 大号加粗数字，勾选实时更新——这是多笔场景的第一关键信息，必须一眼看到；
  • （11-12）多笔摘要行改两行制：首版单行 52pt 里塞勾选+金额+方向+名称+科目·账户+箭头六种信息，名称被挤到只剩一个字（东林实报「丑死了」）。定稿=账单式两行：上行「名称（完整）+ 金额右对齐」、下行「方向胶囊 + 科目·账户小灰字」，行高 64pt。

5待拍板的四个点（都有默认，没意见就按默认走）

① 多笔一次只展开一笔（手风琴）？
默认：是。都展开又回到「一屏装不下」的老问题。
② 票面金额只在跟你输入的数字对不上时才显示？
默认：是。对得上就是废话，不占地方。
③ 对方名只保留在「名称」一栏（转账行不再重复显示）？
默认：是。要保留的话就得反过来砍名称栏，二选一。
④ 单笔态保留右上「记这笔」开关？
默认：保留（它和底部「删除草稿」不完全重复：开关=这笔跳过但草稿还在；删除=整个草稿没了）。想砍也行，能再省一行。

6什么没动

  • 功能一样不少：逐笔编辑七个字段、剔除笔、转账/红包行、警示文案、看原图、三按钮、同向合计；
  • 确认落账的后台逻辑（幂等防重复、科目学习、票根归档、结果留痕）一行不改，只换皮；
  • Holo 既有视觉语言：橙主色、卡片圆角 14、内嵌圆角 10，不新增颜色和圆角档位。
