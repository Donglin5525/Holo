侧边栏导航骨架 · 12.9 寸横屏（1366×1024，示意按 80% 缩放绘制）

图中 橙色圆点编号 对应左侧「本稿拍板点」。本稿定的是骨架：侧边栏长什么样、内容区怎么铺、两层导航怎么合一。内容区的灰色虚线框只是位置示意，具体页面在稿②③④里定。

1本稿拍板点

1侧边栏条目与顺序
推荐如稿：今天 / 想法 / 财务 / 任务 / 习惯 / 记忆长廊 / 健康 / AI 对话，下隔一条分组线放 个人 / 设置。右侧灰字是键盘直跳键（⌘1…⌘8）。若觉得 8 项太多，「健康」可收进次级。
2宽屏内容怎么铺
推荐：通铺 + 32pt 边距，彻底告别 720pt 窄列居中（12.9 横屏两侧各空 323pt 的根因）。11 寸与竖屏自动降为单列，手机完全不受影响。
3模块内小标签栏上移顶部
财务(5)/任务(4)/习惯(3) 内部现在的底部小标签栏全部取消，改为右上角分段切换（如右上示意）。全 App 从「两套导航」变「一套」。
4设置 / 个人升级为正式页面
从弹窗改为侧边栏目的地，点开就是页面，不再出现截图里那块窄卡片。设置页宽屏做双栏（左侧分组导航、右侧内容）。
5中央橙色主按钮的新家
现在悬浮胶囊中央的橙色凸起按钮，迁移为侧边栏底部「＋快速记录」长条按钮（快捷键 ⌘N 不变）。胶囊导航条在 iPad 上退役，手机继续用胶囊。
6系统菜单栏 + 全局快捷键
接妙控键盘后顶部出现系统菜单栏（示意），快捷键从「透明按钮」改为系统菜单方案：任何页面都生效（修复现在对话/我的页按 ⌘, 无响应的问题）。⌘1-9 直跳、⌘N 新建、⌘W 关闭、⌘F 搜索、⌘, 设置。

范围与边界

iPhone 零变化：侧边栏只在 iPad 宽屏出现，手机仍是底部胶囊三 tab。
11 寸 / 12.9 竖屏：侧边栏同样出现，内容自动降为单列或双栏。
状态不丢：切换模块不销毁页面（现有关机保活机制保留），聊天滚动态、列表位置都还在。
本稿不做：分屏多窗口 / Stage Manager（维持全屏运行）；iPhone 横屏。
