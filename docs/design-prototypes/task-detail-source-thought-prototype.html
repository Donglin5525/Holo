这个原型说明了什么

  • 左（现状）：页面顺序是 标题 → 子任务 → 附件 → 属性设置（时间/清单/优先级/状态/目标）→ 想法卡垫底。想法转来的任务标题通常被改写过，想回忆「我当时的原话」反而要滑到最底部。
  • 右（改后）：只把想法卡挪到标题卡正下方——看完任务名，下一眼就是它的来源。卡片很矮（两三行），不会挤压任何主信息。
  • 不受影响的部分：普通任务（不是从想法转来的）不显示这张卡，页面完全不变；卡片内容、样式、点击后跳回想法详情的行为都不变。
  • 改动成本：代码层面就是把一行代码换个位置，无新增逻辑。
