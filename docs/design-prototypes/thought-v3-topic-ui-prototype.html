改动对照 · 主路径上发生什么

移除（从主路径退场）

  • 「✨整理想法」入口与进度 / 失败 / 配额展示
  • AI 标签、AI 建议标签、标签治理
  • 低置信主题确认队列（不再制造待办）
  • 「未归入主题」数量卡（未归类≠负债）
  • 「发现新主题」审批卡（由建议卡替代）
  • 「整理设置」与分类主题开关
  • 知识树入口（被「主题」分段替代）

保留（体验不变）

  • 时间流卡片 + 搜索
  • 用户 #标签：照常输入、展示、筛选
  • 新增想法入口（右下 +）
  • 断网 / 关闭 AI 时：记录与文字搜索完全可用
  • 主题列表与已归档（弱化为列表底部小入口）

新增（静默生长）

  • 卡片底部主题弱徽章（最多 2 个）
  • 点徽章 → 更改主题 / 从这条移除
  • 主题页顶部「新脉络」建议卡（最多一张）
  • 主题详情：AI 摘要 / 反复观点 / 时间脉络 / 相关旧想法
  • 设置里的「设备智能索引」状态页（AI 唯一可见处）

待拍板 · 5 个点

都已按推荐做法画在稿子里；不同意哪个就指出，我按你的意见改。
1
主题徽章样式：灰绿小胶囊（叶子图标），与橙色 #标签拉开区分。AI 自动关联和手动添加的徽章长得完全一样，不做视觉区分——避免「这条是 AI 贴的」心理负担。可以接受吗？
2
筛选行：用户 #标签 与主题混排一行横滚（省纵向空间）；还是分成两行（#标签一行、主题一行）？稿子里画的是混排。
3
建议卡三按钮：建立主题 / 改个名字 / 以后再说（方案原文文案）；「不再建议这个方向」收在卡片二级（长按或角落小字），不占主按钮位。OK？
4
主题详情摘要标题：稿子里用「这段时间的变化」这种平实标题 + 「AI 摘要 · 可重建」角标；也可以直接叫「AI 摘要」。倾向前者（AI 退后一步）。
5
保存反馈文案：「已记录」+ 绿色对勾，1.5 秒自动消失。备选：「已保存」「记好了」。定一个。
