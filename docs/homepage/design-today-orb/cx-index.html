HOLO · 今天

四个创新方向 — 动态演示

都是真实动画（速度与真机不完全一致）。素四·本色仍是保底可落地方案；以下四颗是探索「球成为今天本身」的边界。

创新一
月相钟

亮暗 = 今天的时间进度：清晨细亮、正午全亮、深夜近暗（演示为 16 秒一天快进）。文字在真机版将锚定亮暗交界线，位置随时刻变化——它永远站在「此刻」上。

风险：新增时间维度，需与三环的「事情」维度讲清分工
创新二
行星与卫星

进度=轨道上的卫星：今天 3 项 = 3 颗星（已亮 2、待办 1）。演示了完成瞬间——暗卫星周期性点亮（真机上由真实完成事件触发、点亮后常亮）。

风险：安排多时轨道拥挤（可超 5 颗合并为星尘）；动效实现量较大
创新三
天气球

球面即今天的天空：演示「有安排」的晴间多云态，云纹以不同深度缓慢飘移。无急事=通透无云；逾期=球缘薄雾（不带负面感的表达）。

风险：天气隐喻需要学习成本；云雨动效实现量最大
创新四
显影文字

平时球面零文字，触碰瞬间铭文如水面倒影浮起、涟漪同步荡开、松手沉没（7 秒循环演示）。文字从「标签」变成球的「表情」。适合作为交互彩蛋叠加在素四之上。

风险：信息从常驻变触碰可见——建议只做叠加彩蛋，不替代常驻摘要
