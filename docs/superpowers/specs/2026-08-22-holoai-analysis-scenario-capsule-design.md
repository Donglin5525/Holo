# Holo AI「深度分析胶囊场景化」设计文档（甲方案）

- 日期：2026-08-22
- 状态：已实施（编译绿，待东林真机验收）
- 原型：`docs/design-mockups/holoai-capsule-scenario-options.html`（三方案对比，甲中选）
- 被否方向存档：`docs/design-mockups/holoai-analysis-scenario-catalog.html`（场景目录放报告 Tab——东林否决，场景做在胶囊上）

## 1. 背景与决策

东林诉求：Holo 有很多深度分析能力（财务/睡眠等），用户发起前根本不知道——要把场景**显性**感知出来。方向定为：**「深度分析」胶囊点开场景面板**（甲方案），而非高频直出（乙）或一点一长按（丙）。选甲的理由：只有面板能把全部场景连同「能回答什么」摊开给用户看，感知最大化；乙只剩名字、丙把场景藏起来，都与「显性」初衷相反。

## 2. 场景清单（8 个，数据链已核实）

分析链路 14 个数据源全接（Finance 含预算 vs 实际全口径 / Habit 14 天聚合 / Health 步数·睡眠·站立·运动 / Task / Thought / Goal / Insight / Memory / Profile / Conversation / Anniversary / Project / Feedback / ThoughtReference）。

**预填问句三约束（2026-08-22 校验定稿）**：①每句含「分析/复盘」稳定命中后端 `query_analysis`（意图注册表 v2 触发词：分析、复盘、趋势、结构、占比、总结；长期模式例外走普通对话）；②单域问句必含「最近」给时间语义一个明确锚点；③开放式聚焦——跨域**不点名任何域**（数据在哪个域就分析哪个域，由 Agent 动态工具发现决定），单域用「重点看/比如/也」给方向不给封闭清单。

| 顺序 | 场景 | 预填问句（定稿） | 额度 |
|---|---|---|---|
| 1 | 🔗 跨域洞察（**王牌置顶**） | 把我的各类生活数据放在一起做一次深度分析，重点找出单看一处发现不了的规律 | 深度洞察池 |
| 2 | 💰 财务分析 | 深度分析一下我最近的财务状况，重点看支出结构和预算执行，有异常消费也指出来 | 深度洞察池 |
| 3 | 🌱 习惯分析 | 深度分析一下我最近的习惯坚持情况，哪些天容易掉档、可能和什么有关 | 深度洞察池 |
| 4 | 🌙 睡眠与健康 | 深度分析一下我最近的睡眠和健康数据，比如睡眠规律、运动日和不运动日的差别 | 深度洞察池 |
| 5 | ✅ 任务效率 | 分析一下我最近的任务完成情况和拖延模式 | 深度洞察池 |
| 6 | 💭 想法洞察 | 分析一下我最近反复在想的主题，想法的走向和变化 | 深度洞察池 |
| 7 | 🎯 目标复盘 | 复盘一下我的目标进度，有风险信号也提醒我 | 深度洞察池 |
| 8 | 🧠 长期模式 | 你了解我哪些长期偏好和模式？（既有画像问句） | **普通对话池，不占分析额度** |

保持独立不并入：周期回放（对账型，需选周期）、今日状态（轻量快问快答）、规划目标（流程型）。

## 3. 交互契约

1. **点「深度分析 ▾」→ 场景面板**（弹簧动画展开于能力行与输入栏之间；展开时收起键盘；箭头随开合翻转）。流式生成中胶囊禁用。
2. **选场景 → 只预填**：问句进输入框 + 来源提示条「来自「X」场景 · 可改写问句，确认后发送」；用户改写/清空/发送后提示**自然消失**（计算属性按 inputText == 预填原句判定，无状态同步负担）。
3. **空态建议卡「深度分析」同走面板**——新用户路径一致。
4. 切报告 Tab 时面板收起。额度如实呈现：面板顶部「分析场景共用每月深度洞察额度 · 本月剩余 x/N」（快照未就绪不显示数字），底注「长期模式不占分析额度」。
5. 全 App 发起类交互统一底线：**预填不自动发送，确认权在用户**（东林 2026-08-22 原则）。

## 4. 实现清单

- 新建 `Views/Chat/AnalysisScenarioPanel.swift`：`AnalysisScenario` 枚举（8 场景，词表封闭，未来档案场景关键词归类与此同源）+ 面板视图。
- `ChatViewModel`：`showAnalysisScenarioPanel`；`handleCapabilityTap` 拦截 `.recentAnalysis`（原点击即发改为开面板）；`selectAnalysisScenario`（预填+记录来源）；`activeScenarioPrefillTitle` 计算属性。
- `QuickActionBar`：`.recentAnalysis` 胶囊加开合箭头。
- `ChatView`：面板/来源提示条挂载、动画、键盘收起、切 Tab 收起。
- 纯客户端，无需后端发版。

## 5. 校验与审查记录（2026-08-22，东林要求）

1. **意图词面逐句校验**：8 句对照后端意图注册表 v2（触发词「分析、复盘、趋势、结构、占比、总结」）——7 句含「分析」或「复盘」稳定命中 `query_analysis`；长期模式句刻意不含触发词、走 `query` 普通对话（画像问答，不烧分析额度，与既有空态胶囊同一句、生产已验证）。相邻意图抢答风险排查：任务句不会被 `query_tasks` 抢（有「分析」强信号）、目标句不会被 `update_goal_field` 抢（无操作动词）、无「本周/规划」不触 `weekly_planning`、无「回放」不触 `generate_memory_insight`。
2. **跨域去硬编码**：原句写死「财务、习惯、健康」三域——用户数据若在任务/想法/目标，会被问句框死。定稿句「各类生活数据」不点名任何域，读哪些域交给 Agent 的动态工具发现（数据在哪就分析哪）。单域句同步软化：冒号封闭清单改「重点看/比如/也」开放式聚焦。
3. **旧默认问句残留清理**：报告 Tab 空态 CTA 原预填旧句「分析一下我最近的数据趋势」→ 改为切对话后**直接打开场景面板**（新用户第一发起就看全能力目录，比静默预填更有教育意义）；聊天空态建议卡副文案同步改「选一个场景，发起深度分析」。
4. **全链走查**：能力可见（面板摊开 8 场景）→ 发起（选场景仅预填，确认权在用户）→ 额度（发送时 sendMessage 预检兜底，面板不拦只告知）→ 生成（agent_loop + 动态工具发现）→ 归档（报告 Tab 落卡带原始提问+场景徽标）→ 找回（搜索/月份分组/场景筛选）——六环闭合，无断点。

## 6. 第四轮验收修订（2026-08-22，东林三项拍板）

1. **胶囊排序照原型**：「深度分析」排常驻胶囊行第一位（此前实现漏了 Provider 里的旧顺序，今日状态居首）。
2. **「今日状态」改预填不发送**（长期模式同批处理）：点击只把问句填进输入框，确认权在用户。至此除新用户「使用指南」卡外，全部问答类入口统一预填确认模式。
3. **档案场景徽标 + 按场景筛选拉进本批**：
   - 新增 `ReportScenarioTag` 归类器（P0 问句关键词本地匹配，词表与 AnalysisScenario 同源）：跨域判定优先（旧跨域问句含多个单域词；旧默认句「数据趋势」回溯归跨域），回放按 kind 归 `.replay`；
   - 档案卡与长廊门卡显示场景徽标（回放/其他不另显——类型徽标已表明）；
   - 档案顶部场景筛选行（全部 + 档案中实际存在的场景动态出链），筛选后月份分组随之收窄，空筛选有引导文案；搜索态优先关键词、隐藏筛选行。

## 7. 遗留与后续

- 意图识别终归是模型判定（评测 95.9%），问句已按词面最大化命中；若真机发现某场景被误路由，调整该句用词即可（词表在 `AnalysisScenario.question` 单点维护）。
- 新用户「使用指南」空态卡仍为点击即发（引导提问场景，暂保留，待观察）。
- 场景归类 P0 为关键词匹配；后续意图识别返回场景字段时替换 `ReportScenarioTag.classify` 实现即可，档案零迁移。
