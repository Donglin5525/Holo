任务首页 · 视觉改版方案

2026-08-17 · 延续习惯打卡页的设计语言 · 纯视觉与信息层级改版，功能不增不减
设计主张：习惯页好看，是因为它有「今天的仪式感」——进度头条、色彩淡染的磁贴、点亮时刻、全部完成的庆祝。 任务页要的也是这个感觉，但不能照搬磁贴墙：任务是「有期限的事务流」，标题长、信息密、靠扫读，两列磁贴会截断内容、降低处理效率。 所以本次移植的是习惯页的设计基因（进度头、淡彩、点亮、庆祝文案），布局上则让「时间」成为第一视觉维度： 顶部「今日」仪表区 + 按时间分组的任务流 + 带清单色身份的精致卡片。
01

从习惯页移植什么、不移植什么

先把这个判断说清楚，避免「为了像而像」。

不移植：两列磁贴墙

任务的信息密度撑不起磁贴

磁贴适合「一个图标+一个名字+一个动作」的习惯；任务单条常带长标题、描述、截止时间、清单、优先级、子任务。两列布局每格只有约 170pt 宽，长标题两行就截断，扫读效率反而下降。任务处理的最佳布局仍是单列卡片流。

移植①：进度头条

「今日进度 7/12」大数字 + 渐变进度条

习惯页的进度头是全页视觉锚点。任务页同款语言，但数据更丰富：右侧加环形进度作仪表感锚点，副行显示「还剩 N 项 · K 项过期」（过期是任务特有的紧迫信号，红色强调）。

移植②：色彩淡染身份

清单色 = 卡片左侧色条 + 时间胶囊色系

习惯磁贴用习惯色淡染出「每块磁贴有自己的颜色身份」。任务卡的等价物：左侧 3.5pt 清单色条（一眼区分归属），时间信息升格为右上角语义色胶囊（今天橙 / 过期红 / 明天蓝）。

移植③：庆祝时刻

「今天全部完成」的仪式感

习惯页全部点亮时切换文案+波浪弹跳。任务页同款：今日清零时，顶部仪表区整块变为品牌橙渐变庆祝卡「今天全部完成 ✨ 享受你的夜晚吧」。这是每天最值得给用户的一秒。

02

现状 vs 新版：问题清单

现状 Boring 的原因
今日进度藏在右上角一个小小的「3/5」，没有存在感，翻页即忘
时间维度任务平铺一列，过期/今天/以后混在一起，要自己逐条读小灰字才能分清轻重缓急
卡片清一色白卡+灰字，没有任何颜色身份，10 条任务看起来一模一样
筛选一排小灰胶囊（含所有清单平铺），又长又平，选中态也不突出
完成时刻划线变灰，没有愉悦感，清完一天毫无感觉
新版 对应的解法
今日仪表顶部 Hero 区：日期问候 + 40pt 大数字 7/12 + 环形进度 + 渐变条，过期数红色警示
时间分组已过期 / 今天 / 明天 / 本周 / 稍后 / 未安排 六组，语义色组头+计数，组可折叠；过期组永远置顶
卡片左侧清单色色条 + 右上角时间语义胶囊 + 优先级小胶囊 + 子任务迷你进度条，扫一眼就知道「谁的事、什么时候、多急」
筛选「今日」提为第一位并作默认视图；过期胶囊带红色计数角标；清单筛选收纳为单个「清单 ▾」入口，不再平铺占满一屏
完成时刻勾选后卡片轻弹+淡出（撤回条保留）；今日清零时 Hero 整块变橙色庆祝卡

05

交互规格

区域元素行为定义
顶部仪表Hero 区 新增视觉日期行 + 「今日进度 大数字 n/m」+ 环形进度（74pt，品牌橙渐变）+ 渐变进度条 + 状态句（还剩 N 项 · K 项过期，过期红色）。数据口径=现有 todayProgress，无新数据。
全部完成态 新增视觉今日任务清零瞬间，Hero 整块切换为品牌橙渐变庆祝卡「今天全部完成 ✨」+ 完成环打勾 + 「享受你的夜晚吧」；右上角原 3/5 小数字移除（信息已进 Hero）。
筛选胶囊顺序与默认 调整「今日」提为第一位并作为默认视图（原默认「全部」）；其余顺序：收件箱/全部/已完成/过期/清单/归档。过期胶囊带红色计数角标。所有筛选能力不变。
清单筛选收纳 调整各清单不再平铺占行，收纳为「清单 ▾」单个胶囊，点开弹清单选择层（复用现有清单选择器交互）；选中某清单后胶囊显示该清单名与色点。
任务流时间分组 新增视觉按到期时间分组：已过期（红点·置顶）/ 今天（橙点）/ 明天（蓝点）/ 本周 / 稍后 / 未安排；组头=语义色点+组名+计数胶囊+折叠箭头，点组头折叠/展开（记住展开状态）。已完成 tab 维持按周分组（现状）。
卡片视觉 升级左侧 3.5pt 清单色条（无清单=无色条）；时间信息升为右上语义色胶囊；优先级紧急/高显示小色胶囊；子任务区底部加「n/m+迷你进度条」。整卡点击进任务页、左滑归档删除、勾选撤回——全部沿用上一版重构的交互，零变化。
组内排序 不变组内按截止时间升序（同时刻按优先级），与现有排序逻辑一致。
最近已完成折叠抽屉 不变非今日视图下的「最近已完成」折叠逻辑保留；今日视图内已完成任务直接显示在「今天」组内（带绿色「已完成 时刻」胶囊），与撤回机制衔接不变。
