# Holo Plus 会员中心 — 高保真 UI 设计需求文档

## 产品背景
Holo 是一款 iOS 个人生活管理 App（记账、待办、想法、AI 对话）。Holo Plus 是它的订阅会员。
用户痛点：当前会员页面没有清晰展示"免费版 vs Plus 版"的差异，用户不知道为什么该付费。

## 设计目标
让用户在 3 秒内理解"升级能多得到什么"，并产生升级意愿。
参考对标：Apple One、Notion Plus、Things 3 的订阅页 —— 克制、高级、信息清晰。

## 页面结构（从上到下）

### 1. 顶部状态卡（深色，品牌橙系）
- 深色渐变背景（暖调深褐，不是纯黑，不是冷紫）
- 左上角：Holo Plus 徽标（圆形，橙金渐变球体 + sparkles 图标 + "+" 小徽章）
- 徽标右侧：
  - 大标题"Holo Plus"（如果已订阅显示 PLUS 橙色胶囊徽章）
  - 副标题"升级后解锁更高每日额度"
- 底部一行三个指标胶囊：HoloAI 3→30/天、语音 60秒→5分钟、任务 10→50/天
  - 胶囊用半透明橙色底，不是白色底
- 卡片右上角有一个柔和的橙色光晕（blur circle）

### 2. 权益对比表（页面主体，浅色卡片）
这是最重要的区域，要克制、清晰：

**表头行**（浅灰底）：
- 左列：空（或写"功能"）
- 中列："免费版"（灰色，普通字重）
- 右列："Plus"（橙色，粗体，带 sparkles 图标）—— 这一列整体有极淡的橙色底色

**数据行**（10行，行间用极细分隔线）：
| 功能（带小图标） | 免费版 | Plus |
|---|---|---|
| HoloAI 对话 | 3次/天 | 30次/天 |
| 语音识别 | 20次/天 | 50次/天 |
| 语音时长 | 60秒 | 5分钟 |
| 智能记账 | 20次/天 | 50次/天 |
| 智能任务 | 10次/天 | 50次/天 |
| 记忆洞察 | 1次/周 | 1次/天 |
| 语音启动小组件 | ✗（灰色） | ✓（橙色） |
| 快捷控制台小组件 | ✗（灰色） | ✓（橙色） |
| 财务小组件 | ✗（灰色） | ✓（橙色） |
| 随机漫步小组件 | ✗（灰色） | ✓（橙色） |

**视觉规则**：
- 免费版列数字：中灰色，普通字重
- Plus 列数字：品牌橙色（#F46D38），粗体
- 功能名列：小图标用线条风格（不要圆形底色背景），深灰色名称
- ✓ 用简单的橙色对勾（不要大圆底），✗ 用浅灰叉
- 行高要足够呼吸（每行至少 48pt 高）
- 不要每行都加背景色块，保持干净

### 3. 底部一句话说明
"所有记账、待办、想法等本地功能，免费版与 Plus 版完全一致。"
小字，灰色

### 4. 升级按钮
全宽橙色按钮"升级 Holo Plus"，白色粗体字

## 配色规范
- 品牌主色：#F46D38（温暖橙）
- 浅橙：#FED7AA（用于胶囊/徽章底）
- 深色卡片渐变：#1C1614 → #2A1B15 → #321E18（暖调深褐）
- 深底文字主色：#FFE8D5（暖白）
- 深底文字次色：#F0C9A8（暖灰橙）
- 卡片背景：#FFFFFF（浅色模式）
- 页面背景：#F5F2ED（温暖米白）
- 主文字：#1A1A1A
- 次文字：#8B8B8B
- 分隔线：#E8E5E0（极淡）

## 字体规范（iOS 系统字体）
- 状态卡标题：28pt Bold
- 状态卡副标题：15pt Medium
- 表头：13pt（免费版 Medium 灰，Plus Bold 橙）
- 功能名：15pt Medium 深灰
- 数据数字：15pt（免费版 Medium 灰，Plus Bold 橙）
- 底部说明：12pt 灰色

## 关键设计原则
1. **克制**：对比表不加多余装饰，让数字的对比（灰 vs 橙）自己传达信息
2. **呼吸感**：充足的留白和行高，不要信息堆砌
3. **视觉层级**：Plus 列是视觉重心（橙色），免费版列退后（灰色）
4. **高级感**：深色状态卡提供品质感，浅色对比表提供清晰感，两者过渡自然
5. **品牌一致**：全程品牌橙 #F46D38 为主色调，不出现金色
