1. 在 Prompt 调试开始前，用独立过程生成不少于 40 组留出情境（合成内容或已获准的脱敏内容），覆盖不同领域与组合。

3. 生成后即冻结：提示词调试（包括人工看样例调优）**不得读取本目录任何夹具的逐题答案**。
4. 跑最终评测后若据错误修改了 Prompt，本集合整体转为公开回归集，下次泛化评估必须生成新的留出集替换。
5. 评测 harness 按需加载本目录；评测报告须区分「公开回归」与「真正留出」两类结果。
